## Summary and actual behavior

**Code-confirmed.** [commands.rs:4331](https://github.com/BerryUIKI/Omera/blob/bdac8fbcdbac5535075e091453b77c3afe518ba5/src-tauri/src/commands.rs#L4331) trashes the queued source pathname once its deadline arrives. It does not use `target_file_id` to check that the managed copy still exists and matches, or verify that the source pathname still represents the file originally ingested. Cleanup is invoked during application startup.

If the destination disappears before the grace period ends, cleanup can remove the remaining original. If a generator replaces the source with a new file at the same path, cleanup can remove that newer file instead.

## Environment and evidence

- Baseline: Omera 0.4.3, `dev` at [`bdac8fb`](https://github.com/BerryUIKI/Omera/commit/bdac8fbcdbac5535075e091453b77c3afe518ba5); SQLite schema 15.
- Review host: Windows; the inspected application was launched from the repository root with `pnpm run tauri dev`.
- Evidence strength is stated above. For code-confirmed scenarios, the steps below describe a targeted validation scenario rather than a completed end-to-end reproduction. Remote-provider, destructive real-library and cross-platform scenarios were not exercised.

## Reproduction or validation scenario

1. In an isolated pipeline fixture, harvest an item with delayed source cleanup enabled.
2. Before the cleanup deadline, remove the managed destination; alternatively replace the source at the same pathname.
3. Run `process_pipeline_cleanups` and inspect the original/new source and cleanup receipt.

## Expected behavior

Cleanup preserves a source unless the verified managed destination exists and the source still matches the ingested item.

## Acceptance criteria

- [ ] Record and revalidate source identity and destination content immediately before cleanup.
- [ ] Use `target_file_id` and a durable receipt; retain a deferred/failed state when validation fails.
- [ ] Test destination loss, replaced source, trash failure and restart; exclude external vaults and unrelated media.
