## Summary and actual behavior

**Code-confirmed.** [lib.rs:66](https://github.com/BerryUIKI/Omera/blob/bdac8fbcdbac5535075e091453b77c3afe518ba5/src-tauri/src/lib.rs#L66) ignores auto-migration failure/skipping, then unconditionally opens/creates `omera.db`. [legacy_migration.rs:57](https://github.com/BerryUIKI/Omera/blob/bdac8fbcdbac5535075e091453b77c3afe518ba5/src-tauri/src/legacy_migration.rs#L57) treats mere destination existence as `migrated` when there is no receipt. The Vue source has no calls to the new legacy migration status/preview/start commands.

With multiple discovered legacy databases, a conflict, or an unusable source, users see an empty Omera library and cannot choose/import a source through the intended migration workflow. The legacy data is preserved, but the normal retry path is lost because the empty destination now exists.

## Environment and evidence

- Baseline: Omera 0.4.3, `dev` at [`bdac8fb`](https://github.com/BerryUIKI/Omera/commit/bdac8fbcdbac5535075e091453b77c3afe518ba5); SQLite schema 15.
- Review host: Windows; the inspected application was launched from the repository root with `pnpm run tauri dev`.
- Evidence strength is stated above. For code-confirmed scenarios, the steps below describe a targeted validation scenario rather than a completed end-to-end reproduction. Remote-provider, destructive real-library and cross-platform scenarios were not exercised.

## Reproduction or validation scenario

1. Start with no Omera database and two supported legacy database candidates in isolated application-data roots.
2. Run startup and inspect migration state and the resulting library.
3. Repeat with an unusable candidate or migration failure; attempt to select a source or retry after startup creates an empty destination.

## Expected behavior

Ambiguous/failed migration remains visible and retryable, including supported import after an empty Omera library exists.

## Acceptance criteria

- [ ] Persist choice-needed, failed and pending state independently of destination existence.
- [ ] Expose source selection and retry/import in the application.
- [ ] Test multiple candidates, failed migration, absent receipts, existing empty destination and repeated startup without source mutation.
