## Summary and actual behavior

**Reproduced and code-confirmed.** [transform.rs:63](https://github.com/BerryUIKI/Omera/blob/bdac8fbcdbac5535075e091453b77c3afe518ba5/crates/omera-scan/src/transform.rs#L63) performs raster transformation without implementing `metadata_policy`. A PNG-to-PNG resize with `KeepSupported` removes a supported embedded A1111 prompt. The normal export encoder likewise strips embedded metadata for all re-encoded outputs, even with `KeepAll` ([export.rs:205](https://github.com/BerryUIKI/Omera/blob/bdac8fbcdbac5535075e091453b77c3afe518ba5/crates/omera-scan/src/export.rs#L205)); original-byte fast pass is the exception.

Conversely, managed import's fast-copy path can preserve original embedded metadata when only a stripping policy is selected, because the transform predicate ignores the policy. Its transformed `StripAi` path also copies original `.txt`/`.json` sidecars unfiltered at [commands.rs:864](https://github.com/BerryUIKI/Omera/blob/bdac8fbcdbac5535075e091453b77c3afe518ba5/src-tauri/src/commands.rs#L864). Filtering only the database DTO does not sanitize the file users share.

## Environment and evidence

- Baseline: Omera 0.4.3, `dev` at [`bdac8fb`](https://github.com/BerryUIKI/Omera/commit/bdac8fbcdbac5535075e091453b77c3afe518ba5); SQLite schema 15.
- Review host: Windows; the inspected application was launched from the repository root with `pnpm run tauri dev`.
- Evidence strength is stated above. For code-confirmed scenarios, the steps below describe a targeted validation scenario rather than a completed end-to-end reproduction. Remote-provider, destructive real-library and cross-platform scenarios were not exercised.

## Reproduction or validation scenario

1. Resize a synthetic prompt-bearing PNG to PNG with `KeepSupported`; re-extract metadata from the published bytes.
2. Export a re-encoded image with `KeepAll`; inspect supported embedded fields.
3. Import using Original format with a stripping-only policy, and test transformed `StripAi` with prompt-bearing `.txt`/`.json` sidecars.

## Expected behavior

Preservation/stripping choices govern the published image and every sidecar, with unsupported preservation explained explicitly.
