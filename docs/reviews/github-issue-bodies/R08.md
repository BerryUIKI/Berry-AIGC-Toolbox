## Summary and actual behavior

**Reproduced.** [transform.rs:646](https://github.com/BerryUIKI/Omera/blob/bdac8fbcdbac5535075e091453b77c3afe518ba5/crates/omera-scan/src/transform.rs#L646) applies original disposition before [transform.rs:679](https://github.com/BerryUIKI/Omera/blob/bdac8fbcdbac5535075e091453b77c3afe518ba5/crates/omera-scan/src/transform.rs#L679) updates the file record. A synthetic trigger rejecting UPDATE causes a failed item whose indexed source is already archived and missing from its original path. There is no compensating rollback in that path.

## Environment and evidence

- Baseline: Omera 0.4.3, `dev` at [`bdac8fb`](https://github.com/BerryUIKI/Omera/commit/bdac8fbcdbac5535075e091453b77c3afe518ba5); SQLite schema 15.
- Review host: Windows; the inspected application was launched from the repository root with `pnpm run tauri dev`.
- Evidence strength is stated above. For code-confirmed scenarios, the steps below describe a targeted validation scenario rather than a completed end-to-end reproduction. Remote-provider, destructive real-library and cross-platform scenarios were not exercised.

## Reproduction or validation scenario

1. Create a temporary managed folder and index a synthetic PNG.
2. Install a temporary SQLite trigger: `CREATE TRIGGER review_fail_update BEFORE UPDATE ON files BEGIN SELECT RAISE(FAIL, 'simulated database write failure'); END;`.
3. Call `execute_library_batch_transform` with JPEG output and `OriginalDisposition::Archive`; inspect the failed receipt and indexed source path.

## Expected behavior

A failed database update leaves the indexed original intact; disposition occurs only after durable destination/catalog verification.

## Acceptance criteria

- [ ] Persist a recoverable operation plan and validated destination before original disposition.
- [ ] Keep the indexed original intact on persistence failure and make unpublished derivatives recoverable.
- [ ] Test injected DB failure, interrupted publication/disposition, archive collisions, sidecars and restart reconciliation.
