## Summary and actual behavior

**Code-confirmed.** FastFingerprint at [cloud_sync.rs:469](https://github.com/BerryUIKI/Omera/blob/bdac8fbcdbac5535075e091453b77c3afe518ba5/src-tauri/src/cloud_sync.rs#L469) checks size only; collected mtime is discarded. WebDAV at [cloud_sync.rs:511](https://github.com/BerryUIKI/Omera/blob/bdac8fbcdbac5535075e091453b77c3afe518ba5/src-tauri/src/cloud_sync.rs#L511) ignores the selected checksum strategy and ETag and also checks only size. S3 checksum mode treats a missing checksum header as a successful size match.

Two different equal-length files are therefore reported as synchronized.

- Baseline: Omera 0.4.3, `dev` at [`bdac8fb`](https://github.com/BerryUIKI/Omera/commit/bdac8fbcdbac5535075e091453b77c3afe518ba5); SQLite schema 15.
- Review host: Windows; the inspected application was launched from the repository root with `pnpm run tauri dev`.
