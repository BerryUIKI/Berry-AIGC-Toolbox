## Summary and actual behavior

**Code-confirmed.** [SettingsModal.vue:591](https://github.com/BerryUIKI/Omera/blob/bdac8fbcdbac5535075e091453b77c3afe518ba5/src/components/SettingsModal.vue#L591) logs save errors but still emits the saved state and closes. Theme/locale/cache settings are applied before persistence; [config.ts:197](https://github.com/BerryUIKI/Omera/blob/bdac8fbcdbac5535075e091453b77c3afe518ba5/src/utils/config.ts#L197) mirrors failed writes into localStorage. A keyring, disk, or revision failure therefore produces divergent live/localStorage/backend values without an actionable error.

Reloading the latest config immediately before overlaying an older open form also weakens the intended revision conflict protection.

## Environment and evidence

- Baseline: Omera 0.4.3, `dev` at [`bdac8fb`](https://github.com/BerryUIKI/Omera/commit/bdac8fbcdbac5535075e091453b77c3afe518ba5); SQLite schema 15.
- Review host: Windows; the inspected application was launched from the repository root with `pnpm run tauri dev`.
- Evidence strength is stated above. For code-confirmed scenarios, the steps below describe a targeted validation scenario rather than a completed end-to-end reproduction. Remote-provider, destructive real-library and cross-platform scenarios were not exercised.

## Reproduction or validation scenario

1. Open Settings and change theme/locale and a persistent preference.
2. Inject a rejected `save_app_config` invocation due to revision, keyring or disk failure.
3. Inspect whether the dialog remains open, an error is visible and localStorage/live state agree with backend persistence.

## Expected behavior

A failed save remains visibly failed and preserves editable changes without promoting unpersisted mirrors.

## Acceptance criteria

- [ ] Retain the dialog/edits and show an actionable persistence error.
- [ ] Apply durable settings and localStorage mirrors only after successful persistence; identify any temporary preview.
- [ ] Save against the form's loaded revision and test concurrent edits, credential failure and disk failure.
