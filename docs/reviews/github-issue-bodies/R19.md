## Summary and actual behavior

**Code-confirmed.** [App.vue:1541](https://github.com/BerryUIKI/Omera/blob/bdac8fbcdbac5535075e091453b77c3afe518ba5/src/App.vue#L1541) updates flags in the loaded array without refreshing library counts or reapplying the active query; NSFW batch handling has the same shape. - Evidence strength is stated above. For code-confirmed scenarios, the steps below describe a targeted validation scenario rather than a completed end-to-end reproduction. Remote-provider, destructive real-library and cross-platform scenarios were not exercised.
