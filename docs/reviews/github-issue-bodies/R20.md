## Summary and actual behavior

**Observed UI and code-confirmed.** [PromptStatsModal.vue:43](https://github.com/BerryUIKI/Omera/blob/bdac8fbcdbac5535075e091453b77c3afe518ba5/src/components/PromptStatsModal.vue#L43) hardcodes `top_models: []` and `top_samplers: []`.
