## Summary and actual behavior

**Code-confirmed.** [commands.rs:787](https://github.com/BerryUIKI/Omera/blob/bdac8fbcdbac5535075e091453b77c3afe518ba5/src-tauri/src/commands.rs#L787) transforms only for a non-original format, max edge, or quality. Import UI emits scale percentage, alignment, and target-size fields, but selecting only one of these leaves the predicate false and performs a plain copy. Metadata-only policy suffers the related file-sanitization problem in R07.

- Evidence strength is stated above. For code-confirmed scenarios, the steps below describe a targeted validation scenario rather than a completed end-to-end reproduction. Remote-provider, destructive real-library and cross-platform scenarios were not exercised.

2. Set only scale percentage, alignment or target size, leaving max edge and quality unchanged.
3. Inspect the copied output and compare it with the emitted transformation request.
