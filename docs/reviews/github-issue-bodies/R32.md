## Summary and actual behavior

**Code-confirmed, latent in current Vue flow.** [commands.rs:4475](https://github.com/BerryUIKI/Omera/blob/bdac8fbcdbac5535075e091453b77c3afe518ba5/src-tauri/src/commands.rs#L4475) discards trash errors, appends every candidate to `successfully_trashed_ids`, ignores database deletion errors, and increments the returned count. It also lacks a source ownership check. Current App.vue culling calls `trash_files` instead of this command, so the active UI follows another path.
