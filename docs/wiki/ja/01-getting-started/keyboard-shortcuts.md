# キーボードショートカット一覧

Omera は、**キーボードファーストのワークフロー** を前提に設計されています。マウスに一切触れることなく、膨大なライブラリの閲覧、評価、グループ化、メタデータ確認、整理を行うことができます。

---

## 1. クイックルックとギャラリーの閲覧

| ショートカット | 操作 | 適用対象 | 説明 |
| :--- | :--- | :--- | :--- |
| `Space` または `Enter` | **ライトボックスを開く** | ギャラリー選択項目 | 選択した項目の高解像度クイックルックモーダルを開く。 |
| `Esc` | **閉じる / 選択解除** | グローバル | ライトボックスやモーダルを閉じる、検索入力をクリア、または選択を解除。 |
| `←` / `→` | **前へ / 次へ移動** | ギャラリー＆ライトボックス | 隣接する項目へ選択を移動（動画再生時は1フレーム単位のコマ送り／コマ戻し）。 |
| `↑` / `↓` | **上の行 / 下の行へ移動** | グリッド表示 | 視覚的なグリッドの1行上または下へ選択を移動。 |
| `Ctrl + A` / `Cmd + A` | **すべて選択** | ギャラリーキャンバス | 現在の検索・フィルター条件に一致するすべてのカードを選択。 |
| `Delete` または `Backspace` | **ゴミ箱へ移動** | ギャラリー選択項目 | 選択した項目をOSのゴミ箱へ安全に移動。 |

## 2. 高速キュレーションと評価

| ショートカット | 操作 | 説明 |
| :--- | :--- | :--- |
| `1` | **星1を付ける** | 選択した画像に星1つの評価を設定。 |
| `2` | **星2を付ける** | 選択した画像に星2つの評価を設定。 |
| `3` | **星3を付ける** | 選択した画像に星3つの評価を設定。 |
| `4` | **星4を付ける** | 選択した画像に星4つの評価を設定。 |
| `5` | **星5を付ける** | 選択した画像に星5つの評価を設定。 |
| `0` | **評価をクリア** | 選択した画像の星評価を削除。 |
| `F` | **お気に入り切り替え** | 選択した画像のお気に入り（ブックマーク）登録／解除を切り替え。 |

> [!TIP]
> **ブラインド評価テクニック**: 片手で矢印キー（`←`, `→`）を押して画像を次々とめくりながら、もう片方の手でテンキーまたは数字キー `1`〜`5` を押すことで、超高速なブラインド評価が可能です。評価は即座に SQLite へ非同期保存されます。

## 3. スタック管理と画像比較

| ショートカット | 操作 | 適用対象 | 説明 |
| :--- | :--- | :--- | :--- |
| `Ctrl + G` / `Cmd + G` | **スタックにまとめる** | ギャラリー選択項目 | 選択した画像をトランプ風のバーストスタックにグループ化。 |
| `Ctrl + Shift + G` / `Cmd + Shift + G` | **スタックを解除** | ギャラリー選択項目 | 選択したスタックを展開し、個別の単独画像に戻す。 |
| `Alt + S` / `Option + S` | **表紙に設定** | スタック内選択画像 | 選択した画像をそのスタックのメイン表紙（Hero）画像に指定。 |
| `C` | **2画面並列画像比較** | ギャラリー選択項目 | 同期ズーム＆パン対応の2画面分割比較ビューを開く。 |

## 4. ワークスペースパネルとズーム

| ショートカット | 操作 | 説明 |
| :--- | :--- | :--- |
| `B` | **サイドバーを表示/非表示** | 左側ナビゲーションパネル（ライブラリ、フォルダ、タグ）の開閉。 |
| `I` | **インスペクターを表示/非表示** | 右側プロパティインスペクターパネルの開閉。 |
| `/` または `Ctrl + F` / `Cmd + F` | **検索バーにフォーカス** | 検索入力欄をアクティブにし、入力済みの文字列を選択。 |
| `Ctrl + =` / `Cmd + =` | **拡大** | ギャラリーカードのサムネイル表示サイズを拡大。 |
| `Ctrl + -` / `Cmd + -` | **縮小** | ギャラリーカードのサムネイル表示サイズを縮小。 |
| `Ctrl + 0` / `Cmd + 0` | **ズームをリセット** | ギャラリーカードサイズを標準幅（256px）にリセット。 |
| `F11` | **全画面表示** | ボーダーレス全画面表示モードの切り替え。 |

## 5. ライブラリ操作とモーダル

| ショートカット | 操作 | 説明 |
| :--- | :--- | :--- |
| `Ctrl + O` / `Cmd + O` | **フォルダを追加** | フォルダ追加モードウィザードを開く。 |
| `Ctrl + E` / `Cmd + E` | **一括エクスポート** | 一括トランスコード・メタデータ消去・パッケージング画面を開く。 |
| `Ctrl + ,` / `Cmd + ,` | **環境設定** | アプリケーションの総合設定ウィンドウを開く。 |
| `?` または `Shift + /` | **ショートカット一覧** | ショートカットキー一覧ヘルプモーダルを開く。 |
| `Alt + F4` | **アプリを終了** | Omera を終了。 |

## 6. 選択修飾キーの挙動

- **通常のクリック**: 単一のカードを選択し、それを**選択アンカー**として設定。
- **Shift + クリック**: 直前の選択アンカーからクリックしたカードまでを**連続範囲選択**。
- **Ctrl + クリック**（macOS では `Cmd + クリック`）: 既存の選択状態を保持したまま、個別のカードの選択状態を**反転（トグル）**し、選択アンカーを更新。
- **スタック表紙のダブルクリック**: 誤った展開を防ぎつつ、表紙（Hero）画像を即座にライトボックス拡大表示。
- **スタック件数バッジのシングルクリック**: バーストスタックをインラインで展開／折りたたみ。
