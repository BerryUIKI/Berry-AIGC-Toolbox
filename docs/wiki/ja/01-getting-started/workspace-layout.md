# ワークスペース構成とUI構造

Omera は、高密度なビジュアルキュレーション、軽快なキーボード操作、集中を妨げないプレビュー環境を実現するため、**Eagle** や **Lightroom** に着想を得た3ペイン構成のデスクトップワークスペースを採用しています。

## 2. タイトルバーとネイティブアプリケーションメニュー

ウィンドウはフレームレス設計を採用しており、カスタムタイトルバー（`TitleBar.vue`）およびデスクトップメニューバー（`MenuBar.vue`）を備えています：

### メインメニュー機能一覧
- **ファイル (File)**:
  - `フォルダを追加...` (`Ctrl + O` / `Cmd + O`): ローカルまたはネットワークディレクトリを追加。
  - `現在のフォルダをスキャン`: アクティブなフォルダの新規・変更ファイルを再インデックス。
  - `すべてのフォルダを再スキャン`: 登録されているすべてのフォルダの増分スキャンを強制実行。
  - `データベース管理...`: データベースの最適化・圧縮（VACUUM）、サイズ指標、バックアップツールを開く。
  - `環境設定 / 設定...` (`Ctrl + ,` / `Cmd + ,`): 8つの設定タブを備えた環境設定ウィンドウを開く。
  - `終了` (`Alt + F4`): アプリケーションを安全に終了。
- **編集 (Edit)**:
  - `すべて選択` (`Ctrl + A` / `Cmd + A`): 現在のギャラリー表示内のすべてのアセットを選択。
  - `選択を解除` (`Esc`): ハイライト選択をすべて解除。
  - `タグを一括追加...`: 選択したファイルにタグを付与または削除。
  - `アルバムに一括追加...`: 選択したファイルをアルバムに登録。
  - `フォルダに一括移動...` / `フォルダに一括コピー...`: 登録フォルダ間でファイルを物理的に移動または複製。
  - `一括エクスポート...` (`Ctrl + E` / `Cmd + E`): エクスポート・変換・パッケージング画面を開く。
  - `ゴミ箱へ移動` (`Delete` / `Backspace`): 選択したファイルをOSのゴミ箱へ安全に移動。
- **表示 (View)**:
  - `グリッド表示`: 正方形の均等配置グリッドに切り替え。
  - `ウォーターフォール（元の縦横比）`: 画像のアスペクト比を維持した Masonry 表示に切り替え。
  - `リスト表示`: 表形式の詳細リストモードに切り替え。
  - `サイドバーを表示/非表示` (`B`): 左側ナビゲーションパネルの表示切り替え。
  - `インスペクターを表示/非表示` (`I`): 右側メタデータパネルの表示切り替え。
  - `クイックルック (ライトボックス)` (`Space` / `Enter`): フルスクリーンの拡大プレビューモーダルを開く。
  - `拡大` (`Ctrl + =`), `縮小` (`Ctrl + -`), `ズームをリセット` (`Ctrl + 0`)。
- **ツール (Tools)**:
  - `プロンプト統計...`: キーワードの出現頻度分布や評価との相関を視覚的に分析。
  - `モデル管理...`: チェックポイントのハッシュを分かりやすいモデル名に解決・カタログ化。
  - `CLIPセマンティック検索インデックス...`: 自然言語検索用の特徴量ベクトルインデックスを作成。
  - `LoRA トリガーワードライブラリ`: トリガーワードと `.civitai.info` ファイルを一元管理。
  - `自動タグ付け (WD14)`: ローカル Danbooru アニメ／審美タグ推定ツールを開く。
  - `プロンプトでライブラリを整理`: 類似プロンプトを自動スキャンしてスタック化。
- **ヘルプ (Help)**:
  - `言語`: 7種類の対応言語を瞬時に切り替え。
  - `ショートカット一覧` (`?`): アプリ内ショートカット早見表を表示。
  - `アップデートを確認...`: GitHub Releases を確認して最新バージョンを取得。
  - `Omera について`: バージョン、作者、ライセンス情報を表示。

## 3. 左ナビゲーションサイドバー (`Sidebar.vue`)

左サイドバー（`B` キーで開閉）から各種メディアコレクションに素早くアクセスできます：

1. **システムライブラリ**:
   - **すべての画像**: 登録された全フォルダを横断した総ライブラリ表示（件数バッジ付き）。
   - **お気に入り (★)**: 星マーク・ブックマークを付けた画像のクイックフィルター。
   - **センシティブ (18+) (🔞)**: NSFW フラグが設定されたコンテンツ一覧（デフォルトではぼかし表示）。
2. **フォルダセクション**:
   - 登録されたすべてのフォルダが動作モードアイコンとともに一覧表示されます：
     - `⚡`: AIGC 取り込みパイプライン（生成ツールの出力先を自動監視）。
     - `📦`: 管理プロジェクト保管庫（アプリ内で整理・管理される保管庫）。
     - `📁`: 外部リンク（ファイルを移動しないインプレースゼロコピー監視）。
   - 右クリックまたはホバー操作で、**新規画像の取り込み**、**フォルダをスキャン**、**メタデータの再構築**、**フォルダの削除** が可能です。
   - ドラッグ＆ドロップターゲットに対応：ギャラリーカードをフォルダへドラッグして移動・コピーできます。
3. **アルバムセクション**:
   - ユーザー定義のコレクション。ギャラリーカードをアルバムにドラッグして追加。
   - 「+ 新規」ボタンから素早く作成可能。
4. **タグセクション**:
   - 8色のカラーバッジで視覚化されたタグ分類。
   - ギャラリーの画像をタグへドラッグして一括付与できます。
5. **クイックツールフッター**:
   - プロンプト分析、モデル管理、データベース管理、ショートカット一覧をワンクリックで起動できるショートカットボタン群。

## 4. 中央ギャラリーキャンバス＆検索ツールバー

アセットの閲覧、選択、キュレーションを行うメインの作業領域です：

- **検索バー (`SearchBar.vue`)**:
  - **構文検索モード (`🔍`)**: キーワードや構造化クエリ構文（例: `prompt:"cyberpunk" cfg:>7`）でメタデータを検索。
  - **セマンティック検索モード (`🧠`)**: ローカル CLIP / SigLIP モデルによる自然言語テキスト検索。
- **表示モード切り替え**:
  - **グリッド (⊞)**、**ウォーターフォール (▤)**、**リスト (☰)** レイアウトの切り替え。
  - **ズームスライダー**: カードの最小幅を **130px** 〜 **360px** の範囲でスムーズに調整。画像の縦横比を歪めることなく、レスポンシブに列数が再計算されます。
- **フィルタードロワー切り替え (`FilterDrawer.vue`)**:
  - スライドアウト式のフィルターパネルを開き、チェックポイントモデル、サンプラー、アスペクト比、星評価、動画パラメータなどの複合条件で絞り込みます。

## 5. 右プロパティインスペクター (`InspectorPane.vue`)

右インスペクター（`I` キーで開閉）は、選択中の画像から抽出された可逆 AIGC メタデータを詳細に表示します：

- **メディアプレビュー**: 高解像度サムネイル、NSFWぼかし解除トグル、クイックルック起動。
- **キュレーション操作**: 星評価（0〜5星）、お気に入り登録（`F`）、センシティブ設定。
- **ポジティブプロンプト**: トークン分割されたプロンプト表示。各プロンプト単語がインタラクティブなチップとして描画されます：
  - チップをクリックすると、ライブラリ全体からそのトークンを瞬時に検索。
  - コピーボタンをクリックして、ポジティブプロンプト全文をクリップボードにコピー。
- **ネガティブプロンプト**: ネガティブプロンプトの全文表示（1クリックコピー対応）。
- **生成パラメータ**:
  - モデル名およびチェックポイントの SHA256 ハッシュ。
  - サンプラーおよびスケジューラーアルゴリズム。
  - ステップ数、CFGスケール、シード値（シード値コピー機能付き）。
  - 元画像の生成解像度（幅 × 高さ）。
- **検出された LoRA**:
  - 画像から検出された `<lora:name:weight>` や ComfyUI の LoRA ローダーノードを一覧表示。
  - トリガーワード、適用ウェイトの表示、プロンプト用構文の1クリックコピー。
- **生成環境連携カード**:
  - ローカルの **ComfyUI** および **AUTOMATIC1111** とのリアルタイム接続状態を表示。
  - 「ComfyUI に送信」（ワークフローグラフを直接再キューイング）または「SD WebUI に送信」。
- **生メタデータアコーディオン**: 未加工の生 JSON パラメータブロックや ComfyUI ノードグラフ全体を直接閲覧。

## 6. 下部ステータスバー＆バックグラウンド監視

ウィンドウの最下部に常駐するステータスバー：
- **該当 / 総件数カウンタ**: フィルターに一致した表示件数とライブラリ総数を表示（例: `該当: 420 / 12,500 項目`）。
- **選択件数**: アイテム選択時に選択数を表示（例: `選択中: 5 件`）。
- **データベースステータス**: 使用中のデータベースファイル名とスキーマバージョンを表示。
- **バックグラウンド監視ポップオーバー (`⚡ バックグラウンド`)**:
  - ファイルシステム監視の稼働状態（アクティブルート、ジャーナルバックログ、エラー状態）やバックグラウンドサムネイル生成キューの進捗をリアルタイム表示。

## 7. フローティング一括アクションバー (`BatchActionBar.vue`)

1枚以上の画像を選択すると、キャンバス下部中央にフローティングツールバーがスライド表示されます：

- 複数選択カウンタ（`X / Y 件選択中`）および「すべて選択」「選択解除」ボタン。
- 一括星評価ドロップダウン（0〜5星）。
- 「アルバムに追加」「タグを追加」モーダル呼び出し。
- 「自動タグ (WD14)」一括タグ付け実行。
- 「お気に入り」一括切り替え。
- 「パスをコピー」「プロンプトをコピー」クリップボード操作。
- 「移動」「コピー」フォルダ選択ダイアログ。
- 「低評価の下書きを整理 (Cull Drafts)」（スタック選択時に有効化）。
- 「一括エクスポート...」（一括フォーマット変換、メタデータ消去、HTMLショーケース生成）。
- 「ゴミ箱へ移動」（選択したファイルをOSのゴミ箱へ安全に移動）。
