# ギャラリー表示モードと表示オプション

Omera は、高速なビジュアル選別から詳細な技術的検証まで、さまざまなキュレーション作業に合わせて設計された4つの専用ギャラリー表示モードを提供します。

---

## 1. ギャラリー表示モード

上部ツールバーのボタンまたはメニューのショートカット（`表示`）を使用して、表示モードを切り替えることができます：

### 1. グリッド表示 (`grid` — ⊞)
- **コンセプト**: 一定のアスペクト比を持つカードが、ウィンドウ幅に応じたレスポンシブな列数で均等に配置される標準モード。
- **レスポンシブ構造**: ウィンドウサイズを変更しても、画像を無理に引き伸ばしたり押し縮めたりせず、列数を動的に再計算（`calculateGalleryColumns`）してカード幅の安定性を保ちます。
- **ズームスライダー**: ズームスライダーをドラッグするか `Ctrl + =` / `Ctrl + -` を押すことで、カードの最小幅を **130 px**（俯瞰サムネイルモード）から **360 px**（大判ディテールモード）までスムーズに調整できます。
- **DOM 仮想化**: 現在画面のビューポート内にある要素（および先読み用の小さなオーバースキャンバッファ）のみを DOM に描画します。10万枚のライブラリをスクロールしても、100枚をスクロールする場合と同等の軽量なメモリ消費量を維持します。

### 2. ウォーターフォール表示 (`masonry` — ▤)
- **コンセプト**: 各画像の本来のアスペクト比を維持したまま並べるフルイドマルチカラム（Masonry）レイアウト。
- **トリミングなしの表示**: 横長の風景壁紙、縦長のキャラクター立ち絵（9:16）、パノラマ環境アートなどが混在するコレクションに最適です。端がトリミングされることなく、`object-fit: contain` により元の構図のまま美しく縮小表示されます。
- **最短列への優先配置**: 新しいアイテムは常に現在の全列の中で最も高さが低い列に配置されるため、全体の高低差が均等に保たれ、美しいビジュアルウォールが形成されます。

### 3. 詳細リスト表示 (`table` — ☰)
- **コンセプト**: 1行あたり 46px の固定高を持つ、仮想化されたスプレッドシート形式のレイアウト。
- **高い情報密度**: マイクロサムネイル（36px）とともに、詳細な表形式の列データを一覧表示します：
  - チェックボックス選択状態
  - ファイル名および相対ディレクトリパス
  - メディアコンテナ形式 (`PNG`, `WEBP`, `MP4`)
  - 解像度 (`幅 × 高さ`)
  - ファイルサイズ (KB/MB 形式)
  - 更新日時タイムスタンプ
  - 星評価 (0〜5星 / 1〜10)
  - 審美予測スコア (Aesthetic Score)

### 4. 類似画像検索マッチビュー
- **起動方法**: 右側インスペクターまたは任意の画像のコンテキストメニューから **「類似画像を検索」** をクリックします。
- **上部マッチバナー**: 基準となる元画像、類似度しきい値スライダー（**0%〜95%**、5%刻み）、件数上限セレクター（**20、50、100、200** 件）が表示されます。
- **類似度パーセントバッジ**: 一致した各カード上に、CLIP ベクトルのコサイン距離から算出された類似度スコアバッジ（例: `94% 類似`）がカラー表示されます。
- **終了方法**: `Esc` キーを押すか、バナーの閉じるボタン（`✕`）をクリックすると、通常のギャラリー表示に戻ります。

## 2. カードバッジとビジュアルオーバーレイ

**環境設定 > ギャラリー（表示と安全保護）** で、**カードバッジを表示** のオン／オフを切り替えることができます。有効にすると、カード上に以下の情報チップが表示されます：

- **フォーマット / コンテナバッジ**: `.png`, `.webp`, `.jpg`, `.mp4`, `.webm` などの拡張子を表示。
- **解像度バッジ**: ネイティブのピクセル解像度（例: `1024×1024`、`832×1216`）。
- **動画の長さ＆フレームレート**: アニメーションや動画の場合、再生時間（例: `00:04`）とフレームレート（`24 fps`）を表示。
- **生成ツールバッジ**: メタデータから検出された生成ツールのシグネチャ（例: `WebUI`, `ComfyUI`, `NovelAI`, `Fooocus`）。
- **星評価オーバーレイ**: 設定されている星評価（★ 1〜5）。
- **お気に入りフラグ**: ブックマークされた画像の右上にゴールドの星アイコンを表示。

## 3. センシティブ画像 (NSFW) のプライバシーぼかし

プレゼンテーション中や公共の場での作業時にプライバシーを保護するため、Omera は強力なコンテンツ保護機能を備えています：

- **自動ぼかし (`blur_nsfw` 設定)**: `is_nsfw` フラグが設定されているアセットや、成人向けレーティングが付与された画像は、強力な CSS ぼかしフィルターで自動的に覆われます。
- **クリックでぼかし解除**: 目のアイコン（`👁`）またはカードをクリックすると、その画像のみ一時的にぼかしが解除され、確認できます。
- **グローバルセンシティブセクション**: 左サイドバーに **センシティブ (18+) (🔞)** ライブラリが常設されており、フラグ付きコンテンツをまとめて確認・再分類できます。
