# 整理・評価・タグ管理

Omera は、ファイルシステムを散らかすことなく、数万枚規模の作品群を素早く並び替え、分類し、優先順位を付けるための多彩なキュレーション機能を提供します。

---

## 1. 星評価とスコアリングシステム

Omera は SQLite に直接格納される高精度な評価モデル（`files.rating` および `files.aesthetic_score`）を採用しています：

### 星評価（0〜5星 / 1〜10段階評価）
- **キーボードショートカット**: 1枚または複数枚の画像を選択してキーを押します：
  - `1` 〜 `5`: その星評価を即座に設定。
  - `0`: 星評価をクリア。
- **インスペクター／一括アクションバー**: ドロップダウンから10段階評価（例: 8/10、9/10）の詳細設定にも対応しています。
- **データベースインデックス**: `rating` カラムには SQLite B-tree インデックスが設定されており、50万枚のライブラリでも `rating:>=4` や `rating:5` などの条件検索がミリ秒未満で実行されます。

### お気に入り (★ ブックマーク)
- **切り替え**: `F` キーを押すか、インスペクター内の星アイコンをクリック。
- **視覚表示**: カードの右上にゴールドの星バッジが表示されます。
- **サイドバーアクセス**: お気に入り登録されたすべての画像は、左側ナビゲーションサイドバーの **お気に入り (★)** から瞬時に閲覧できます。

## 2. カスタムアルバム (`AlbumModal.vue`)

アルバムを使用すると、物理ファイルをディスク上で移動させることなく、異なるフォルダにまたがる関連作品を柔軟にグループ化できます。

### アルバムの作成と管理
1. 左サイドバーの **アルバム** セクションにある **「+ 新規」** をクリックします。
2. アルバム名（例: `"サイバーパンク・キャラクター"`, `"2026年ポートフォリオ"`）と任意の説明を入力します。
3. サイドバーでアルバムを右クリックすると、いつでも名前変更や削除が可能です。アルバムを削除しても、グループ化の関連付けが解除されるだけで、ディスク上の物理ファイルが削除されることはありません。

### アルバムへのアセット追加
- **ドラッグ＆ドロップ**: ギャラリーから1枚または複数枚のカードを選択し、左サイドバーのアルバムへ直接ドラッグします。
- **一括アクションバー**: 画面下部のフローティングツールバーで **「アルバム」** をクリックします。
- **右インスペクター**: インスペクターパネルから直接アルバムを検索して追加・紐付けできます。

## 3. カラータグ分類体系 (`TagModal.vue`)

タグを使用することで、きめ細かな分類や視覚的な選別（トリアージ）が可能になります：

### プリセットカラーバッジ
Omera には8種類の視覚的なカラープリセットが用意されています：
- 🔴 レッド (Red)
- 🟠 オレンジ (Orange)
- 🟡 イエロー (Yellow)
- 🟢 グリーン (Green)
- 🔵 ブルー (Blue)
- 🟣 パープル (Purple)
- 🌸 ピンク (Pink)
- ⚪ スレート / グレー (Slate)

### タグの操作
- **タグの新規作成**: サイドバーの **「+ 新規」** をクリックし、カラーを選択してタグ名（例: `メインキャラ`, `下書き`, `クライアント承認済`）を入力します。
- **ドラッグしてタグ付け**: キャンバスから選択したカードを左サイドバーのタグチップへ直接ドラッグして付与します。
- **タグによる絞り込み**: サイドバーのタグをクリックすると、そのタグが付いた画像のみがギャラリーに表示されます。
- **複数タグの付与**: 1枚の作品に対して無制限にタグを付与できます。

## 4. フローティング一括アクションバー (`BatchActionBar.vue`)

複数枚の画像を選択すると（`Ctrl+クリック`、`Shift+クリック`、または `Ctrl+A`）、画面下部に **一括アクションバー** がスライド表示されます：

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  [✓ 14 / 120 件選択中]  [すべて選択]  [選択解除]                                         │
│  [★ 評価 ▾]  [🏷 タグ]  [📁 アルバム]  [🧠 自動タグ]  [★ お気に入り]  [🔞 センシティブ]   │
│  [📋 パスをコピー]  [💬 プロンプトをコピー]  [📂 移動]  [📄 コピー]  [🧹 下書き整理]      │
│  [📤 エクスポート]  [🗑 ゴミ箱へ移動]                                                  │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### 主要な一括操作機能：
- **評価を設定**: 選択したすべての画像に統一した星評価を適用。
- **タグ／アルバム**: モーダルを開き、タグやアルバムの一括追加・解除を実行。
- **プロンプトをコピー**: 選択した全画像のポジティブプロンプトを `---` 区切りでクリップボードに一括コピー。
- **パスをコピー**: コマンドラインやスクリプトへ貼り付け可能な絶対ファイルパス（1行1ファイル）をコピー。
- **移動＆コピー**: Omera に登録されている別のフォルダへ物理ファイルを移動または複製。
- **低評価の下書きを整理**: 選択範囲にバーストスタックが含まれている場合に有効化（詳細は [スタックとバースト](../04-intelligent-curation/stacks-and-bursts.md) を参照）。
- **ゴミ箱へ移動**: 選択したすべてのファイルを OS のゴミ箱へ安全に移動。
