# 動画・モーションメディア対応

AI 生成技術が画像から動画領域（AnimateDiff、SVD、Wan2.1、HunyuanVideo、CogVideoX、LTX-Video など）へと急速に拡大する中、Omera は **MP4** および **WebM** 形式のアニメーションや動画作品をネイティブかつファーストクラスでサポートしています。

---

## 1. 対応動画フォーマットとコンテナ構造

Omera は、Rust ネイティブのメタデータパーサー（`omera-metadata`）を通じて動画コンテナを直接解析します：

- **MP4 (`.mp4`)**: ISOBMFF ボックス構造（`ftyp`, `moov`, `trak`, `mdia`, `minf`, `stbl`）を解析。
  - 動画解像度（幅 × 高さ）、フレームレート（FPS）、再生時間、動画コーデック（`H.264`, `H.265 / HEVC`, `AV1`）を自動抽出。
  - `moov/udta` ボックスを走査し、埋め込まれた ComfyUI 実行グラフや生成パラメータを取得。
- **WebM (`.webm`)**: VP8、VP9、AV1 ビデオストリームを含む EBML コンテナ形式を解析し、再生時間やフレーム解像度をストリームヘッダーから直接取得。

---

## 2. ギャラリー動画カードと動的プレビュー

ギャラリーキャンバス上では、動画ファイルは静止画像と明確に区別して表示されます：

- **再生時間バッジ**: カードの隅に正確な再生時間を表示（例: `00:05`、`01:24`）。
- **フレームレート＆フォーマットバッジ**: `MP4 · 24fps` や `WEBP · 30fps` などを表示。
- **サムネイル生成**:
  - 一般的な画像処理ライブラリでは動画の直接デコードが難しいため、Omera のフロントエンド WebView がオフスクリーンの HTML5 `<video>` キャンバスから最初のキーフレームを自動キャプチャして base64 化し、Rust バックエンドが `save_video_thumbnail` 経由で最適化された WebP サムネイルとしてキャッシュします。
- **ホバープレビュー**: 動画カードにマウスカーソルを合わせると、全画面ビューを開くことなくキャンバス上で軽量なプレビュー再生が開始されます。

## 3. ライトボックス動画プレーヤー (`LightboxModal.vue`)

動画カード上で `Space` または `Enter` キーを押すと、フルスクリーンの **クイックルック・ライトボックスプレーヤー** が起動します：

```
┌────────────────────────────────────────────────────────────────────────┐
│ [✕]                                                          [★ お気に入り]
│                                                                        │
│                       [ 動画再生キャンバス ]                             │
│                                                                        │
│                                                                        │
│ ┌────────────────────────────────────────────────────────────────────┐ │
│ │ [▶ / ⏸] [⏪ コマ戻し] [コマ送り ⏩] [00:03 / 00:08] ──●── [1.0x ▾] [🔁] [🔊]│ │
│ └────────────────────────────────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────────────────────────────────┐ │
│ │ フィルムストリップ: [縮小版] [縮小版] [● 再生中の動画] [縮小版] [縮小版]   │ │
│ └────────────────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────────────┘
```

### ライトボックス動画操作コントロール：
1. **再生 / 一時停止**: キャンバスをクリック、または `Space` キーを押す。
2. **1フレーム単位のコマ送り／コマ戻し**: `←` または `→` キー（あるいは HUD のボタン）を押して、動きの細部をフレーム単位で詳細に検証。
3. **再生速度の変更**: 速度セレクターで **0.25x**、**0.5x**、**1.0x**、**1.5x**、**2.0x** から選択。
4. **ループ再生＆音声**: ループ再生のオン／オフ（`🔁`）および音量調整／ミュート切り替え（`🔊`）。
5. **フィルムストリップ操作**: 下部のサムネイルフィルムストリップから、前後の静止画像や動画へスムーズに切り替え。

## 4. ComfyUI モーション＆動画ワークフローの解析

動画生成では、複数のステップを組み合わせた複雑な ComfyUI ワークフロー（例: テキストプロンプト → 初期潜在画像 → AnimateDiff モーションモジュール → ControlNet OpenPose 誘導 → 空間アップスケーラー）が頻繁に使用されます。

ComfyUI で生成された動画ファイルを Omera で閲覧した場合：
- **プロパティインスペクター** が、モーションモデルに使用されたポジティブ／ネガティブテキストプロンプトを抽出して表示します。
- **生メタデータアコーディオン** で、モデルチェックポイント、モーション LoRA、コンテキストウィンドウ長、オーバーラップフレーム数、VAE デコード設定を含む完全なノード実行グラフを確認できます。
- **「ComfyUI に送信」** をワンクリックするだけで、動画を生成したワークフロー全体を実行中の ComfyUI にそのまま読み込み、再レンダリングや調整を行うことができます。
