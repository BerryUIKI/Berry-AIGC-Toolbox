# AIGC メタデータとプロンプトインスペクション

Omera は、Rust で記述された高精度・可逆なマルチエンジンメタデータパーサー（`omera-metadata`）を搭載しています。主要な各種 AI 画像生成ツールから、プロンプト、ネガティブプロンプト、モデル情報、シード値、実行グラフを自動抽出します。

---

## 1. 対応する AI 生成ツールとプラットフォーム

Omera は、PNG チャンク、WebP EXIF ヘッダー、MP4 ISOBMFF ボックスに埋め込まれたメタデータをネイティブに解析します：

| 生成ツール / プラットフォーム | 抽出されるメタデータ項目 | 格納コンテナと場所 |
| :--- | :--- | :--- |
| **AUTOMATIC1111 / SD.Next / Forge** | プロンプト、ネガティブプロンプト、ステップ数、サンプラー、CFG、シード値、画像サイズ、モデルハッシュ、モデル名、Denoising強度、Hiresアップスケール情報 | PNG `parameters` チャンク / JPEG EXIF `UserComment` |
| **ComfyUI** | 完全なノード実行グラフ、ポジティブ/ネガティブ CLIP テキストエンコード、KSampler シード値、ステップ数、CFG、チェックポイントローダー、LoRA ローダー、Latent アップスケールノード | PNG `prompt` & `workflow` チャンク / WebP ComfyUI チャンク / MP4 `moov/udta` |
| **NovelAI** | タイトル、説明、プロンプト、ネガティブプロンプト、シード値、サンプラー、ステップ数、スケール、ソフトウェアバージョン | PNG `Comment` & `Description` チャンク |
| **Fooocus / Fooocus-MRE** | ベースモデル、リファイナー、LoRA ウェイト、シャープネス、パフォーマンスモード、解像度、プロンプト | PNG `parameters` テキストブロック |
| **InvokeAI** | モデル名、VAE、スケジューラー、生成モード (txt2img/img2img)、シームレスタイル設定 | PNG `sd-metadata` & `invokeai_metadata` JSON |
| **EasyDiffusion / Stable Swarm** | フォーマット済み JSON パラメータブロック、シード値、モデル名 | PNG `sui_image_params` / サイドカーファイル |

## 3. インタラクティブなプロンプトトークンチップ

Omera は、長いプロンプト文字列を単なるプレーンテキストの羅列としてではなく、トークンごとに分割された対話型チップとして描画します：

- **1クリック検索**: 任意のトークンチップ（例: `[cyberpunk city]`）をクリックすると、ライブラリ全体の全作品を対象にその単語を含む画像が即座に検索されます。
- **1クリックコピー**: プロンプト欄の右上にあるコピーアイコンをクリックすると、エスケープされていないクリーンなプロンプト全文がクリップボードにコピーされます。
- **タグの発見と再利用**: トークンチップ化されているため、アーティストのスタイル、照明キーワード、クオリティ向上タグなどを直感的に見つけ出し、制作に再利用できます。

## 4. チェックポイントモデルとハッシュの自動解決

AI 生成ツールは、人間が読めるモデルファイル名ではなく、短縮モデルハッシュ（例: `31e35c80`）や完全な SHA256 ハッシュのみを画像に埋め込むことがよくあります。

- Omera はローカルの **モデルキャッシュ**（SQLite の `model_cache` テーブル）を自動照会し、暗号のようなハッシュを `"Animagine XL 3.1"` のような分かりやすいモデル名に自動変換して表示します。
- 未知のハッシュに遭遇した場合は、AUTOMATIC1111 の `cache.json` ファイルをインポートするか、Civitai から直接オンライン逆引き検索を行うことができます（詳細は [モデルとLoRAライブラリ](../04-intelligent-curation/models-and-loras.md) を参照）。

## 5. 生メタデータと ComfyUI ワークフロー JSON

ノードの接続構造やパラメータを詳細に検証したい上級ユーザーやテクニカルディレクター向け：
- インスペクター下部の **生メタデータ** アコーディオンを展開すると、未加工の完全な JSON ペイロードを閲覧できます。
- ワークフロー JSON ブロック全体をワンクリックでコピーし、外部のテキストエディタに貼り付けたりチームメンバーと共有したりすることが可能です。
