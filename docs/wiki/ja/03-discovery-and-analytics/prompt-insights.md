# プロンプト分析とインサイト

作品コレクションが数千、数万枚へと拡大するにつれ、どのプロンプトキーワード、アーティスト名、技術パラメータが高評価作品を生み出しているのかを客観的に把握することが重要になります。Omera は、ライブラリ全体のメタデータを集計・可視化する専用の分析モーダル（`PromptStatsModal.vue`）を備えています。

---

## 1. プロンプト分析の起動方法

分析ダッシュボードを開くには：
- 上部メニューバーの **ツール > プロンプト統計...** をクリックするか、
- 左側ナビゲーションサイドバー下部のクイックツールの **「分析」** ボタンをクリックします。

---

## 2. 分析タブとビジュアル指標

```
┌────────────────────────────────────────────────────────────────────────┐
│ プロンプト＆メタデータ分析                                         [✕] │
├────────────────────────────────────────────────────────────────────────┤
│ [ 高頻度ポジティブワード ] [ 高頻度ネガティブワード ] [ 使用モデル ] [ サンプラー ] │
├────────────────────────────────────────────────────────────────────────┤
│ 並び替え: (●) 出現頻度順    ( ) 平均評価順                             │
├────────────────────────────────────────────────────────────────────────┤
│ 順位 │ トークン / キーワード        │ 出現回数    │ 平均評価   │ 操作  │
├──────┼──────────────────────────────┼─────────────┼────────────┼───────┤
│ #1   │ masterpiece                  │ 4,120 回    │ ★ 4.2      │ [🔍]  │
│ #2   │ cinematic lighting           │ 2,845 回    │ ★ 4.7      │ [🔍]  │
│ #3   │ 1girl                        │ 2,410 回    │ ★ 3.9      │ [🔍]  │
│ #4   │ cyberpunk city               │ 1,890 回    │ ★ 4.8      │ [🔍]  │
│ #5   │ volumetric fog               │ 1,230 回    │ ★ 4.5      │ [🔍]  │
│ #6   │ photorealistic               │ 1,115 回    │ ★ 3.2      │ [🔍]  │
└────────────────────────────────────────────────────────────────────────┘
```

ダッシュボードには4つの分析タブが用意されています：

### 1. 高頻度ポジティブワード (Positive Tokens)
- すべてのポジティブプロンプト内の個別トークンチップを集計・評価します。
- 単語の総出現回数と、その単語を含む画像の **平均星評価** を並べて表示します。
- 星4つや星5つの高評価作品に頻繁に関与している「成功の秘訣」キーワードをひと目で発見できます。

### 2. 高頻度ネガティブワード (Negative Tokens)
- ワークフロー全体で最も頻繁に使用されているネガティブプロンプトのフレーズを分析します。
- 肥大化して出力品質に寄与していない冗長なネガティブ埋め込みや無駄なキーワードを特定するのに役立ちます。

### 3. 使用モデルランキング (Top Models)
- ライブラリ内で使用されている全チェックポイントモデルを、総生成枚数およびユーザー平均評価でランキング表示します。
- どのファインチューニングモデルが最も優れた成果を出しているかを客観的に比較できます。

### 4. 使用サンプラーランキング (Samplers & Schedulers)
- サンプリングアルゴリズム（例: `DPM++ 2M Karras`、`Euler a`、`UniPC` など）を頻度と審美評価でランク付けします。

---

## 3. 検索機能とのシームレスな連動

分析テーブルの各キーワード行には、**操作（`🔍`）** ボタンが用意されています：
- 検索アイコンをクリックすると、分析モーダルが自動的に閉じ、選択したトークンがメインギャラリー検索バーに `prompt:"..."` として即座に入力され、そのキーワードを含む作品一覧へジャンプします。
- これにより、マクロな統計分析からミクロな個別画像の確認・キュレーションへ、一切の手間なくスムーズに移行できます。
