# 検索構文とビジュアルフィルター

Omera は、正確な技術パラメータ絞り込みを行う **構造化構文検索** と、自然言語による感覚的な検索を可能にする **AI セマンティック検索** のデュアル検索エンジンを備えています。

---

## 1. 構文検索とクエリ文法

上部検索バー（`/` または `Ctrl + F`）では、自由なキーワード入力とキー・バリュー形式の構造化クエリをシームレスに組み合わせて検索できます：

### 基本フリーテキスト検索
- 接頭辞なしで単語を入力すると、ファイル名、相対パス、ポジティブプロンプト、ネガティブプロンプト、モデル名を横断して部分一致検索します：
  ```
  cyberpunk neon rain
  ```
- 完全一致フレーズを検索する場合は二重引用符を使用します：
  ```
  "cyberpunk street" "rainy reflections"
  ```

---

## 2. キー・バリュー構文リファレンス

Omera は検索トークンを Rust ネイティブで解析して構造化された `SearchCriteria` を生成し、SQLite インデックスを活用してミリ秒未満で結果を返します：

| トークンキー | 構文例 | 説明 |
| :--- | :--- | :--- |
| `prompt:` | `prompt:"masterpiece, 1girl"` | ポジティブプロンプト内の単語に一致。 |
| `neg:` | `neg:"bad hands, blurry"` | ネガティブプロンプト内の単語に一致。 |
| `model:` | `model:"animagine_xl"` | モデルチェックポイント名で絞り込み。 |
| `hash:` | `hash:31e35c80` | 短縮ハッシュまたは完全な SHA256 モデルハッシュに一致。 |
| `sampler:` | `sampler:"Euler a"` | サンプラーアルゴリズムで絞り込み。 |
| `steps:` | `steps:30`, `steps:20..40`, `steps:>=25` | ステップ数の完全一致または数値範囲。 |
| `cfg:` | `cfg:7`, `cfg:>=7.5`, `cfg:5..10` | CFG スケール値または数値範囲。 |
| `seed:` | `seed:12345678` | 特定の生成シード値を検索。 |
| `rating:` | `rating:5`, `rating:>=4`, `rating:1..3` | ユーザーの星評価で絞り込み。 |
| `aesthetic:`| `aesthetic:>=7.0` | 審美予測スコア（Aesthetic Score）で絞り込み。 |
| `fav:` | `fav:true`, `fav:false` | お気に入り（ブックマーク）状態で絞り込み。 |
| `is:` | `is:nsfw`, `is:sfw` | センシティブ（NSFW）フラグで絞り込み。 |
| `type:` | `type:image`, `type:video` | メディアコンテナ種別（画像／動画）で絞り込み。 |
| `duration:` | `duration:>=5`, `duration:5..30` | 動画の再生時間（秒）で絞り込み。 |
| `fps:` | `fps:>=30`, `fps:24..60` | 動画のフレームレート（FPS）で絞り込み。 |

### 数値範囲の構文
- **範囲指定 (`min..max`)**: `steps:20..35`（20〜35ステップの範囲）。
- **以上 (`>=`)**: `cfg:>=7.0`（CFGスケール 7.0 以上）。
- **以下 (`<=`)**: `rating:<=2`（星2つ以下）。
- **完全一致**: `rating:5`（星5つのみ）。

## 3. ビジュアルフィルタードロワー (`FilterDrawer.vue`)

構文を手入力する代わりに GUI で直感的に絞り込みたい場合は、検索バー右側の **フィルタードロワーボタン（`☰ フィルター`）** をクリックしてスライドパネルを開きます：

```
┌────────────────────────────────────────────────────────┐
│ ビジュアル検索＆フィルター             [すべてリセット] [✕] │
├────────────────────────────────────────────────────────┤
│ モデル チェックポイント                                  │
│ [ すべてのモデル ▾                                    ] │
│                                                        │
│ サンプラー                                              │
│ [ すべてのサンプラー ▾                                ] │
│                                                        │
│ 星評価                                                  │
│ [ ★★★★★ (星5つのみ) ▾                                 ] │
│                                                        │
│ ステップ数範囲                                          │
│ 最小: [ 20 ] ─────────────●──────────── 最大: [ 50 ]   │
│                                                        │
│ CFGスケール範囲                                         │
│ 最小: [ 5.0 ] ────────────●──────────── 最大: [ 12.0 ] │
│                                                        │
│ メディア種別                                            │
│ (●) すべて    ( ) 画像のみ    ( ) 動画のみ               │
│                                                        │
│ フラグ条件                                              │
│ [✓] お気に入りのみ    [ ] センシティブ (NSFW) のみ       │
└────────────────────────────────────────────────────────┘
```

フィルタードロワーにはアクティブなフィルター項目数がバッジ表示され、現在いくつの条件で絞り込まれているかをひと目で把握できます。

## 4. ギャラリーの並び替えオプション (`SortBar.vue`)

ギャラリーキャンバス上部の右端で、現在の検索結果の並び順を変更できます：

### 並び替え項目：
- **更新日時 (`modified_at`)**: ファイルのタイムスタンプに基づく時系列順。
- **ファイル名 / パス (`path`)**: ファイルシステムパスのアルファベット順。
- **ファイルサイズ (`size_bytes`)**: ファイルのデータサイズ順。
- **星評価 (`rating`)**: 付けられた星評価順。
- **審美スコア (`aesthetic_score`)**: ニューラル審美予測スコア順。

### 並び替え方向：
- 方向ボタンをクリックして、**降順 (`↓`)**（最新／最大／最高評価が先頭）と **昇順 (`↑`)**（最古／最小／最低評価が先頭）を切り替えます。
