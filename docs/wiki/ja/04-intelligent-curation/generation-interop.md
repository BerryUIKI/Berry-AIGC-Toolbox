# 生成環境との連携

Omera はクリエイティブな制作ツールの心強いコンパニオンとして機能し、**ComfyUI** や **AUTOMATIC1111 / SD.Next** との双方向 API 連携を提供します。

---

## 1. 生成サービスの接続設定

接続先エンドポイントは **環境設定 > 生成環境連携** で設定できます：

- **ComfyUI ベース URL**: デフォルト `http://127.0.0.1:8188`
- **SD WebUI ベース URL**: デフォルト `http://127.0.0.1:7860`

各設定項目には **「接続テスト」** ボタンが用意されています。Omera は軽量なヘルスチェック ping（ComfyUI は `/system_stats`、WebUI は `/sdapi/v1/options`）を送信し、接続状態を **オンライン (🟢)** または **オフライン (🔴)** バッジで即座に表示します。

---

## 2. ComfyUI ワークフローの直接送信 (`send_to_comfyui`)

ComfyUI で生成された画像や動画を閲覧している際：
1. 右側のプロパティインスペクターにある **生成環境連携カード** を確認します。
2. **「ComfyUI に送信」** をクリックします。
3. Omera のバックエンドが ComfyUI の `/prompt` HTTP エンドポイントに接続し、画像から抽出された正確なノードグラフと潜在パラメータを送信します。
4. 実行中の ComfyUI インスタンスがそのワークフローを即座に読み込み、生成キューに追加します。ウィンドウ間でファイルをドラッグ＆ドロップする必要はありません。

---

## 3. SD WebUI へのパラメータ送信 (`send_to_webui`)

AUTOMATIC1111、Forge、SD.Next で生成された画像の場合：
1. インスペクター内の **「SD WebUI に送信」** をクリックします。
2. Omera はポジティブプロンプト、ネガティブプロンプト、ステップ数、サンプラー、CFGスケール、シード値、解像度を含む txt2img 生成ペイロードを構築します。
3. ペイロードが WebUI の `/sdapi/v1/txt2img` API に送信され、WebUI の入力欄に自動反映されるか、新規生成キューが開始されます。

---

## 4. リアルタイム・パイプライン連携ループ

**生成環境連携** と **AIGC 取り込みパイプラインフォルダ**（モードC）を組み合わせることで、極めてスムーズな制作サイクルが実現します：
1. Omera から ComfyUI または WebUI へワークフローやプロンプトを送信。
2. 生成ツールが画像をレンダリングし、出力ディレクトリに保存。
3. Omera のバックグラウンド監視が新規ファイルを検知し、書き込み完了（500ms）を待ってメタデータを抽出。WebP サムネイルを生成し、完成した作品がギャラリー最上部にリアルタイムで表示。
4. 生成とキュレーションの間で画面の切り替えや手作業によるファイル移動を必要としない、シームレスな制作ループが完成します。
