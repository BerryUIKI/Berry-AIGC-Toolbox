# チェックポイントモデルと LoRA ライブラリ

AI 画像生成ワークフローにおいて、数百種類もの Stable Diffusion チェックポイントモデルや LoRA を管理することは容易ではありません。Omera は、モデルの自動カタログ化、ハッシュ解決、トリガーワードの統合管理機能を標準搭載しています。

---

## 1. チェックポイントモデルカタログ (`ModelManagerModal.vue`)

Omera は、ライブラリ内の全画像から出現したすべてのチェックポイントモデルを自動的に追跡・蓄積します。

### モデルの自動検出：
- ファイルのインデックス時、埋め込まれた PNGInfo や EXIF メタデータからモデル名とモデルハッシュを抽出します。
- **ツール > モデル管理...** を開くと、登録されている全モデルの一覧、短縮ハッシュ、完全な SHA256 チェックサム、使用されている画像総数を確認できます。

### AUTOMATIC1111 `cache.json` によるハッシュ解決：
- 生成メタデータ内では、モデルが8文字の短縮ハッシュ（例: `31e35c80`）として記録されることがよくあります。
- AUTOMATIC1111 をお使いの場合：
  1. モデル管理画面で **「A1111 cache.json をインポート」** をクリックします。
  2. WebUI フォルダ内の `cache.json`（通常は `<webui_root>/cache.json`）を選択します。
  3. Omera はハッシュとモデル名の対応関係をローカルの `model_cache` テーブルに取り込み、ライブラリ内の暗号のようなハッシュを一瞬で分かりやすいモデル名へ自動解決します。

### Civitai SHA256 ハッシュ逆引き：
- ローカルに名前が登録されていないモデルの場合、インスペクター内の Civitai 検索ボタンをクリックして、モデルハッシュをもとに Civitai の公開データベースを直接照会できます。

---

## 2. LoRA トリガーワードライブラリ (`LoraManagerModal.vue`)

LoRA (Low-Rank Adaptation) を効果的に適用するには、意図したキャラクターの特徴、画風、衣装を引き出すための特定のアクティベーションタグ（トリガーワード）をプロンプトに入力する必要があります。

```
┌────────────────────────────────────────────────────────────────────────┐
│ LoRA トリガーワードライブラリ                                      [✕] │
├────────────────────────────────────────────────────────────────────────┤
│ [🔍 モデル名、Hash、トリガーワードで検索... ] [+ LoRA を追加] [フォルダをスキャン]│
├────────────────────────────────────────────────────────────────────────┤
│ LoRA モデル名           │ 推奨ウェイト │ トリガーワード          │ 操作   │
├─────────────────────────┼──────────────┼─────────────────────────┼────────┤
│ CyberpunkCityStyle      │ 0.80         │ cyberpunk, neon signs,  │ [コピー]│
│                         │              │ futuristic alleys       │ [挿入]  │
│ GenshinRaidenShogun     │ 0.85         │ raiden shogun, purple   │ [コピー]│
│                         │              │ braid, glowing katana   │ [挿入]  │
│ StudioGhibliVintage     │ 0.70         │ ghibli style, vintage   │ [コピー]│
│                         │              │ watercolor, cel shaded  │ [挿入]  │
└────────────────────────────────────────────────────────────────────────┘
```

### 主要な LoRA 管理機能：
1. **インスペクターでの LoRA 自動検出**:
   - 画像を閲覧中、プロパティインスペクターが `<lora:name:weight>` 構文や ComfyUI の `LoraLoader` ノードを自動検知します。
   - 検出された LoRA、適用ウェイト、認識されたトリガーワードを一覧表示します。
2. **1クリックでのプロンプト挿入**:
   - **「<lora> 形式でコピー」** をクリックすると、`<lora:name:0.8>` 形式のタグがクリップボードにコピーされます。
   - 個別のトリガーワードチップをクリックして、プロンプトエディタへ即座に貼り付けることができます。
3. **Civitai サイドカーファイル (`.civitai.info`) のインポート**:
   - Civitai ヘルパーなどによって保存された `.civitai.info` や `.json` サイドカーがある場合、モデルハッシュ、ベースモデル種別（SD 1.5, SDXL, Pony, Flux）、学習済みトリガーワード、プレビュー画像を自動抽出してライブラリに登録します。
4. **ローカル LoRA フォルダのスキャン**:
   - ローカルの LoRA 保存フォルダ（例: `models/Lora/`）を指定してスキャンを実行できます。
   - Omera はすべての `.safetensors` ファイルとプレビュー画像を走査し、オフラインで素早く検索可能な LoRA リファレンスライブラリを構築します。
