# 画像スタック・バーストグループ化・画像比較

AI 画像生成では、最良の1枚を見つけるために同一または少しだけプロンプトを変えて10〜50枚単位のバリエーション（バースト生成）を一括生成することが一般的です。適切なキュレーションツールがない場合、ライブラリは似通った下書き画像であふれかえってしまいます。

Omera は、**インテリジェントなバーストスタック**、**トランプ風カード表示**、**表紙（Hero）画像の選定**、**2画面並列画像比較** によってこの課題をスマートに解決します。

---

## 1. スタックの仕組み

**画像スタック（Image Stack）** とは、一連の関連バリエーション画像を1つにまとめ、ギャラリーキャンバス上では **表紙（Hero）** と呼ばれる代表画像1枚のカードとして表示するグループ化機能です。

```mermaid
flowchart LR
    subgraph バースト生成バッチ
        A[バリエーション1 - Seed 101]
        B[バリエーション2 - Seed 102 (星5 表紙Hero)]
        C[バリエーション3 - Seed 103]
        D[バリエーション4 - Seed 104]
    end

    subgraph スタック表示
        E["トランプ風カード [バッジ: 4枚] (表紙: バリエーション2)"]
    end

    A & B & C & D -->|自動または手動グループ化| E
```

### 折りたたみ表示と展開表示
- **折りたたみ（デフォルト）**: 重なり合うトランプのような視覚効果を持つ1枚のカードとして表示され、スタック枚数バッジ（例: `[ 4 ]`）が付きます。
- **展開**: 枚数バッジをクリックすると、スタック内のすべてのバリエーションがギャラリーのグリッド内にインライン展開され、個別の星評価、メタデータ確認、削除が行えます。

---

## 2. 自動バーストスタック機能 (`auto_stack_images`)

Omera は、バックグラウンドで連続生成されたバースト画像を自動検出してグループ化できます：

### クラスタリング判定基準：
1. **プロンプトトークン類似度**: ポジティブプロンプトのトークン化された Jaccard 類似度を算出。必要なしきい値は **環境設定 > スタック** で調整可能（デフォルト: `0.85` / 85% 一致）。
2. **生成時間枠の近接性**: バースト生成は短時間に連続して行われます。設定された時間枠（デフォルト: `180分`）以内に作成されたバリエーションをクラスタリングします。
3. **実行方法**: メニューの **ツール > プロンプトでライブラリを整理（すべてのフォルダーまたは現在のフォルダー）** から手動実行できるほか、インポート時に自動スタックさせることも可能です。

## 3. 手動スタック操作

キーボードショートカットを使って、直感的にスタックの作成、解除、調整が行えます：

| 操作 | ショートカット | 説明 |
| :--- | :--- | :--- |
| **スタックにまとめる** | `Ctrl + G` / `Cmd + G` | 選択した複数の単独画像またはスタックを1つのスタックに結合。 |
| **スタックを解除** | `Ctrl + Shift + G` / `Cmd + Shift + G` | 選択したスタックを個別の単独画像カードに展開・分解。 |
| **表紙（Hero）に設定** | `Alt + S` / `Option + S` | スタック内で選択中の画像を代表表紙カード（`stack_order = 0`）に設定。 |

### スタックの結合とフラット化の安全性
Omera では、スタックの入れ子（スタックの中にスタックを入れること）は**禁止**されています。複数のスタックを選択して `Ctrl + G` を押した場合：
- Omera は元スタック内の画像を自動的にすべてフラットに展開し、ターゲットのスタックに統合します。
- 誤操作を防ぐための確認ダイアログ（`StackMergeWarningModal.vue`）が表示されます。
- 「今後この警告を表示しない」にチェックを入れて非表示にできます（**環境設定 > スタック > 非表示の警告をリセット** からいつでも復元可能）。

## 4. ジェスチャー競合の防止（シングルクリック vs ダブルクリック）

ギャラリー操作の快適性を確保するため、クリックの競合調停が行われます：
- **枚数バッジをシングルクリック**: スタックをインラインで展開／折りたたみ。
- **カード本体をシングルクリック**: スタックを選択（240ms のデバウンスタイマー）。
- **カード本体をダブルクリック**: 展開タイマーを直ちにキャンセルし、表紙（Hero）画像を全画面の **クイックルック・ライトボックス** で拡大表示。

## 5. 2画面並列画像比較 (`CompareModal.vue`)

瞳の描き込み、指の造形、ライティングの微細な差異を見極めたい場合：
1. ギャラリーで比較したい2枚の画像を選択します。
2. `C` キーを押します（またはコンテキストメニューの比較を選択）。
3. **2画面並列画像比較モーダル** が開きます：
   - **スロットA（左）** と **スロットB（右）** に2枚の画像が並列表示されます。
   - **同期ズーム＆パン**: どちらか一方の画面をマウスホイールで拡大縮小したりドラッグ移動すると、両方の画像が完全に同期して連動移動し、等倍（100% ピクセル）での精密な比較が容易に行えます。
   - **HUD メタデータ差分**: シード値、モデル、ステップ数、CFG スケールの違いを並べて表示。
   - **「表紙画像に設定」ボタン**: 比較して勝者と決めた画像を、ワンクリックでバーストスタックの表紙（Hero）に昇格させることができます。

---

## 6. 低評価の下書き整理ツール (`CullDraftsModal.vue`)

ベストな表紙画像を選び、気に入った作品に星3つ以上の評価を付けた後：
1. スタックを選択し、画面下部の一括アクションバーで **「低評価の下書きを整理 (Cull Drafts)」** をクリックします。
2. モーダルが開き、表紙以外の低評価または未評価のボツ候補画像が一覧表示されます。
3. **「ゴミ箱へ移動」** をクリックすると、不要な下書き画像が一括で OS のゴミ箱へ安全に移動され、最高傑作だけを残しながらディスク容量を素早く回復できます。
