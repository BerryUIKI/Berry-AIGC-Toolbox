# 一括エクスポート・トランスコード・Webショーケース

Omera は、**Rayon** によるマルチスレッド並列処理を活用した超高速なエクスポート＆パッケージングエンジン（`ExportModal.vue`）を内蔵しています。フォーマット変換、プライバシーメタデータ消去、ファイル名テンプレート命名、外部依存ゼロのスタンドアロン HTML ショーケース生成に対応しています。

---

## 1. 一括エクスポートの起動方法

エクスポートモーダルを開くには：
- ギャラリーで1枚以上の画像またはスタックを選択します。
- 画面下部のフローティング一括アクションバーで **「一括エクスポート...」** をクリックするか、`Ctrl + E` / `Cmd + E` を押します（またはメニューの `編集 > 一括エクスポート...` を選択）。

---

## 2. フォーマット変換と圧縮品質

Omera は CPU の全コアを使用して、画像を高速に並列エンコード・変換します：

| 出力形式 | 設定項目と特徴 | 最適な用途 |
| :--- | :--- | :--- |
| **元の形式** | 元のファイルコンテナとバイト列をそのまま維持。 | 可逆アーカイブやバックアップ。 |
| **WebP** | 品質スライダー調整（1〜100%、推奨 85%）。極めて高い圧縮率。 | Web配信、Discord、ポートフォリオサイト。 |
| **JPEG** | 標準的なプログレッシブ JPEG エンコード（品質 1〜100%）。 | 従来の画像ビューアや古い環境との互換性。 |
| **PNG** | 完全な可逆圧縮。 | スタジオ納品、高品位な印刷用途。 |

### 解像度スケーリング制限：
巨大な 4K / 8K 画像の誤配布を防ぐため、出力の最大長辺サイズを制限できます：
- **元の解像度を維持**（縮小なし）
- **4K UHD**（最大長辺: 3840 px）
- **2K QHD**（最大長辺: 2048 px）
- **Full HD**（最大長辺: 1080 px）
- **カスタム指定**（任意のピクセル数を指定）

## 3. 4段階のプライバシーメタデータ消去

作品を SNS やオンラインで公開する際、独自のプロンプト、ネガティブ埋め込み、シード値を非公開にしたいクリエイターのために、Omera は **4段階のプライバシー保護レベル** を提供しています：

1. **すべて保持 (プロンプト・ワークフロー・EXIFを維持)**:
   - 埋め込まれたすべてのメタデータ（ComfyUI ワークフローグラフ、A1111 パラメータ、NovelAI コメント、EXIF カメラデータ）を完全に維持。
2. **プロンプトのみ消去 (技術パラメータは保持)**:
   - ポジティブおよびネガティブプロンプト文字列を削除し、モデル名、サンプラー、ステップ数、CFGスケール、シード値などの技術パラメータのみを残します。
3. **すべてのAI生成メタデータ・ワークフローを消去**:
   - ComfyUI フローチャート、A1111 パラメータブロック、LoRA 情報、生成ツールのシグネチャを完全に消去します。
4. **完全クリーン (ピクセルのみ、EXIF/ICCなし)**:
   - EXIF ヘッダー、ICC カラープロファイル、ソフトウェア署名を含め、画像ピクセル以外のすべての補助データを完全消去。純粋なラスタピクセルデータのみを出力します。

## 4. ファイル名パターンテンプレートとサイドカー

動的テンプレート変数を使用して、出力ファイル名を自由にカスタマイズできます（リアルタイムプレビュー付き）：

### 使用可能なテンプレート変数：
- `{name}`: 拡張子を除いた元のファイル名。
- `{id}`: データベースの一意な ID または UUID。
- `{index}`: 連番インデックス（001, 002, 003...）。
- `{date}`: 作成日（`YYYY-MM-DD`）。
- `{rating}`: 星評価（例: `5star`）。
- `{model}`: チェックポイントモデル名。
- `{seed}`: 生成シード値。

*パターン例*: `{date}_{model}_{seed}_{name}` → `2026-09-22_animagine_xl_2849104812_cyberpunk_01.webp`

### メタデータサイドカーファイル：
エクスポート画像と同名のコンパニオンファイルを自動生成できます：
- **なし**: サイドカーファイルを生成しない。
- **プロンプトテキスト (`.txt`)**: ポジティブプロンプトのみをテキストファイルとして書き出し。
- **完全なJSONメタデータ (`.json`)**: 構造化された全メタデータおよび ComfyUI ワークフローグラフを出力。

---

## 5. 独立型インタラクティブ HTML ショーケース生成

Omera は、エクスポートした作品群を **自己完結型の単一 HTML ポートフォリオ**（`index.html`）としてパッケージ化できます：

- **依存関係ゼロ**: Web サーバー、Node.js、外部 CDN、JavaScript ライブラリを一切必要としません。ファイルをダブルクリックするだけで任意のブラウザでオフライン動作します。
- **搭載機能**:
  - Omera と統一された美しいダークモード UI。
  - サムネイル遅延読み込み（Lazy Loading）対応のレスポンシブギャラリー。
  - マウスホイールでのズーム＆パンに対応したフルスクリーンライトボックス。
  - 生成パラメータを確認できる折りたたみ式プロンプトインスペクター。
  - クライアント側で瞬時に動作するキーワード検索バー。
- **パッケージングオプション**: フォルダへの直接エクスポートのほか、クライアント納品やウェブ配布用にすべてを1つの `.zip` アーカイブにまとめて出力することも可能です。
