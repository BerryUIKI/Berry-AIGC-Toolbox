# プロダクト用語集

本用語集では、**Omera** 全体で使用される主要な専門用語、アーキテクチャ概念、および機能定義について解説します。

---

## A
- **AIGC (AI-Generated Content / AI生成コンテンツ)**: Stable Diffusion、ComfyUI、Midjourney、Flux などのニューラルネットワークモデルを使用して生成されたデジタルメディア（画像、アニメーション、音声、動画）。
- **AIGC 取り込みパイプライン (モード C)**: 生成ツールの出力先ディレクトリをアクティブ監視し、500ms のファイル書き込み完了デバウンス、自動取り込み、猶予期間後の遅延クリーンアップを行うフォルダ動作モード。
- **アルバム (Album)**: ディスク上の物理ファイルを移動することなく、任意のアセットをグループ化できるユーザー定義のコレクション。
- **表紙画像 (Authoritative Hero / メイン画像)**: 折りたたまれた画像スタックの代表としてギャラリー上に表示されるメイン画像。

## B
- **一括アクションバー (Batch Action Bar)**: 1枚以上の画像を選択した際に画面下部にスライド表示されるフローティングツールバー。一括評価、タグ付け、移動、エクスポート、ゴミ箱移動などの操作を提供。
- **バーストスタック (Burst Stacking)**: 類似したプロンプトと短い時間間隔で連続生成された一連のバリエーション画像を、自動的に1枚のスタックカードにクラスタリングする機能。

## C
- **CFG スケール (Classifier-Free Guidance)**: ディフュージョンモデルにおいて、画像生成結果が入力テキストプロンプトにどれだけ忠実に従うかを制御するパラメータ。
- **チェックポイントモデル (Checkpoint Model)**: 学習済み重みを含む基本生成ニューラルネットワークモデル（主に `.safetensors` 形式）。モデル名と SHA256 ハッシュで識別。
- **CLIP (Contrastive Language-Image Pre-training)**: 自然言語セマンティック検索や画像の視覚的類似度計算のために Omera が利用するマルチモーダルニューラルネットワーク。
- **ComfyUI**: ノードベースのモジュール型生成 AI ワークフローエンジン。Omera は埋め込まれたワークフローグラフを解析し、`/prompt` API による直接キューイングをサポート。
- **低評価の下書きを整理 (Cull Drafts)**: バーストスタック内の高評価な表紙画像（Hero）を保持しつつ、低評価または不要なバリエーション画像を一括で OS のゴミ箱へ移動する整理機能。

## E
- **外部リンクと監視 (モード A)**: ローカルまたはネットワークストレージをインプレースかつゼロコピーでインデックスし、物理ファイルを移動・変更しないフォルダ動作モード。

## J
- **Jaccard 類似度 (Jaccard Similarity)**: 自動バーストクラスタリングにおいて、トークン化された2つのプロンプト文字列の一致度と重複度を測定するための統計指標。

## K
- **Keyset カーソル式ページネーション (Keyset Cursor Pagination)**: 従来の遅い `OFFSET N` 型クエリの代わりに `WHERE (modified_at, id) < (?, ?)` を使用するデータベースクエリ戦略。50万件を超えるレコードでもミリ秒未満の高速ページ遷移を実現。

## L
- **クイックルック / ライトボックス (Lightbox / Quick Look)**: `Space` または `Enter` キーで開く全画面ビューア。マウスホイールによるズーム＆パン、動画のコマ送り／コマ戻しに対応。
- **LoRA (Low-Rank Adaptation)**: 特定のキャラクター、画風スタイル、衣装などを反映させるために、チェックポイントモデルの上から適用される軽量な追加学習モデル。

## M
- **管理プロジェクト保管庫 (モード B)**: インポートされた画像ファイルを、日付ベースのフォルダ構造（`YYYY/MM/UUID_ファイル名.ext`）に自動整理・格納する専用の保管庫モード。
- **ウォーターフォール（元の縦横比） (Masonry Waterfall)**: 各作品本来のアスペクト比を切り抜くことなく維持したまま、複数のフルイド列に並べるギャラリーレイアウトモード。

## N
- **NSFW ぼかし (NSFW Blur)**: 成人向けコンテンツやセンシティブとマークされた画像に対して、明示的にクリックされるまで CSS ぼかしフィルターを適用するプライバシー保護機能。

## O
- **OCC (Optimistic Concurrency Control / 楽観的並行性制御)**: 行レベルの `version` 番号を使用して、複数のチームメンバーが同一ライブラリを同時に編集した場合の競合やデータ消失を防ぐ並行性制御手法。

## P
- **トランプ風スタックカード (Poker-Deck Card)**: ギャラリー内における画像スタックの視覚的表現。表紙画像の背後にカードが重なり合うレイヤー効果と、枚数バッジを備える。
- **プロンプトチップ (Prompt Chips)**: プロパティインスペクター内でプロンプトの各単語を視覚化したインタラクティブな UI タグ。クリックによるライブラリ横断検索や一括コピーが可能。

## S
- **サンプラー / スケジューラー (Sampler / Scheduler)**: 潜在ノイズから徐々にノイズを除去して完成画像を生成する数値積分アルゴリズム（例: `Euler a`, `DPM++ 2M Karras` など）。
- **シード値 (Seed)**: 再現性のある画像生成を行うために、疑似乱数ノイズ生成器を初期化する整数値。
- **サイドカーファイル (Sidecar File)**: 生成パラメータや Civitai メタデータを含み、画像ファイルと同名で隣接配置される補助ファイル（`.txt` や `.json`）。
- **ストレージルート (Storage Root)**: OS ごとに異なるマウントパスを吸収し、ネットワーク共有フォルダを横断的に一意識別するクロスプラットフォームな UUID。

## W
- **WAL (Write-Ahead Logging)**: バックグラウンドでのインデックス作成やサムネイル生成中であっても、非ブロッキングな並行読み込みを可能にする SQLite のジャーナルモード。
- **WD14 タガー (WD14 Tagger)**: 画像ピクセルから Danbooru アニメタグやコンテンツレーティングを自動推定するコンピュータビジョンモデル（SmilingWolf 提供）。
