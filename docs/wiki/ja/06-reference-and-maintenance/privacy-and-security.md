# プライバシーとセキュリティアーキテクチャ

Omera は、**100% ローカルファースト・テレメトリ完全排除** の設計思想に基づいて構築されています。生成 AI ワークフローでは、独自の画風スタイル、未公開のキャラクター設定、機密性の高いクライアントワークなどを扱うことが多くあります。Omera は、クリエイターのすべての作品とデータが外部に出ることなく、自身のローカルマシン内に完全に留まることを保証します。

---

## 1. テレメトリ完全ゼロとオフライン動作

### 外部への情報送信（Phone-Home）なし
- Omera には、**トラッキングピクセル、アクセス解析 SDK、クラッシュ報告サービスは一切組み込まれていません**（Google Analytics、Sentry、Mixpanel、PostHog などの外部収集モジュールは皆無です）。
- インターネットから完全に遮断されたオフライン環境や、企業の厳格なエアギャップファイアウォール内でも、すべての機能を何ら制限なく利用できます。

### 外部への送信が発生する明確な条件
Omera が外部ネットワークと通信を行うのは、ユーザーが意図して操作した以下の **3つのケースのみ** です：
1. **アップデートの確認**: 「起動時に自動で更新を確認」が有効な場合（またはメニューの `ヘルプ > アップデートを確認...` を手動実行した場合）、公開されている GitHub Releases API（`https://api.github.com/repos/BerryUIKI/Omera/releases/latest`）に最新リリース情報を照会します。
2. **Civitai ハッシュ逆引き**: 未登録のモデルハッシュに対して、ユーザーが明示的に「Civitai で検索」をクリックした場合にのみ、Civitai の公開モデル API に単一のリクエストを送信します。
3. **クラウドバックアップとチーム共有**: ユーザー自身が環境設定で AWS S3、WebDAV、または共有 PostgreSQL/MySQL サーバーを設定した場合に、その指定先とのみ通信します。

---

## 2. 完全ローカルでの AI 推論実行

Omera 内のすべての機械学習・推論機能は、内蔵された **ONNX Runtime**（`ort`）を通じて、ローカルマシンの CPU/GPU のみで実行されます：

- **CLIP / SigLIP 特徴量ベクトル生成**: 画像の前処理およびベクトルエンコードはすべてローカルで行われます。プロンプト、検索テキスト、画像のピクセルが外部サーバーに送信されることはありません。
- **WD14 アニメ自動タグ付け**: ニューラルネットワークの推論はローカルモデルファイル（`models/`）を使用して実行され、推定されたタグはローカルの SQLite データベースに直接保存されます。

---

## 3. プライバシー保護に特化したエクスポートと消去

作品を一般公開・共有する際、Omera は **4段階のメタデータ消去エンジン** を提供します：

- SNS や Discord に画像をアップロードする前に、埋め込まれた ComfyUI ノードグラフ、ポジティブ/ネガティブプロンプト、シード値、LoRA タグをワンクリックで完全消去できます（詳細は [エクスポートとWebショーケース](../05-export-and-collaboration/export-and-web-showcase.md) を参照）。
- **完全クリーン** モードでは、EXIF や ICC プロファイルを含むすべての補助データを消去し、純粋な画像ピクセルデータのみを出力します。
