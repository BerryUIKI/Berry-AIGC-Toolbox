# 環境設定パラメータリファレンス

Omera の環境設定ウィンドウ（`SettingsModal.vue`）は、メニューの `ファイル > 環境設定 / 設定...` または `Ctrl + ,` / `Cmd + ,` から開くことができます。すべての設定項目は、ローカルのアプリケーションデータディレクトリにある `config.json` に永続保存されます。

---

## タブ 1: 一般設定 (General)

| 設定項目 | `config.json` 内のキー | デフォルト値 | 説明 |
| :--- | :--- | :--- | :--- |
| **表示言語** | `locale` | `"auto"` | 選択可能な言語: `auto` (OS言語に従う)、`en` (英語)、`zh-CN` (簡体字中国語)、`zh-TW` (繁体字中国語)、`ja` (日本語)、`de` (ドイツ語)、`fr` (フランス語)、`es` (スペイン語)。 |
| **デフォルトのギャラリー表示** | `default_view` | `"grid"` | 起動時の初期表示モード: `"grid"` (グリッド表示)、`"masonry"` (ウォーターフォール)、`"table"` (詳細リスト)。 |
| **起動時に自動スキャン** | `auto_scan` | `true` | 起動時に登録済みフォルダの新規・変更ファイルを自動検出。 |
| **起動スキャンの間隔** | `startup_scan_interval_minutes`| `360` | ディレクトリ全体の完全再スキャンを省略するクールダウン期間（分単位: `30`, `60`, `360`, `1440`）。頻繁なアプリ再起動時のディスク負荷を抑制します。 |
| **起動時に自動で更新を確認** | `auto_check_update` | `true` | 起動時に GitHub Releases をバックグラウンド確認し、新バージョンがある場合にバッジを表示。 |

## タブ 2: ギャラリー（表示と安全保護）

| 設定項目 | `config.json` 内のキー | デフォルト値 | 説明 |
| :--- | :--- | :--- | :--- |
| **テーマ** | `theme` | `"system"` | UIカラーパレット: `"system"` (OS準拠)、`"midnight"` (OLED向け黒)、`"graphite"` (ニュートラルダーク)、`"violet"` (クリエイティブパープル)、`"light"` (ライト)。 |
| **センシティブ画像 (NSFW) をデフォルトでぼかす** | `blur_nsfw` | `true` | 成人向け・センシティブ指定された画像を、クリックするまで CSS ぼかしマスクで保護。 |
| **カードバッジを表示** | `show_card_badges` | `true` | ギャラリーカード上にフォーマット (`PNG`, `MP4`)、解像度 (`1024×1024`)、生成ツール、星評価バッジを表示。 |
| **サムネイル解像度規格** | `thumbnail_max_edge` | `384` | 生成サムネイルの長辺ピクセルサイズ (64の倍数): `256` (コンパクト)、`384` (標準推奨)、`448` (高解像度)、`512` (超高解像度)。 |
| **Thumbnail Cache Budget** | `thumbnail_cache_budget_mb` | `2048` | WebP サムネイルキャッシュに割り当てる最大ディスク容量 (MB)。上限を超えると最も古くアクセスされた階層から自動破棄 (LRU)。 |
| **サムネイルキャッシュを消去** | なし | なし | ディスク上のすべてのキャッシュサムネイルを即座に完全消去するアクションボタン。 |
| **診断情報** | なし | なし | Rayon スレッドプールや LRU キャッシュのリアルタイム指標を表示するアクションボタン。 |

## タブ 3: スタック（スタックとバースト）

| 設定項目 | `config.json` 内のキー | デフォルト値 | 説明 |
| :--- | :--- | :--- | :--- |
| **自動スタックを有効にする** | `auto_stack` | `true` | 連続生成されたバースト画像をトランプ風スタックカードに自動グループ化。 |
| **プロンプト類似度閾値** | `stack_similarity_threshold` | `0.85` | 同一スタックとしてグループ化するために必要なトークン化 Jaccard 類似度の最小値 (0.0〜1.0)。 |
| **生成間の最大時間枠 (分)** | `stack_time_window_minutes` | `180` | 同一バースト生成とみなす連続生成間の最大時間間隔。 |
| **複数のスタックを同時に開く** | `allow_multiple_open_stacks` | `false` | `false` の場合、別のスタックを開くと既存の展開スタックは自動で折りたたまれます。`true` の場合、複数のスタックを同時に展開したままにできます。 |
| **非表示の警告をリセット** | なし | なし | スタック結合時などに「今後この警告を表示しない」をチェックして非表示にした警告ダイアログを再有効化。 |

## タブ 4: 生成環境連携 (Interop)

| 設定項目 | `config.json` 内のキー | デフォルト値 | 説明 |
| :--- | :--- | :--- | :--- |
| **ComfyUI ベース URL** | `comfyui_url` | `"http://127.0.0.1:8188"` | ローカルの ComfyUI サーバーの HTTP エンドポイント。接続テストボタン付き。 |

## タブ 5: チーム共有とDB (Team & Collaboration)

| 設定項目 | `config.json` 内のキー | デフォルト値 | 説明 |
| :--- | :--- | :--- | :--- |
| **データベースエンジン** | `storage_backend` | `"sqlite"` | 使用するデータベース: `"sqlite"`, `"mysql"`, または `"postgres"`. |
| **リモート接続URL** | `remote_connection_url` | `""` | 接続文字列 (例: `postgres://user:pass@host:5432/omera_studio`)。 |
| **クライアント識別子 (Client ID)** | `client_identifier` | `""` | 変更ジャーナルや OCC 楽観的並行性制御で端末を一意に識別する固有のクライアント名。 |
| **共有ストレージルート対応** | `root_mappings` | `{}` | 共有 Root UUID と各 OS ローカルのマウントパスを紐付けるクロスプラットフォームマッピング。 |
| **接続テスト** | なし | なし | リモートデータベースサーバーへの ping を実行し、往復遅延時間（ミリ秒）を表示。 |
| **移行ウィザードを開く** | なし | なし | SQLite から MySQL / PostgreSQL へのスキーマ・データ移行スクリプト生成ツールを起動。 |

## タブ 6: クラウドバックアップと同期

| 設定項目 | `config.json` 内のキー | デフォルト値 | 説明 |
| :--- | :--- | :--- | :--- |
| **ストレージプロバイダー** | `cloud_backup.provider` | `"local_path"` | 保存先プロトコル: `"local_path"`, `"webdav"`, または `"s3"`. |
| **WebDAV URL / 認証情報** | `cloud_backup.webdav_*` | `""` | Nextcloud や Synology WebDAV のエンドポイント URL、ユーザー名、パスワード。 |
| **S3 エンドポイント / 認証情報** | `cloud_backup.s3_*` | `""` | S3 / Cloudflare R2 / MinIO のエンドポイント、バケット名、リージョン、アクセスキー、シークレットキー。 |
| **差分比較戦略** | `cloud_sync.strategy` | `"fingerprint"` | `"fingerprint"` (サイズ + ETag) または `"checksum"` (完全 SHA-256 検証)。 |
| **転送スレッド数** | `cloud_sync.threads` | `4` | クラウドメディアアップロード用の並行ワーカースレッド数。 |
| **帯域幅制限** | `cloud_sync.bandwidth_limit_kbs` | `0` | 最大アップロード速度 (KB/s、0 = 無制限)。 |

## タブ 7: メタデータ（組み込み抽出エンジン）

組み込みの可逆メタデータパーサーのリアルタイム稼働状態を表示：
- AUTOMATIC1111 / SD.Next PNG `parameters` チャンクパーサー (稼働中 🟢)
- ComfyUI ノード実行グラフ ＆ `workflow` JSON パーサー (稼働中 🟢)
- NovelAI `Comment` ＆ `Description` パーサー (稼働中 🟢)
- Fooocus / Fooocus-MRE プロンプトブロックパーサー (稼働中 🟢)
- InvokeAI `sd-metadata` ＆ `invokeai_metadata` パーサー (稼働中 🟢)
- MP4 ISOBMFF ＆ WebM EBML ビデオストリームパーサー (稼働中 🟢)

## タブ 8: ストレージと情報 (About)

- **バージョン**: 現在のアプリケーションバージョンを表示（例: `v0.3.0`）。
- **スキーマ**: 現在の SQLite スキーママイグレーションバージョン（例: `スキーマ v14`）。
- **ローカル SQLite パス**: 使用中の `omera.db` の絶対パス。
- **フォルダを開くボタン**:
  - `設定ファイルを開く`: `config.json` があるフォルダを開く。
  - `データベースを開く`: `omera.db` および WAL ジャーナルがあるフォルダを開く。
  - `サムネイルを開く`: WebP サムネイルキャッシュフォルダを開く。
  - `モデルを開く`: ONNX AI モデルフォルダを開く。
