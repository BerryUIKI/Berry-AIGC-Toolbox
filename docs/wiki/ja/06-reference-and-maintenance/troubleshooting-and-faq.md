# トラブルシューティングとよくある質問 (FAQ)

本ガイドでは、Omera の利用時によくある疑問、特殊なケース、および不具合発生時のトラブルシューティング手順について解説します。

---

## 1. よくある問題と解決策

### 問題: AI 生成ツールで新しく作成した画像がギャラリーに表示されない
- **原因**: 対象フォルダがアクティブな取り込みパイプラインとして設定されていないか、ファイルシステム監視の書き込み安定待ち（クワイエット期間）中の可能性があります。
- **解決手順**:
  1. 左サイドバーに該当フォルダが正しく登録されているか確認します。
  2. AUTOMATIC1111 や ComfyUI を利用している場合は、フォルダモードが **モードC: ⚡ AIGC 取り込みパイプライン** に設定されていることを確認してください（書き込み完了デバウンスが有効になります）。
  3. サイドバーでフォルダを右クリックし、**「新規画像の取り込み」** または **「スキャン」** をクリックして即時チェックを実行します。

### 問題: サムネイルの読み込みが遅い、またはプレースホルダーが表示される
- **原因**: 大規模な初回インポート時、バックグラウンドの Rayon ワーカースレッドがバッチ単位で画像を順次縮小処理しています。
- **解決手順**:
  1. 下部ステータスバーの **⚡ バックグラウンド** をクリックし、サムネイル生成ワーカーが処理中であるかを確認します。
  2. **環境設定 > ギャラリー（表示と安全保護）** で、**Thumbnail Cache Budget** が `2048 MB` 以上に設定されていることを確認します。
  3. 初回の大量インポート時は、重い動画レンダリングやゲームの同時実行を避けることで処理速度が向上します。

### 問題: プロンプトに含まれているはずの単語を検索しても0件になる
- **原因**: **構文検索モード (`🔍`)** ではなく **セマンティック検索モード (`🧠`)** になっているか、インデックス対象外のフィールドで絞り込んでいる可能性があります。
- **解決手順**:
  1. 検索バーの左端アイコンを確認してください。脳のアイコンが表示されている場合は、クリックして **構文検索 (`🔍`)** に戻します。
  2. スペースを含む完全一致フレーズを検索する場合は、引用符で囲んで検索します: `prompt:"cyberpunk city"`。
  3. **フィルタードロワー (`☰ フィルター`)** を開き、**「すべてリセット」** をクリックして、意図しないフィルター条件（星5評価のみなど）が結果を隠していないか確認します。

### 問題: スタックがバラバラに分離したり、重複して見える
- **原因**: OS のエクスプローラー等で外部からファイル名を変更したり移動した場合、スタックの紐付けが途切れることがあります。
- **解決手順**: ギャラリーで該当する複数のカードを選択し、`Ctrl + G` を押して1つのスタックに再結合してください。

### 問題: 「ComfyUI に送信」を実行すると接続拒否エラーになる
- **原因**: ComfyUI が起動していないか、異なるポート番号で動作している可能性があります。
- **解決手順**:
  1. **環境設定 > 生成環境連携** を開きます。
  2. **ComfyUI ベース URL** が ComfyUI のコンソールに表示されている URL（デフォルト: `http://127.0.0.1:8188`）と一致しているか確認します。
  3. **「接続テスト」** ボタンをクリックし、通信が可能であるかテストします。

## 2. よくある質問 (FAQ)

### Omera は完全無料で利用できますか？
はい。Omera は **AGPL-3.0** ライセンスの下で公開されているフリー＆オープンソースソフトウェアです。サブスクリプション、課金、機能制限などは一切ありません。

### 10万枚や50万枚を超えるような超大規模ライブラリでも扱えますか？
はい。Omera は当初から大規模コレクションを快適に管理できるよう設計されています：
- **Keyset カーソル式ディープページネーション**（`search_files_cursor_page`）により、ライブラリの規模に関わらずミリ秒未満の検索応答を維持。
- **SQLite Write-Ahead Logging (WAL)** による非ブロッキングな超高速並行読み込み。
- 画面の表示領域にあるカードのみを描画する **動的 DOM 仮想化**。

### プロンプトや画像が外部のクラウドへ勝手に送信されることはありますか？
一切ありません。ファイルスキャン、メタデータ抽出、データベース保存、AI推論（CLIP および WD14）はすべて **100% ローカル環境** で実行されます。利用状況のテレメトリやアクセス解析も一切収集されません。

### Omera から ComfyUI や Discord へ画像を直接ドラッグ＆ドロップできますか？
はい。ギャラリーのカードをブラウザや外部デスクトップアプリへ直接ドラッグ＆ドロップすると、標準の OS ファイルドロップとして処理され、埋め込まれたメタデータチャンクを保持したまま転送されます。

### 左サイドバーからフォルダを削除すると、中の画像ファイルも消えてしまいますか？
いいえ。Omera 上でフォルダを削除しても、Omera のデータベースからフォルダとインデックス情報が登録解除されるだけです。**ディスク上の物理ファイルが移動・削除されることは決してありません。**

### チーム内の複数のクリエイターで同じライブラリを共有・共同作業できますか？
はい。**環境設定 > チーム共有とDB** でデータベースを SQLite から共有 **MySQL 8.0+** または **PostgreSQL 14+** に切り替えることで、リアルタイムの変更同期とクロスプラットフォームパス変換を備えた共有ネットワークライブラリとして運用できます。
