# アップデートとライフサイクル

Omera は、制作作業を妨げることなく、かつユーザーデータを決して危険に晒さないよう設計された、安全なインプレース自動アップデータを備えています。

---

## 1. アップデートの確認方法

### 起動時の自動確認：
デフォルトでは、Omera の起動時に GitHub Releases API を照会します：
- 新しいバージョンが利用可能な場合、**ヘルプ** メニューに更新インジケーターバッジが表示されます。
- この動作は **環境設定 > 一般設定 > 起動時に自動で更新を確認** で有効／無効を切り替えることができます。

### 手動での確認：
いつでも手動で更新を確認できます：
- 上部メニューバーの **ヘルプ > アップデートを確認...** をクリックします。

---

## 2. アプリ内アップデート画面 (`UpdateModal.vue`)

新バージョンが検出されると、**アップデート確認ウィンドウ** が表示されます：

```
┌────────────────────────────────────────────────────────────────────────┐
│ 新しいバージョンが見つかりました: v0.3.1                           [✕] │
├────────────────────────────────────────────────────────────────────────┤
│ Omera の新バージョンが利用可能です (現在: v0.3.0)。          │
│                                                                        │
│ 更新履歴:                                                              │
│ • HunyuanVideo 向けの ComfyUI 動画メタデータパーサーを最適化。         │
│ • 10万点規模ライブラリにおける Keyset ページネーションの遅延を改善。   │
│ • フローティング一括アクションバーに10段階評価セレクターを追加。       │
├────────────────────────────────────────────────────────────────────────┤
│ ダウンロード進捗:                                                      │
│ [██████████████████████████░░░░░░░░░░] 68% (12.4 MB / 18.2 MB · 4 MB/s)│
├────────────────────────────────────────────────────────────────────────┤
│ [ 閉じる ]                                 [ 🚀 自動ダウンロードして更新 ]│
└────────────────────────────────────────────────────────────────────────┘
```

### インストールの流れ：
1. **「🚀 自動ダウンロードして更新」** をクリックします。
2. Omera は GitHub Releases からお使いの OS に適したリリースパッケージを一時フォルダにストリーミングダウンロードします。
3. ダウンロードが完了すると、アプリの再起動を促すメッセージが表示されます。
4. **「⚡ 今すぐインストールして再起動」** をクリックすると、サイレント上書きインストールが実行され、最新バージョンで自動再起動します。

## 3. データの完全保持保証

Omera のアップデートにおいて、**ユーザーデータが消失することは一切ありません**：

- **データベースの安全性**: `omera.db` データベース、カスタムアルバム、カラータグ、星評価、バーストスタックの関係性は、OS のユーザー AppData ディレクトリ（`%APPDATA%`、`~/Library/Application Support`、または `~/.config`）に安全に保存されており、実行バイナリとは完全に分離されています。
- **追記型スキーママイグレーション**: 新バージョンでデータベース構造が変更された場合でも、Omera の Rust バックエンドが起動時に `PRAGMA user_version` を使用して **追記型のスキーママイグレーション** を実行します。既存のレコードを書き換えたり削除したりすることなく、差分のみが増分適用されます。
- **設定の永続性**: `config.json` に保存された環境設定、サムネイルキャッシュバジェット、登録フォルダのパス情報もすべて確実に引き継がれます。
