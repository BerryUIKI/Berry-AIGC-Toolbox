# 键盘快捷键速查表

Omera 专为**全键盘高效操作流**深度设计。无需频繁切换或移动鼠标，你即可完成海量图库的极速浏览、星级评分、堆叠分组、参数查看与分类归档。

---

## 1. 快速查看与画廊浏览

| 快捷键 | 操作功能 | 生效范围 | 功能说明 |
| :--- | :--- | :--- | :--- |
| `Space` 或 `Enter` | **快速查看 / 灯箱预览** | 画廊选中项 | 为当前选中的图片唤起全屏高清大图预览弹窗。 |
| `Esc` | **关闭 / 清除选择** | 全局 | 关闭灯箱预览或浮层窗口、清除搜索内容、或取消卡片选中状态。 |
| `←` / `→` | **上一张 / 下一张** | 画廊与灯箱 | 将选中光标移动至相邻项（在视频回放状态下为逐帧步进）。 |
| `↑` / `↓` | **上一行 / 下一行** | 网格视图 | 将选中光标在视觉网格行间垂直移动。 |
| `Ctrl + A` / `Cmd + A` | **全选当前视图** | 画廊画布 | 全选当前搜索与筛选条件下的所有匹配卡片。 |
| `Delete` 或 `Backspace` | **移入废纸篓** | 画廊选中项 | 将所选文件安全投入操作系统的回收站/废纸篓。 |

## 2. 极速评级与收藏打标

| 快捷键 | 操作功能 | 功能说明 |
| :--- | :--- | :--- |
| `1` | **打分 1 星** | 将当前选中项评为 1 星。 |
| `2` | **打分 2 星** | 将当前选中项评为 2 星。 |
| `3` | **打分 3 星** | 将当前选中项评为 3 星。 |
| `4` | **打分 4 星** | 将当前选中项评为 4 星。 |
| `5` | **打分 5 星** | 将当前选中项评为 5 星。 |
| `0` | **清除评分** | 清空当前选中项的星级评分。 |
| `F` | **切换收藏状态** | 一键为当前选中项添加或取消收藏书签。 |

> [!TIP]
> **盲打极速刷图模式**：一只手按住方向键（`←`、`→`）快速连续切图，另一只手在数字键 `1`–`5` 上随看随评。评分会立即直接异步写入底层 SQLite 数据库，毫秒级响应，绝不卡顿掉帧。

## 3. 堆栈管理与并排比对

| 快捷键 | 操作功能 | 生效范围 | 功能说明 |
| :--- | :--- | :--- | :--- |
| `Ctrl + G` / `Cmd + G` | **新建图片堆栈** | 画廊选中项 | 将选中的多张相似图片聚合为扑克牌折叠卡片。 |
| `Ctrl + Shift + G` / `Cmd + Shift + G` | **解散图片堆栈** | 画廊选中项 | 将选中的堆栈解体拆散还原为单张独立卡片。 |
| `Alt + S` / `Option + S` | **设为封面 Hero** | 堆栈内选中项 | 将当前选中的图片指定为该堆栈的默认主封面图。 |
| `C` | **双图并排深度比对** | 画廊选中项 | 进入双图并排分屏比对视图，支持同屏联动缩放与拖动平移。 |

## 6. 多选与交互修正键

- **单机单击 (Plain Click)**：选中单张卡片，并将其确立为当前**选区锚点 (Selection Anchor)**。
- **Shift + 单击**：以当前锚点为起点，连选至本次点击的卡片，建立包含首尾的**连续区间选择**。
- **Ctrl + 单击**（macOS 上为 `Cmd + 单击`）：对单张卡片执行**反选切换 (Toggle)**，既不破坏其他已有选中项，同时将锚点更新至该卡片。
- **双击堆栈封面**：直接唤起主封面图的高清全屏灯箱预览（双击手势裁决机制可有效避免误触展开堆栈）。
- **单击堆栈右上角计数角标**：原地就地展开或收起该连拍堆栈中的所有子图片。
