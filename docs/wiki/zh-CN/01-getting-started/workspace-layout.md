# 工作区布局与交互架构

Omera 借鉴了 **Eagle** 与 **Lightroom** 的经典设计哲学，采用高度优化的三栏式桌面工作区架构，专为高密度视觉整理、极速键盘盲打操作及沉浸式浏览体验量身打造。

## 2. 标题栏与原生应用菜单栏

软件采用无边框轻量化设计，搭配深度定制的原生风格标题栏（`TitleBar.vue`）与桌面级菜单系统（`MenuBar.vue`）：

### 顶部菜单功能索引
- **文件 (File)**：
  - `添加文件夹...`（`Ctrl + O` / `Cmd + O`）：挂载新的本地硬盘或网络共享目录。
  - `扫描当前目录`：对当前激活的文件夹执行增量扫描，捕获变动或新增文件。
  - `重新扫描所有目录`：强制对所有已添加的文件夹执行完整差异扫描。
  - `数据库管理...`：打开数据库紧凑整理（VACUUM）、存储占用统计与备份还原面板。
  - `首选项 / 设置...`（`Ctrl + ,` / `Cmd + ,`）：打开 8 大功能设置主窗口。
  - `退出程序`（`Alt + F4`）：安全保存状态并平稳退出应用。
- **编辑 (Edit)**：
  - `全选当前视图`（`Ctrl + A` / `Cmd + A`）：选中当前画廊视图中的所有图片。
  - `取消选择`（`Esc`）：清除所有高亮选中的条目。
  - `批量添加标签...`：为多选图片批量绑定或解绑标签。
  - `批量加入相册...`：将多选图片一键收录至目标相册。
  - `批量移动到文件夹...` / `批量复制到文件夹...`：在物理磁盘间转移媒体文件。
  - `批量导出...`（`Ctrl + E` / `Cmd + E`）：打开格式转码、元数据脱敏与打包面板。
  - `移入废纸篓`（`Delete` / `Backspace`）：安全将选中项移入操作系统回收站。
- **视图 (View)**：
  - `网格视图`：切换至规整的等高自适应卡片布局。
  - `瀑布流视图`：切换至保留原始宽高比、无裁切的瀑布流画廊。
  - `列表视图`：切换至紧凑的信息表格清单模式。
  - `切换左侧导航栏`（`B`）：展开或收起左侧导航面板。
  - `切换右侧检查器`（`I`）：展开或收起右侧参数属性检查器。
  - `全屏灯箱预览 (快速查看)`（`Space` / `Enter`）：打开全屏沉浸式大图弹窗。
  - `放大网格`（`Ctrl + =`）、`缩小网格`（`Ctrl + -`）、`重置默认缩放`（`Ctrl + 0`）。
- **工具 (Tools)**：
  - `提示词洞察与词频统计...`：打开全库词频分布与评分相关性图表。
  - `模型管理器与缓存...`：管理 Checkpoint 哈希库并解析友好模型名。
  - `CLIP 语义检索模型与索引...`：管理自然语言文本向量索引与建库。
  - `LoRA 触发词库...`：管理 LoRA 触发词（Activation Tags）与 `.civitai.info` 伴随文件。
  - `WD14 AI 自动打标器...`：基于本地 Danbooru 深度学习模型一键预测打标。
- **帮助 (Help)**：
  - `语言`：支持即时切换 7 种界面语言。
  - `快捷键指南`（`?`）：调出软件内置快捷键速查面板。
  - `检查更新...`：连接 GitHub Releases 校验新版本并支持静默就地升级。
  - `关于 Omera`：查看版本号、构建信息、开源协议与开发者鸣谢。

## 3. 左侧导航侧栏 (`Sidebar.vue`)

左侧边栏（快捷键 `B` 切换显示）让你可以快速穿梭于不同的媒体资产聚合分类中：

1. **系统预置库**：
   - **全部图像**：汇集当前所有挂载目录下的全部已索引资产，附带总数统计徽章。
   - **收藏夹 (★)**：快速筛选所有已星标收藏的精品图片。
   - **敏感内容 (18+) (🔞)**：快速定位标记为 NSFW 的内容（默认启用高斯模糊遮罩保护）。
2. **文件夹列表 (Folders)**：
   - 列出所有已纳管的目录，带有清晰的模式图标：
     - `⚡`：**AI 自动流水线**（实时监视生图输出目录）。
     - `📦`：**托管项目库**（由 Omera 集中归档管理的专用库）。
     - `📁`：**外链模式**（原地零拷贝只读引用）。
   - 悬停或右键菜单可触发：**收获新图片**、**扫描目录**、**重建元数据**或**移除文件夹**。
   - 支持拖拽交互：直接从画廊中拖动图片卡片到文件夹上，即可执行物理移动或复制。
3. **相册分类 (Albums)**：
   - 用户自定义的虚拟聚合合集。直接拖动卡片至相册即可加入收录。
   - 提供快捷的“+ 新建”相册按钮。
4. **色彩标签 (Tags)**：
   - 8 种高对比度色彩的分类标签胶囊。
   - 支持拖拽画廊图片投掷至标签上批量打标。
5. **底部快捷工具栏**：
   - 设有快捷入口，可一键呼出提示词洞察、模型库、数据库维护及快捷键指南弹窗。

## 4. 中央画廊画布与搜索工具条

中央核心工作区是用户进行资产浏览、选片、对比与整理的主战场：

- **多模态搜索栏 (`SearchBar.vue`)**：
  - **语法搜索模式 (`🔍`)**：支持自由关键词以及高阶参数语法查询（例如 `prompt:"cyberpunk" cfg:>7`）。
  - **AI 语义搜图模式 (`🧠`)**：无需精准提示词，直接输入自然语言描述即可基于本地 CLIP/SigLIP 检索画面。
- **视图切换与尺寸缩放**：
  - 支持在**网格 (⊞)**、**瀑布流 (▤)**与**列表 (☰)**视图间平滑切换。
  - **缩放滑块**：动态调节卡片最小基准宽度（**130px** 至 **360px**）。列数根据屏幕宽度自适应重排，图片不会变形拉伸。
- **抽屉筛选器开关 (`FilterDrawer.vue`)**：
  - 点击滑出多维度高级筛选抽屉，支持按 Checkpoint 模型、采样器、画面比例、星级评分以及视频时长/帧率组合过滤。

## 5. 右侧属性检查器 (`InspectorPane.vue`)

右侧面板（快捷键 `I` 切换显示）为当前选中的图片提供深度的无损 AIGC 生成参数解析：

- **媒体预览窗口**：高清缩略图展示，附带敏感内容临时显隐切换与快速查看灯箱入口。
- **快速策展控制**：0–5 星级评分打分板、一键收藏切换（`F`）以及敏感内容（NSFW）标记开关。
- **正向提示词 (Prompt)**：
  - **词元化交互展示**：提示词被自动分词解析为一个个独立的可点击芯片标签（Token Chips）。
  - 点击任一词元即可全库反查包含该描述的所有图片。
  - 配备一键复制完整正向提示词按钮。
- **负向提示词 (Negative Prompt)**：展示完整负向过滤描述，支持一键快捷复制。
- **核心生成技术参数**：
  - 模型名称（Model Name）与 Checkpoint SHA-256 哈希值。
  - 采样器（Sampler）与调度算法（Scheduler）。
  - 采样步数（Steps）、提示词引导系数（CFG Scale）与随机种子（Seed，附带复制按钮）。
  - 原始生成分辨率尺寸（`宽 × 高`）。
- **识别到的 LoRA 列表**：
  - 自动提取图片中包含的所有 `<lora:name:weight>` 语法或 ComfyUI LoRA 加载节点。
  - 展示触发词列表、应用权重，并支持一键复制标准 LoRA 提示词语法。
- **生成环境互通卡片 (Generation Interop)**：
  - 实时显示与本地 **ComfyUI** 及 **AUTOMATIC1111** 的 API 在线状态。
  - 提供“发送到 ComfyUI”（重排工作流节点）或“发送到 SD WebUI”一键回传。
- **原始工作流折叠层**：查看未经处理的原生 JSON 工作流节点图或 A1111 原始参数文本块。

## 6. 底部状态栏与后台任务监控

位于应用窗口最底端，提供关键运行指标：
- **筛选匹配 / 总量指示**：展示当前视图可见条目与全库总量的比例（如 `筛选匹配: 1,248 / 8,920 项`）。
- **选区计数器**：清晰标注当前选中的项目数（如 `3 项已选`）。
- **数据库版本标识**：显示当前 SQLite 数据库文件名称与数据表版本（Schema Version）。
- **后台任务监控弹层 (`⚡ 后台任务`)**：
  - 点击展开实时监控面板，查看底层文件监视器状态（活跃监听根目录数、日志待处理队列、错误率）以及后台 WebP 缩略图并行解码队列进度。

## 7. 悬浮批量操作栏 (`BatchActionBar.vue`)

当你在画廊中选中 1 张或多张卡片时，画布中下方会自动浮现专用的批量操作工具栏：

- 多选数量指示器（`已选 X / Y`），带有“全选”与“取消选择”按钮。
- 批量评分下拉选择框（0–5 星 / 10 级标度）。
- “相册”与“标签”快捷添加弹窗入口。
- “自动打标 (WD14)”批量触发器。
- 批量“收藏” / 取消收藏切换。
- 批量“复制路径”与“复制提示词”至剪贴板。
- 目标目录“移动”与“复制”引导对话框。
- “清理低分草稿 (Cull Drafts)”工具（当选中项包含堆栈时自动高亮激活）。
- “批量导出...”面板（转码、脱敏清洗、独立 HTML 网页画册打包）。
- “移至废纸篓”（将所选项安全投递至操作系统回收站）。
