# 画廊视图与显示设置

Omera 提供四种专用的画廊展示呈现视图，旨在满足从快速视觉初筛到深度技术参数比对等多样化的选片工作流。

---

## 1. 画廊四大视图模式

你可以通过顶部工具栏图标或应用菜单（`视图`）快捷切换不同的画廊布局：

### 1. 等宽网格视图 (`grid` — ⊞)
- **核心理念**：固定高度、统一宽高比的卡片以自适应响应式列排列。
- **响应式排版架构**：在缩放或调整主窗口尺寸时，卡片宽度保持平稳。Omera 会智能动态计算列数（`calculateGalleryColumns`），杜绝图片被拉伸、挤压或产生畸变。
- **平滑缩放滑块**：拖动顶部缩放滑块或使用快捷键 `Ctrl + =` / `Ctrl + -`，可将卡片基准最小宽度在 **130 px**（紧凑鸟瞰缩略图）至 **360 px**（大图细节模式）之间无极平滑调节。
- **超强 DOM 虚拟化**：仅渲染视口当前可见区域（附加微量预加载缓冲 Overscan 区域）的卡片元素。滚动浏览 100,000 张图片的超大图库与浏览 100 张图占用相同的极低内存。

### 2. 瀑布流视图 (`masonry` — ▤)
- **核心理念**：流式多列排版，百分之百完整保留每张图片的原始宽高比。
- **无裁切画廊**：非常适合混合包含横版电脑壁纸、9:16 竖版人物立绘概念图以及超长全景图的图库。图片通过 `object-fit: contain` 优雅呈现，绝无边缘被生硬裁剪的缺憾。
- **最短列平衡分配算法**：渲染新图片时，流式布局引擎会自动将其放置在当前垂直高度累计最小的一列中，确保画廊瀑布流整齐美观、下边缘落差平衡。

### 3. 高信息密度列表视图 (`table` — ☰)
- **核心理念**：高度虚拟化的表格数据清单，采用固定的 46px 行高。
- **极致的信息呈现密度**：在微型缩略图（36px 规格）右侧，一览无余地平铺丰富的结构化技术字段：
  - 复选框选中状态
  - 媒体文件名与相对目录路径
  - 容器格式类型（`PNG`、`WEBP`、`MP4` 等）
  - 画面原始分辨率（`宽 × 高`）
  - 磁盘文件大小（格式化 KB/MB 展现）
  - 文件物理修改时间戳
  - 星级评分（0–5 星 / 1–10 标度）
  - AI 美学预测评分（Aesthetic Score）

### 4. 相似图片检索匹配视图 (Visual Similarity Match View)
- **唤起方式**：在右侧属性检查器中点击**“寻找相似图片”**，或在画廊任意图片上右键菜单触发。
- **顶部比对控制横幅**：清晰展示检索基准原图、相似度阈值滑块（**0% 至 95%**，以 5% 为步进阶梯）以及匹配数量上限选择（**20、50、100、200** 项）。
- **相似度百分比徽章**：匹配出的每张图片卡片上方均悬浮带有颜色的相似度数值徽章（例如 `94% 相似度`），由底层本地 CLIP 特征向量余弦相似度计算得出。
- **快速退出**：按键盘 `Esc` 键或点击横幅右上角的关闭图标（`✕`），即可瞬间退出相似检索并回归常规画廊视图。

## 2. 卡片角标与视觉悬浮徽章

在**首选项设置 > 显示与安全保护**中，你可以开启或关闭**显示卡片角标**。开启后，每张卡片底部将附带轻量优雅的信息胶囊：

- **格式容器徽章**：标明 `.png`、`.webp`、`.jpg`、`.mp4` 或 `.webm`。
- **分辨率尺寸徽章**：标注原始物理像素（如 `1024×1024` 或 `832×1216`）。
- **视频时长与帧率**：针对动图和视频，标注播放时长（如 `00:04`）与帧率（`24 fps`）。
- **生成器平台徽章**：识别并标注其生成工具引擎指纹（如 `WebUI`、`ComfyUI`、`NovelAI`、`Fooocus`）。
- **星级评分悬浮**：常驻高亮显示当前评级（★ 1–5）。
- **收藏状态角标**：对于已加入收藏的精品图片，右上角点缀醒目的金色星标。

## 3. 敏感内容 (NSFW) 隐私模糊保护

为了在办公大屏投影、团队汇报或公共场所使用时保护创作者隐私，Omera 内置了严密的敏感内容防护机制：

- **自动模糊遮罩 (`blur_nsfw` 配置项)**：任何标记为 `is_nsfw` 或被识别为成人分级的媒体资产，默认自动覆以强力高斯模糊遮罩层。
- **点击临时显隐 (Click-to-Reveal)**：点击卡片中心眼睛图标（`👁`）或卡片本体，可临时揭开展开该张大图，便于快速审阅。
- **全局敏感内容专区**：左侧边栏设有专用的**敏感内容 (18+) (🔞)**快捷入口，方便用户集中审计、重分类或批量调整敏感标记。
