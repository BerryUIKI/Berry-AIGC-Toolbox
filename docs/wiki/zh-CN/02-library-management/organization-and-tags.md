# 资产整理、评分与标签

Omera 提供了极具生产力价值的图片策展与资产整理体系，专为在不破坏或弄乱底层物理磁盘文件系统的前提下，对数万张生成艺术作品进行飞速分级、打标与归纳而设计。

---

## 1. 星级评分与美学评价体系

Omera 在底层 SQLite 数据库中维护了一套双精度的量化评分模型（`files.rating` 与 `files.aesthetic_score`）：

### 星级评分系统 (0 至 5 星 / 1 至 10 级标度)
- **键盘极速快捷键**：在画廊中选中单张或多张图片，随手敲击：
  - 数字键 `1` 至 `5`：立即赋予对应的星级评分。
  - 数字键 `0`：一键清除当前选中项的星级评分。
- **右侧属性检查器 / 批量操作栏**：通过下拉选择框支持扩展的 10 级评分标度（例如 8/10 或 9/10 分）。
- **高性能 B-Tree 索引加速**：数据库中的 `rating` 字段深度建立了 B-tree 索引，即便在 50 万张图片的超大图库中，执行诸如 `rating:>=4` 或 `rating:5` 的筛选也是瞬间返回。

### 收藏夹 (★ 一键加入书签)
- **快捷切换**：随时按下快捷键 `F`，或在右侧检查器中点击星形图标。
- **视觉反馈**：卡片右上角将立即呈现亮丽的金色星标。
- **侧栏直达**：所有加入收藏的图片，均可随时点击左侧导航侧栏中的**收藏夹 (★)**一网打尽。

## 2. 精选相册管理 (`AlbumModal.vue`)

相册是一种虚拟的分组容器，无需搬移原始物理文件，即可跨不同磁盘或文件夹将主题相似的艺术作品串联在一起。

### 创建与维护相册
1. 在左侧导航栏的**相册**区域，点击 **"+ 新建"**。
2. 输入相册名称（如 `"赛博朋克角色概念"`, `"2026 年度精选集"`）及选填的描述备注。
3. 随时右键点击相册可重命名或删除。删除相册仅移除虚拟归纳关联关系，**绝不会删除**磁盘上的原始物理文件。

### 将图片添加至相册
- **直观拖拽**：在画廊中选中一张或多张卡片，直接拖动并投掷到左侧边栏的目标相册上即可。
- **悬浮批量操作栏**：在底部批量操作栏中点击**“相册”**按钮进行批量归集。
- **右侧检查器**：在右侧参数检查器中，随时通过下拉搜索框关联或解除相册。

## 3. 8 色标签分类体系 (`TagModal.vue`)

标签体系为作品打上了更细粒度的语义标记与视觉状态指示：

### 预设色彩徽章
Omera 预置了 8 种高对比度色彩分类：
- 🔴 红色 (Red)
- 🟠 橙色 (Orange)
- 🟡 黄色 (Yellow)
- 🟢 绿色 (Green)
- 🔵 蓝色 (Blue)
- 🟣 紫色 (Purple)
- 🌸 粉色 (Pink)
- ⚪ 石墨灰 (Slate / Gray)

### 标签的使用技巧
- **新建标签**：点击侧栏**标签**旁的 **"+ 新建"**，挑选一种主题色并输入名称（例如 `主角立绘`、`概念草稿`、`客户已确认`）。
- **拖拽快速打标**：直接将画廊卡片拖拽投掷到左侧对应的标签胶囊上，即可秒速完成多图关联。
- **单选与多选筛选**：在侧栏中点击任意标签，画廊将瞬间过滤并呈现打上该标签的所有作品。
- **无上限多重标签**：每张图片均可叠加赋予无限数量的自定义标签。

## 4. 悬浮批量操作栏 (`BatchActionBar.vue`)

当你在画廊中多选图片时（通过 `Ctrl+单击`、`Shift+单击` 或 `Ctrl+A`），**悬浮批量操作栏**将优雅地从画布底部滑出浮现：

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  [✓ 14 / 120 项已选]  [全选]  [取消选择]                                               │
│  [★ 评分 ▾]  [🏷 标签]  [📁 相册]  [🧠 自动打标]  [★ 收藏]  [🔞 设为敏感]               │
│  [📋 复制路径]  [📋 复制提示词]  [📂 移动]  [📄 复制]  [🧹 清理低分草稿]  [📤 批量导出]   │
│  [🗑 移至废纸篓]                                                                       │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### 核心批量操作详解：
- **批量评分**：为所有选中图片赋予整齐划一的星级评分。
- **批量打标 / 加入相册**：呼出管理弹窗，批量添加或解绑标签与相册。
- **复制提示词**：一键将所有选中图片的完整正向提示词提取至剪贴板，图片间自动插入 `---` 分割线。
- **复制路径**：提取所有选中图片的绝对物理文件路径（每行一条），便于粘贴至终端或外部脚本。
- **移动与复制**：将选中的物理文件批量搬移或拷贝至 Omera 已纳管的其他目录中。
- **清理低分草稿**：当选中项包含连拍堆叠时自动激活（详见[连拍堆叠、扑克卡片与对比](../04-intelligent-curation/stacks-and-bursts.md)）。
- **移至废纸篓**：安全将所有选中的物理文件及附属元数据文件移入操作系统回收站，绝不暴力物理抹除。
