# 提示词统计与词频洞察

随着图库资产规模的飞速累积，深入洞察哪些提示词关键词、艺术风格及核心生成参数能够持续产出高分佳作变得至关重要。Omera 提供了专属的词频与参数统计分析面板（`PromptStatsModal.vue`），可在全库范围内智能汇总提取元数据。

---

## 1. 唤起提示词洞察面板

你可以通过以下两种途径随时呼出数据分析看板：
- 点击顶部菜单栏的 **工具 > 提示词洞察与词频统计...**，或
- 点击左侧导航栏底部快捷工具区中的 **洞察** 按钮。

---

## 2. 分析维度与可视化指标

```
┌────────────────────────────────────────────────────────────────────────┐
│ 提示词与参数洞察                                                   [✕] │
├────────────────────────────────────────────────────────────────────────┤

├────────────────────────────────────────────────────────────────────────┤

├────────────────────────────────────────────────────────────────────────┤
│ 排名 │ 词元 / 提示词标签            │ 出现频次    │ 平均评分   │ 操作  │
├──────┼──────────────────────────────┼─────────────┼────────────┼───────┤

└────────────────────────────────────────────────────────────────────────┘
```

数据看板提供了四个独立维度的深度分析视图：

### 1. 高频正向提示词 (Positive Prompt Tokens)
- 提取全库所有图片正向 Prompt 中的细分词元标签。
- 汇总统计每个词元的总出现频次，并精准核算使用该词元的所有图片的**平均星级评分**。
- 助你快速提炼属于自己的“神仙词组”——那些平均评分稳定保持在 4★ 或 5★ 的制胜关键词。

### 2. 高频负向提示词 (Negative Prompt Tokens)
- 统计在你的生成流程中最常被调用的负向过滤用词。
- 帮助发现并精简那些冗余、低效或并无实质改善效果的死板负面 Embedding 及提示词垃圾。

### 3. Checkpoint 底模热度排行 (Top Checkpoint Models)
- 按照生成作品总数和平均用户评分对图库中使用的所有底模进行排序。
- 明确哪些微调模型或混合底模真正为你带来了最高产出的优质画面。

### 4. 采样器与调度算法 (Samplers & Schedulers)
- 评估各大常用采样器（如 `DPM++ 2M Karras`、`Euler a`、`UniPC` 等）的使用频次及其美学评分表现。

---

## 3. 联动画廊一键反查 (Interactive Search)

分析表格中的每一行末尾均配备了**操作 (`🔍`)**按钮：
- 点击该放大镜图标，分析弹窗将自动关闭，系统自动将选中的词元填充进主画廊顶部搜索栏（如 `prompt:"cinematic lighting"`），并即刻过滤呈现包含该词元的全部作品。
- 这一机制让你能够丝滑地从宏观数据统计直接穿透至微观图片画廊，极大地提升了提示词调优与选图效率。
