# 搜索语法与可视化筛选抽屉

Omera 拥有一套强大的双模态搜索系统：用于精准工程筛选的**结构化语法搜索**，以及用于自然语言概念匹配的 **AI 语义搜图**。

---

## 1. 语法搜索与查询语法

在顶部常驻搜索框中（可通过按键盘 `/` 或快捷键 `Ctrl + F` 快速聚焦激活），你可以直接输入自由模糊文本，也可以组合构建严谨的键值对结构化查询：

### 基础自由文本搜索
- 直接输入不带前缀的单词，将在文件名、相对路径、正向提示词、负向提示词以及模型名称中执行全字段模糊匹配：
  ```
  cyberpunk neon rain
  ```
- 使用半角英文双引号包裹执行精准短语匹配：
  ```
  "cyberpunk street" "rainy reflections"
  ```

## 2. 键值对高级语法速查表

Omera 会在底层 Rust 原生代码中将查询词元解析为结构化的 `SearchCriteria` 实体，并在毫秒级内完成 SQLite 索引过滤：

| 语法前缀 | 示例语法 | 功能说明 |
| :--- | :--- | :--- |
| `prompt:` | `prompt:"masterpiece, 1girl"` | 匹配正向生成提示词中的关键词。 |
| `neg:` | `neg:"bad hands, blurry"` | 匹配负向过滤提示词中的词元。 |
| `model:` | `model:"animagine_xl"` | 按 Checkpoint 模型名称过滤。 |
| `hash:` | `hash:31e35c80` | 匹配模型短哈希或完整的 SHA-256 哈希值。 |
| `sampler:` | `sampler:"Euler a"` | 按采样器算法过滤。 |
| `steps:` | `steps:30`, `steps:20..40`, `steps:>=25` | 匹配精确采样步数或步数区间。 |
| `cfg:` | `cfg:7`, `cfg:>=7.5`, `cfg:5..10` | 匹配提示词引导系数（CFG）或数值区间。 |
| `seed:` | `seed:12345678` | 精确查询指定的随机种子。 |
| `rating:` | `rating:5`, `rating:>=4`, `rating:1..3` | 按用户打分星级进行过滤。 |
| `aesthetic:`| `aesthetic:>=7.0` | 按神经美学评分模型给出的预测值过滤。 |
| `fav:` | `fav:true`, `fav:false` | 按是否收藏进行过滤。 |
| `is:` | `is:nsfw`, `is:sfw` | 按敏感内容分级标志过滤。 |
| `type:` | `type:image`, `type:video` | 按媒体容器类型过滤（仅图片/仅视频）。 |
| `duration:` | `duration:>=5`, `duration:5..30` | 筛选视频播放时长（秒数区间）。 |
| `fps:` | `fps:>=30`, `fps:24..60` | 筛选视频帧率。 |

### 数值范围语法规范
- **闭区间范围 (`min..max`)**：`steps:20..35`（表示采样步数在 20 到 35 之间，包含端点）。
- **大于等于 (`>=`)**：`cfg:>=7.0`（引导系数大于或等于 7.0）。
- **小于等于 (`<=`)**：`rating:<=2`（评分为 2 星或更低）。
- **精确单值匹配**：`rating:5`（仅匹配 5 星）。

## 3. 可视化筛选抽屉 (`FilterDrawer.vue`)

如果你更偏好直观的图形化交互界面，点击搜索框右侧的**抽屉筛选器按钮 (`☰ 筛选`)**，即可平滑滑出侧边多维可视化筛选面板：

## 4. 画廊排序方式设置 (`SortBar.vue`)

在画廊画布右上角，你可以根据需要随心调整当前结果集的排序规则：

### 排序字段：
- **修改时间 (`modified_at`)**：按文件物理写入时间戳倒序或正序排列。
- **文件名称 / 路径 (`path`)**：按文件系统命名拼音或英文字母排序。
- **文件大小 (`size_bytes`)**：按文件在磁盘上所占用的字节大小排序。
- **星级评分 (`rating`)**：按用户打分的高低进行排序。
- **美学评分 (`aesthetic_score`)**：按美学模型预测打分的高低进行排序。

### 排序升降序方向：
- 点击方向按钮可在**降序 (`↓`)**（由高到低 / 最新优先）与**升序 (`↑`)**（由低到高 / 最旧优先）之间秒速切换。
