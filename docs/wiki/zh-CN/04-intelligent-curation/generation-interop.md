# 生图工具互通与双向工作流

Omera 不仅是一个被动的看图资产库，更是你日常创作生图工具的得力副驾驶。它提供针对 **ComfyUI** 与 **AUTOMATIC1111 / SD.Next** 的双向实时 API 通信机制。

---

## 1. 配置生图服务接口地址

在**首选项设置 > 生成环境互通**中配置你的本地服务终结点：

- **ComfyUI 基础地址**：默认 `http://127.0.0.1:8188`
- **AUTOMATIC1111 WebUI 基础地址**：默认 `http://127.0.0.1:7860`

每个配置输入框旁均提供了**“测试连接”**按钮。Omera 会发送轻量级的心跳探测请求（针对 ComfyUI 请求 `/system_stats`，针对 WebUI 请求 `/sdapi/v1/options`），并即时显示 **在线 (🟢)** 或 **离线 (🔴)** 状态徽章。

---

## 2. ComfyUI 工作流一键回传 (`send_to_comfyui`)

当审阅任何由 ComfyUI 生成的图片或视频时：
1. 在右侧属性检查器面板中，找到**生成环境互通卡片**。
2. 点击**“发送到 ComfyUI”**按钮。
3. Omera 后台会直连 ComfyUI 的 `/prompt` HTTP API 接口，将从该图片内嵌提取的完整节点执行图与潜空间参数直接推入。
4. 正在运行的 ComfyUI 实例将瞬间载入该工作流并将其排入生图队列——无需在多个窗口或屏幕间反复手动拖拽文件。

---

## 3. SD WebUI 提示词与参数回传 (`send_to_webui`)

针对来自 AUTOMATIC1111、Forge 或 SD.Next 的作品：
1. 在属性检查器中点击**“发送到 SD WebUI”**。
2. Omera 会组装包含正向 Prompt、Negative Prompt、步数 Steps、采样器 Sampler、CFG 引导系数、Seed 随机种子及分辨率的完整 `txt2img` 载荷。
3. 载荷直接发送至 WebUI 的 `/sdapi/v1/txt2img` API，自动填充 WebUI 界面各参数字段或直接触发新一批次的生成。

---

## 4. 实时生图流水线闭环协作

当你将**生成环境互通**与**AI 自动流水线文件夹**（模式 C）结合使用时，将形成极具生产力的高效闭环：
1. 你在 Omera 中选中历史高分作品，点击一键回传至 ComfyUI 或 WebUI。
2. 生图引擎在后台静默渲染并将新成果写入输出目录。
3. Omera 的后台文件监视器毫秒级捕捉新文件，执行 500 ms 写入防抖、提取参数、生成 WebP 缩略图，并在主画廊画布顶端瞬间呈现全新作品。
4. 这种无缝协同消除了在不同窗口间手动导图、复制粘贴参数的繁琐切换，让创作者能够专注于灵感迭代与筛选。
