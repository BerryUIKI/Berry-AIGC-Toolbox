# 批量导出与静态网页画册

Omera 内置了由 Rust **Rayon** 多线程并发强力驱动的高吞吐媒体导出与打包转码引擎（`ExportModal.vue`）。支持批量格式转码、多级隐私元数据脱敏清洗、动态文件名命名模板以及生成零依赖的独立自适应 HTML 交互网页画册。

---

## 1. 呼出批量导出面板

你可以通过以下方式随时调出导出配置窗口：
- 在画廊画布中选中单张/多张图片或整个堆栈。
- 点击底部悬浮批量操作栏中的**“📤 批量导出...”**，或直接按下快捷键 `Ctrl + E` / `Cmd + E`（或点击应用菜单 `编辑 > 批量导出...`）。

---

## 2. 格式转码与压缩质量调节

Omera 能够跨所有可用 CPU 物理核心并行对媒体资产进行快速重编码与压缩：

| 目标格式 | 调节参数与配置项 | 最佳适用场景 |
| :--- | :--- | :--- |
| **原始格式 (保持原容器)** | 保持原本字节流与容器封装完全不变。 | 原汁原味的资产备份或无损存档。 |
| **WebP** | 可调画质滑块（1–100%，默认推荐 85%）。体积极其紧凑。 | 网页公开发布、Discord 分享、个人作品集网站。 |
| **JPEG** | 标准渐进式 JPEG 编码（画质 1–100%）。 | 兼容老旧照片查看器与通用设备。 |
| **PNG** | 纯无损压缩。 | 高精度印刷出版、客户高保真交付。 |

### 分辨率缩放限制 (Downscaling)：
你可以为导出图片设置最大边长尺寸约束，防止意外分发未经缩小的数千万像素超清原图：
- **保持原始分辨率**（不缩放）
- **4K 超清**（最大边长：3840 px）
- **2K 标清**（最大边长：2048 px）
- **全高清**（最大边长：1080 px）
- **自定义边长**（用户输入自定义最大像素限制）

## 3. 4 级隐私与元数据脱敏清洗

许多创作者希望在社交网络或公开展览中分享艺术作品，同时对核心商业提示词、私有负向 Embedding 或特定种子进行保密。Omera 提供**四级元数据脱敏方案**：

1. **完整保留 (Keep All)**：
   - 完整保留所有内嵌数据块（包括 ComfyUI 流程图 JSON、A1111 原始参数块、NovelAI 注释及原始 EXIF 相机参数）。
2. **仅擦除提示词 (Strip Prompt Only)**：
   - 彻底抹除正向与负向 Prompt 文本描述，但完好保留采样器、步数、CFG 系数、Seed 种子及模型底模名称等技术参数。
3. **擦除所有 AI 生成元数据与工作流 (Strip All AI Metadata)**：
   - 彻底清除 ComfyUI 节点网络图、A1111 参数文本块、LoRA 标签以及所有生成器签名。
4. **完全净化 (Full Clean / 仅保留纯像素)**：
   - 清除一切非像素数据，包括 EXIF 头、ICC 色彩配置文件以及生成软件版本。导出的文件仅包含纯净的原始位图像素，杜绝任何数据泄露风险。

## 4. 命名规则模板与伴随文件

通过直观的动态变量模板为导出文件进行规范化重命名，支持即时效果预览：

### 支持的变量占位符：
- `{name}`：原文件名（不包含扩展名）。
- `{id}`：数据库内部唯一自增 ID 或 UUID。
- `{index}`：流水序号递增（如 001、002、003...）。
- `{date}`：文件生成或修改日期（`YYYY-MM-DD`）。
- `{rating}`：星级评分（例如 `5star`）。
- `{model}`：底模 Checkpoint 名称。
- `{seed}`：生成时使用的随机种子。

*示例规则模板*：`{date}_{model}_{seed}_{name}` → `2026-09-22_animagine_xl_2849104812_cyberpunk_01.webp`

### 伴随元数据文件 (Sidecars)：
可在导出图片的同时，自动在同级目录下输出伴随文件：
- **不生成伴随文件**：仅输出图片。
- **独立提示词文本 (`.txt`)**：将正向生成 Prompt 输出为同名伴随文本文件。
- **完整结构化参数 (`.json`)**：导出包含全部结构化参数及 ComfyUI 完整流程图的 `.json` 文件。

## 5. 独立单文件 HTML 静态网页画册生成

Omera 能够将选中的艺术作品一键打包生成为**完全独立、单文件的现代化静态交互网页画册**（`index.html`）：

- **零运行依赖**：无需部署任何 Web 服务器、无需 Node.js 环境，直接双击即可在任意电脑或手机浏览器中离线打开。
- **内置完整交互特性**：
  - 完美复刻 Omera 的深色高级暗黑主题。
  - 响应式等宽瀑布流画廊网格，内置原生缩略图懒加载。
  - 全屏 Lightbox 灯箱预览器，支持滚轮微米级缩放与鼠标拖拽平移。
  - 侧边抽屉式提示词面板，可随时展开查看生成参数并一键复制。
  - 纯前端瞬时关键词模糊检索过滤。
- **打包输出选项**：可直接输出至指定本地目录，也可勾选**“打包输出为单个 .zip 压缩文件”**，便于直接发送给客户或一键上传至 GitHub Pages / Netlify 进行在线展览。
