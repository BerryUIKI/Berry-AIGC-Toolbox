# 数据库维护与缓存管理

Omera 在设计之初便秉持极高可靠性与几乎免维护的理念。然而，随着你对数十万张生成艺术品进行长期的策展整理、删除低分草稿与拆解堆栈，定期执行数据库压缩物理优化与缩略图缓存维护，能够帮助系统始终处于最佳读写性能峰值。

## 2. SQLite 空间压缩优化 (`VACUUM`)

### 什么是数据库碎片化？
当你在 Omera 中批量删除图片、解绑标签或解散堆栈时，底层 SQLite 并不会立刻物理缩减磁盘上的 `.db` 文件体积，而是将这些被释放的空间标记为“空闲页 (Freelist)”，留待后续写入时重用。

### 执行 `VACUUM` 物理紧凑：
- 点击**“执行 VACUUM”**按钮，将触发底层 SQLite 的原生全表重构整理流程。
- Omera 会重新紧凑排列全量数据行与索引树，将空闲页空间彻底归还给操作系统物理硬盘，立竿见影缩减 `.db` 文件体积。
- **百分之百事务安全保障**：`VACUUM` 过程遵循严格的 ACID 事务特性。即使在执行中途遭遇电脑异常断电，SQLite 也会安全回滚，绝无损坏原有数据的风险。

## 3. 数据库热备份与灾难恢复

### 创建本地热备份快照 (`backup_database`)
- 点击**“导出备份…”**，即可将当前数据库生成一份校验完备的快照副本。
- Omera 深度调用 SQLite 在线热备份 API，整个备份过程完全在后台非阻塞进行，丝毫不影响你前台正常的选片、评分与看图。

### 从备份快照一键还原恢复 (`restore_database`)
- 当需要在新电脑上迁移图库环境，或是需要撤销灾难性的人为误操作时，点击**“恢复数据库…”**。
- Omera 会在载入前自动为当前的运行数据库生成一份安全回滚镜像，然后无缝热替换为指定的备份快照，并瞬间重载图库。

## 4. 缩略图磁盘预算管理与 LRU 淘汰淘汰

所有本地缩略图均以超高压缩比的现代化 WebP 格式保存在 `<app_data_dir>/thumbnails/` 目录中。

### 可自定义的磁盘预算控制：
- 在**首选项设置 > 显示与安全保护**中，可自由配置**缩略图缓存磁盘预算**（默认：`2048 MB` / 2 GB）。
- Omera 在 SQLite 的 `thumbnail_cache_entries` 元数据表中忠实记录每张缩略图的最后访问时间戳。
- 一旦缩略图总体积超出你划拨的磁盘预算上限，Omera 的后台垃圾清理程序将基于工业级 **LRU (最近最少使用)** 淘汰算法，自动剔除最早未被查阅的历史低优先级缩略图。

### 随时一键清空缩略图缓存：
- 当你需要紧急腾出宝贵的系统盘空间时，点击**“清理缩略图缓存”**。
- Omera 会瞬间抹除本地已缓存的 WebP 图片并重置索引表。当你日后重新滚动浏览对应相册或目录时，缩略图会在后台按需毫秒级懒加载自动重新生成。

## 5. 缩略图性能与线程诊断 (`ThumbnailDiagnosticsModal.vue`)

针对追求极致系统监控与性能调优的技术创作者：
- 进入**设置 > 显示与安全保护 > 诊断信息**，可实时监控：
  - 后台活跃的 Rayon 多线程工作池吞吐状态（如 `4 个解码线程并发运行中`）。
  - 等待解码处理的图片任务队列积压深度。
  - 累计已完成与已取消的缩略图生成任务计数。
  - 内存级 LRU 缩略图缓存的高速命中率。
