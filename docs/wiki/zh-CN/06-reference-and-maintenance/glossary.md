# 核心专有名词术语表

本术语表收录并权威定义了贯穿于 **Omera** 全系统的专业技术词汇、架构概念及核心产品特性。

---

## A
- **AIGC (人工智能生成内容 / AI-Generated Content)**：指利用深度神经网络扩散模型（如 Stable Diffusion、ComfyUI、Midjourney、Flux 等）自动生成的图像、动画、音频与视频数字资产。
- **AI管线模式 (模式 C / AIGC Ingestion Pipeline)**：一种主动监听生图工具输出目录的接入模式。具备 500 ms 文件写入锁定防抖、自动收获新图片入库以及延迟安全删除清理队列等特性。
- **相册 (Album)**：由用户自主创建的虚拟聚合收藏合集，可以在不物理挪动磁盘文件的前提下将不同位置的图片归类在一起。
- **主封面图 Hero (Authoritative Hero / 封面)**：在连拍堆叠处于折叠聚合状态时，被用户选定用于代表整组作品画廊形象的核心最优代表图。

## B
- **悬浮批量操作栏 (Batch Action Bar)**：当在画廊画布中选中单张或多张卡片时，浮现在视口中下方的悬浮工具栏，提供快速批量评分、打标、收录相册、导出与移入废纸篓等操作。
- **连拍堆叠 (Burst Stacking)**：在后台自动将提示词高度相似且生成时间高度接近的一组批次跑图作品聚类合并为单张扑克牌折叠卡片的技术。

## C
- **提示词引导系数 CFG (CFG Scale / Classifier-Free Guidance)**：扩散模型中的核心超参数，用于控制最终生成画面与正向文本提示词描述的契合严格程度。
- **Checkpoint 模型 (底模)**：包含完整预训练权重的基础生成神经网络模型（通常为 `.safetensors` 格式），在系统中通过底模名称与 SHA-256 哈希值唯一标识。
- **CLIP (对比式语言-图像预训练)**：由 OpenAI 开源的多模态跨模态视觉表示模型。Omera 基于本地 ONNX 版本的 CLIP/SigLIP 实现文本自然语言语义搜图与以图搜图相似度匹配。
- **ComfyUI**：一种模块化、基于有向无环图（DAG）节点拓扑的高级生图流程引擎。Omera 支持对其内嵌的流程图数据流进行无损反解及双向 API 派发。
- **清理低分草稿 (Cull Drafts)**：一种一键批处理清理动作。它会自动保留堆叠中已精选的高星级主封面图 Hero，而将该批次中未达标的低分草稿变体批量投放至操作系统回收站。

## E
- **外链模式 (模式 A / External Link)**：一种原地零拷贝建立索引的文件夹模式，Omera 仅读取元数据并生成缩略图，绝不改动、移动或污染物理磁盘上的任何原始文件。

## J
- **Jaccard 相似度 (Jaccard Similarity)**：一种用于量化两个集合交集与并集比例的统计学指标。Omera 将正向 Prompt 进行分词提取后计算该系数，作为自动连拍堆叠判定的核心算法依据。

## K
- **游标深度分页 (Keyset Cursor Pagination)**：一种高性能数据库查询翻页策略。通过使用基于排序键的条件检索 `WHERE (modified_at, id) < (?, ?)` 代替传统的全表偏移量扫描 `OFFSET N`，在 50 万+ 级别超大图库中依旧保持 <1ms 的瞬时翻页响应。

## L
- **全屏灯箱预览 (快速查看 / Lightbox)**：按下键盘 `Space` 或 `Enter` 即可唤起的全屏极简看图模式。支持鼠标滚轮微米级无极缩放、拖拽平移以及视频逐帧步进回放。
- **LoRA (低秩适应微调模型 / Low-Rank Adaptation)**：一种附加在 Checkpoint 基础底模之上的轻量级微调权重层，用于向模型注入特定的人物面部、特定服饰、道具细节或艺术画风。

## M
- **托管项目库 (模式 B / Managed Vault)**：由软件集中规范纳管的专属内部存储仓库。新导入的素材会按照日期分区整齐归档至规范目录树中（`年/月/UUID_原文件名.扩展名`）。
- **瀑布流视图 (Masonry Waterfall)**：一种流式多列排版的画廊展示模式。能够百分之百完整呈现每张图片的原始宽高比，画面绝无边缘裁切。

## N
- **敏感内容模糊遮罩 (NSFW Blur)**：一种隐私保护安全机制。对于标记为敏感或成人分级的艺术作品，默认覆以强力高斯模糊遮罩，直到用户主动点击方可临时揭开展开。

## O
- **乐观并发控制 (OCC / Optimistic Concurrency Control)**：一种用于多用户协同的并发事务管理技术。通过数据行级的递增 `version` 版本戳校验，保障团队多人在共享数据库上协同打标、评分时绝不产生数据覆盖与脏写丢失。

## P
- **扑克牌折叠卡片 (Poker-Deck Card)**：图片堆栈在画廊中的立体视觉形态。卡片后侧带有层次分明的阴影与斜切边缘，并带有醒目的成员张数计数角标。
- **词元化交互式提示词标签 (Prompt Chips)**：在属性检查器中呈现的独立可点击芯片标签。每个词元均支持一键全库反查及一键复制，彻底告别阅读密密麻麻的未格式化提示词字符串。

## S
- **采样器与调度器 (Sampler / Scheduler)**：用于在潜空间中逐步剔除噪声、将潜变量恢复为清晰高维画面的数值积分算法（如 `Euler a`、`DPM++ 2M Karras`、`DDIM` 等）。
- **随机种子 (Seed)**：用于初始化伪随机数生成器的长整数数值。在相同底模、提示词与采样步数下，相同的 Seed 能够确保画面生成的百分之百可复现性。
- **伴随文件 (Sidecar File)**：存放在媒体文件同级目录下的伴生文本或数据文件（如 `.txt`、`.json` 或 `.civitai.info`），用于记录外部生成参数或模型元数据。
- **存储根 (Storage Root)**：跨平台的抽象目录唯一标识符（UUID）。在团队协同架构中，用于将统一的共享 NAS 网络位置映射到不同操作系统工作站的本地挂载路径。

## W
- **预写日志 (WAL / Write-Ahead Logging)**：一种高可靠性的 SQLite 日志工作模式。允许写操作与读操作完全并发进行，保障后台在执行大量增量扫描与缩略图入库时，前台画廊查询丝毫不受任何阻塞。
- **WD14 AI 自动打标器 (WD14 Tagger)**：基于深度学习视觉主干网络的 Danbooru 动漫自动预测打标模型，能够秒级直接从图像像素预测出上万种二次元画面标签与内容敏感度分级。
