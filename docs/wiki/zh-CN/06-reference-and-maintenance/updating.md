# 版本升级与数据保护

Omera 内置了完全静默的就地自动更新引擎，旨在快速为你带来最新的生图解析算法支持与性能优化，同时绝不打断你的创作心流，更绝不危及图库数据的安全。

---

## 1. 检查版本更新

### 启动时自动检查：
默认情况下，Omera 在每次应用启动时会在后台轻量级向 GitHub Releases API 发送版本校验请求：
- 若探测到官方发布了更新的正式版本，**帮助**菜单项以及状态栏将亮起优雅的红点更新角标。
- 你可以随时在**首选项设置 > 常规偏好 > 启动时自动检查更新**中选择开启或关闭该探测行为。

### 手动检查更新：
你可以随时手动发起最新版本校验：
- 点击顶部菜单栏的 **帮助 > 检查更新...**。

---

### 极速升级流水线：
1. 点击**“🚀 自动下载并就地更新”**。
2. Omera 将从官方 GitHub Releases 节点高速流式下载适配当前操作系统的增量安装补丁包至临时缓存区。
3. 下载完成后，系统会提示你重启软件。
4. 原生安装更新程序将在后台执行静默覆盖替换，并在数秒内自动重启进入新版 Omera。

## 3. 跨版本数据零丢失架构保障

在 Omera 中执行版本升级**绝对不会触碰或损坏你的任何用户数据**：

- **数据与程序文件彻底物理隔离**：你的核心 `omera.db` 数据库、自创相册、8 色标签分类、星级评分、连拍堆叠从属关系以及 WebP 高速缩略图，均妥善保存在当前操作系统的用户 AppData 应用数据专属目录中（`%APPDATA%`、`~/Library/Application Support` 或 `~/.config`），与软件的可执行二进制文件完全物理隔离。
- **纯追加式增量数据表迁移 (Append-Only Migrations)**：当新版本引入了新增的元数据字段或新的功能表结构时，Rust 后台会在软件启动时依据 `PRAGMA user_version` 自动执行增量结构迁移。迁移过程完全是只追加（Append-Only）模式，绝不会重写、覆盖或抹除你的任何历史图片记录。
- **配置跨版本无缝继承**：你的 `config.json` 偏好配置、自定义缩略图磁盘预算、生图工具 API 地址及所有挂载的文件夹映射，都会在升级后被原封不动地继承。无需卸载旧版，亦无需重新跑配置向导。
