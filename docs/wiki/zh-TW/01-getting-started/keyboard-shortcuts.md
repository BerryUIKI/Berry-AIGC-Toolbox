# 鍵盤快速鍵手冊

Omera 專為**鍵盤優先工作流程**而打造。無需依賴滑鼠，即可在龐大的圖庫中極速完成瀏覽、評分、分組堆疊、參數檢查與分類管理。

---

## 1. 快速查看與畫廊導航

| 快速鍵 | 操作說明 | 適用範圍 | 詳細說明 |
| :--- | :--- | :--- | :--- |
| `Space` 或 `Enter` | **開啟全螢幕燈箱** | 畫廊選取項目 | 為所選圖片或影片開啟高解析度快速查看預覽燈箱。 |
| `Esc` | **關閉 / 取消選取** | 全域 | 關閉燈箱預覽或彈出視窗、退出搜尋，或清除所有選取項目。 |
| `←` / `→` | **瀏覽上一張 / 下一張** | 畫廊與燈箱 | 將選取焦點移至相鄰項目（或在影片播放時逐格前進/後退 1 影格）。 |
| `↑` / `↓` | **導航上一列 / 下一列** | 網格檢視模式 | 在視覺網格中將選取游標垂直移動一列。 |
| `Ctrl + A` / `Cmd + A` | **全選目前檢視** | 畫廊畫布 | 全選目前符合篩選條件的所有卡片項目。 |
| `Delete` 或 `Backspace` | **移至垃圾桶** | 畫廊選取項目 | 將所選項目及其附屬 sidecar 檔案移至系統資源回收筒。 |

---

## 2. 極速篩選與星級評分

| 快速鍵 | 操作說明 | 詳細說明 |
| :--- | :--- | :--- |
| `1` | **評為 1 星** | 為所選項目賦予 1 星評分。 |
| `2` | **評為 2 星** | 為所選項目賦予 2 星評分。 |
| `3` | **評為 3 星** | 為所選項目賦予 3 星評分。 |
| `4` | **評為 4 星** | 為所選項目賦予 4 星評分。 |
| `5` | **評為 5 星** | 為所選項目賦予 5 星評分。 |
| `0` | **清除評分** | 移除所選項目的星級評分。 |
| `F` | **切換收藏狀態** | 將所選項目加入或移出「我的最愛」。 |

> [!TIP]
> **盲打評分法**：您可以一手放在方向鍵（`←`、`→`）上快速翻閱圖片，另一手放在數字鍵 `1`–`5` 上即時給予星級評分。變更會以非同步事務立即寫入 SQLite，完全不中斷瀏覽體驗。

## 3. 圖片堆疊與深度比對

| 快速鍵 | 操作說明 | 適用範圍 | 詳細說明 |
| :--- | :--- | :--- | :--- |
| `Ctrl + G` / `Cmd + G` | **分組建立堆疊** | 畫廊選取項目 | 將多張所選圖片打包為撲克牌折疊卡連拍堆疊。 |
| `Ctrl + Shift + G` / `Cmd + Shift + G` | **解散堆疊** | 畫廊選取項目 | 將所選的堆疊展開並還原為獨立的單張圖片。 |
| `Alt + S` / `Option + S` | **設為封面 Hero** | 堆疊內圖片 | 將當前圖片指定為該堆疊的主封面展示圖。 |
| `C` | **雙圖並排深度比對** | 畫廊選取項目 | 開啟雙螢幕 1:1 分割畫面比對，支援同步縮放與拖曳平移。 |

## 4. 工作區面板與縮放

| 快速鍵 | 操作說明 | 詳細說明 |
| :--- | :--- | :--- |
| `B` | **切換左側側邊欄** | 顯示或隱藏左側導覽面板（媒體庫、資料夾、相簿、標籤）。 |
| `I` | **切換右側檢查器** | 顯示或隱藏右側 AIGC 元數據屬性檢查面板。 |
| `/` 或 `Ctrl + F` / `Cmd + F` | **聚焦搜尋框** | 高亮選取頂部搜尋列並選中現有查詢文字。 |
| `Ctrl + =` / `Cmd + =` | **放大網格** | 增大畫廊圖片卡片縮圖尺寸。 |
| `Ctrl + -` / `Cmd + -` | **縮小網格** | 縮小畫廊圖片卡片縮圖尺寸。 |
| `Ctrl + 0` / `Cmd + 0` | **重設預設縮放** | 將畫廊卡片尺寸重設為標準寬度（256px）。 |
| `F11` | **全螢幕模式** | 切換無邊框全螢幕視窗模式。 |

| `Ctrl + O` / `Cmd + O` | **新增資料夾** | 開啟新增資料夾與模式選擇精靈。 |

## 6. 滑鼠多重選取組合鍵

- **單擊滑鼠左鍵**：選取單張卡片，並將其設定為**選取錨點 (Anchor)**。
- **Shift + 左鍵單擊**：從目前的選取錨點到點擊的卡片之間進行**連續區間多選**。
- **Ctrl + 左鍵單擊**（macOS 為 `Cmd + 左鍵單擊`）：**切換**單個卡片的選取狀態，保留其餘已選中項目，並同步更新選取錨點。
- **按兩下堆疊封面**：直接開啟主封面 Hero 圖片的高解析度燈箱預覽（內建防誤觸仲裁機制，避免意外展開堆疊）。
- **單擊堆疊數量角標**：在目前畫廊網格中就地展開或折疊連拍堆疊。
