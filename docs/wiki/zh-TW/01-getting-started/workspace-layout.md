# 工作區與介面結構

Omera 採用借鑒 **Eagle / Lightroom** 風格的三欄式桌面工作空間，專為高密度視覺策展、快速鍵優先工作流程以及無干擾專注瀏覽而打造。

## 2. 視窗標題列與原生應用程式選單

視窗採用現代無邊框設計，整合自訂標題列組件 (`TitleBar.vue`) 與桌面端選單系統 (`MenuBar.vue`)：

### 頂部選單詳細參考
- **檔案 (File)**：
  - `新增資料夾...` (`Ctrl + O` / `Cmd + O`)：連接新的本機或區域網路共享目錄。
  - `掃描目前目錄`：重新索引目前作用中資料夾的新增或變更檔案。
  - `重新掃描所有目錄`：強制對所有已登記的資料夾執行增量掃描。
  - `資料庫管理...`：開啟資料庫物理壓縮 (`VACUUM`)、空間指標統計與快照備份工具。
  - `偏好設定 / 設定...` (`Ctrl + ,` / `Cmd + ,`)：開啟包含 8 大設定分頁的偏好設定視窗。
  - `結束程式` (`Alt + F4`)：正常關閉並退出工作室。
- **編輯 (Edit)**：
  - `全選目前檢視` (`Ctrl + A` / `Cmd + A`)：全選當前畫廊檢視中的所有圖片卡片。
  - `取消選取` (`Esc`)：取消所有已高亮選取的卡片項目。
  - `批次新增標籤...`：為選取的圖片批次附加或移除分類標籤。
  - `批次加入相簿...`：將選取的圖片分配至指定相簿。
  - `批次移動至資料夾...` / `批次複製至資料夾...`：將實體檔案轉移或複製到其他已索引目錄。
  - `批次匯出...` (`Ctrl + E` / `Cmd + E`)：開啟格式轉碼、隱私擦除脫敏與封裝匯出視窗。
  - `移至垃圾桶` (`Delete` / `Backspace`)：將選取的檔案安全移入作業系統資源回收筒。
- **檢視 (View)**：
  - `網格檢視`：切換為等寬等高響應式排列卡片。
  - `瀑布流（原始寬高比）`：切換為保留圖片原始比例不裁切的多欄流式展示。
  - `清單檢視`：切換為高密度試算表格化清單模式。
  - `切換左側側邊欄` (`B`)：顯示或隱藏左側導覽面板。
  - `切換右側檢查器` (`I`)：顯示或隱藏右側元數據屬性面板。
  - `全螢幕燈箱預覽（快速查看）` (`Space` / `Enter`)：開啟全螢幕高解析度預覽燈箱。
  - `放大網格` (`Ctrl + =`)、`縮小網格` (`Ctrl + -`)、`重設預設縮放` (`Ctrl + 0`)。
- **工具 (Tools)**：
  - `提示詞洞察與統計...`：開啟視覺化詞元頻率分佈與評分關聯性分析。
  - `模型管理器與快取...`：管理 Checkpoint 雜湊與易讀名稱快取對應。
  - `CLIP 語意檢索模型與索引...`：建置圖庫特徵向量嵌入索引，實現自然語言搜圖。
  - `LoRA 觸發詞庫...`：管理 LoRA 啟用觸發詞與 `.civitai.info` 側車檔案。
  - `WD14 AI 自動標籤器...`：開啟本機 Danbooru 動漫風格/美學標籤辨識預測。
- **說明 (Help)**：
  - `語言`：即時在 7 種語言之間無縫切換。
  - `快速鍵手冊` (`?`)：呼叫互動式鍵盤快速鍵指南。
  - `檢查更新...`：連線至 GitHub Releases 查詢最新可用版本。
  - `關於 Omera`：顯示產品版本號、作者與 AGPL 開源授權資訊。

## 3. 左側導覽側邊欄 (`Sidebar.vue`)

左側側邊欄（按 `B` 鍵快速顯示/隱藏）提供資產集合的快速導覽入口：

1. **系統媒體庫**：
   - **全部圖像**：彙整所有已連線資料夾的全域圖庫檢視，附帶資產總數角標。
   - **我的最愛 (★)**：快速篩選所有已加星收藏與書籤的圖片。
   - **敏感內容 (18+) (🔞)**：快速存取已標記為 NSFW 的成人/敏感內容（預設帶有模糊遮罩防護）。
2. **資料夾分組**：
   - 顯示所有已登記資料夾並帶有類型徽章：
     - `⚡`：AIGC 自動管線（持續監聽本機生圖工具輸出目錄）。
     - `📦`：代管專案庫（由軟體託管規範歸檔的內部目錄樹）。
     - `📁`：外部連結與監聽（原地零拷貝唯讀引用索引）。
   - 右鍵點擊或懸停可執行操作：**收穫新圖片**、**掃描目錄**、**重建元數據** 或 **移除資料夾**。
   - 支援拖放操作：可將畫廊中的卡片直接拖曳至資料夾上執行實體移動或複製。
3. **相簿分組**：
   - 使用者自訂虛擬集合。將畫廊卡片拖入相簿即可歸檔，不影響實體目錄。
   - 點擊「+ 新增」即可建立新相簿。
4. **標籤分組**：
   - 8 種視覺色碼標籤體系。
   - 可直接拖曳卡片到標籤徽章上進行大量標記。
5. **快捷工具列底座**：
   - 底部常駐快捷按鈕，點擊即可開啟提示詞洞察、模型庫、資料庫維護以及快速鍵手冊對話框。

## 4. 中央畫廊畫布與搜尋工具列

中央工作區是您瀏覽、選取與智慧策展的核心區域：

- **搜尋列組件 (`SearchBar.vue`)**：
  - **語法搜尋模式 (`🔍`)**：使用自然關鍵字或結構化語法查詢元數據（例如 `prompt:"cyberpunk" cfg:>7`）。
  - **AI 語意搜尋模式 (`🧠`)**：由本機 CLIP/SigLIP 模型驅動的自然語言文字搜圖。
- **檢視切換工具**：
  - 快速切換 **網格 (⊞)**、**瀑布流 (▤)** 與 **清單 (☰)** 版面配置。
  - **縮放滑桿**：動態調整卡片最小寬度（**130px** 至 **360px**）。欄位數量會自適應調整，圖片絕不變形拉伸。
- **抽屜篩選器開關 (`FilterDrawer.vue`)**：
  - 點擊展開多維度篩選抽屜，支援按 Checkpoint 模型、取樣器、長寬比、星級評分以及影片特有屬性交叉篩選。

## 5. 右側屬性檢查器 (`InspectorPane.vue`)

右側參數檢查器（按 `I` 鍵快速顯示/隱藏）為選取項目提供完整無損的 AIGC 生成參數檢視：

- **媒體預覽**：高畫質縮圖檢視，具備 NSFW 遮罩解除開關與燈箱快速查看觸發鈕。
- **策展控制項**：星級評分（0–5 星）、我的最愛切換 (`F`) 以及敏感內容 (NSFW) 標記。
- **正向提示詞 (Positive Prompt)**：互動式分詞標籤檢視。每個詞元（Token）皆渲染為可點擊標籤：
  - 點擊任意詞元即可在全圖庫中反向搜尋該關鍵字。
  - 點擊右上角複製按鈕可一鍵複製完整正向提示詞。
- **負向提示詞 (Negative Prompt)**：完整負向提示詞文字區塊，支援一鍵複製。
- **技術生成參數**：
  - Checkpoint 模型名稱與 SHA256 雜湊 (Hash)。
  - 取樣器 (Sampler) 與排程演算法 (Scheduler)。
  - 取樣步數 (Steps)、CFG 引導係數、隨機種子 (Seed，附帶複製按鈕)。
  - 原始生成尺寸解析度 (`寬 × 高`)。
- **已識別 LoRA 模組**：
  - 列出圖片中偵測到的所有 `<lora:name:weight>` 標籤或 ComfyUI LoRA 載入器節點。
  - 顯示啟用觸發詞、推薦權重，以及一鍵複製標準提示詞格式。
- **生成環境互通卡片**：
  - 實時監測本機 **ComfyUI** 與 **AUTOMATIC1111** 的服務在線狀態。
  - 提供一鍵「傳送至 ComfyUI」（重新入隊工作流程圖）或「傳送至 SD WebUI」。
- **原始元數據手風琴折疊區**：展開檢視未加工的原始 JSON 參數字串或 ComfyUI 節點流程圖。

## 6. 底部狀態列與後台任務浮動視窗

位於視窗最底部：
- **篩選符合 / 總數計數器**：顯示目前符合篩選條件的卡片數量與圖庫總量（例如 `篩選相符: 420 / 12,500 項`）。
- **選取計數器**：顯示當前已選取的資產總數（`已選取: 5 項`）。
- **資料庫狀態**：顯示使用中的資料庫檔案名與綱要結構版本（如 `資料庫版本 v14`）。
- **後台任務彈出視窗 (`⚡ 後台任務`)**：
  - 點擊開啟即時監控視窗，顯示檔案系統監聽器狀態（監聽根目錄、日誌積壓佇列、健康狀態）以及背景 WebP 縮圖解碼進度。

## 7. 浮動批次操作工具列 (`BatchActionBar.vue`)

當畫廊中選取一張或多張卡片時，畫布底部中央會浮現懸浮工具列：

- 多選計數指示器（`X / Y 項已選`），附帶全選與取消選取按鈕。
- 批次星級評分下拉選單（0 至 10 星級）。
- 「加入相簿」與「新增標籤」彈出視窗開關。
- 「自動標籤 (WD14)」一鍵批次辨識。
- 「收藏」與「敏感內容」狀態切換。
- 一鍵「複製路徑」與「複製提示詞」至剪貼簿。
- 「移動」與「複製」實體目錄目的地選取器。
- 「清理低分草稿」（選中堆疊時自動啟用）。
- 「批次匯出...」（格式轉碼、隱私擦除脫敏、打包 ZIP 或 HTML 畫冊）。
- 「移至垃圾桶」（將所選檔案移入系統資源回收筒）。
