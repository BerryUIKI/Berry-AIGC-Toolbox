# 畫廊檢視與顯示選項

Omera 提供四種專門設計的畫廊呈現模式，完美滿足從快速視覺篩選到深度技術檢查等多元策展需求。

---

## 1. 畫廊檢視模式

透過頂部工具列按鈕或選單快捷鍵（`檢視`）可在不同檢視模式間即時切換：

### 1. 等寬網格檢視 (`grid` — ⊞)
- **設計理念**：固定高度、統一比例的卡片，整齊排列於響應式欄位中。
- **響應式排版**：當調整視窗大小時，卡片寬度保持穩定。Omera 會動態增減欄位數量 (`calculateGalleryColumns`)，而非拉伸或壓縮圖片。
- **縮放滑桿**：拖曳縮放滑桿或使用快捷鍵 `Ctrl + =` / `Ctrl + -`，可將卡片最小寬度平滑調整於 **130 px**（高密度縮圖模式）至 **360 px**（大圖細節模式）之間。
- **虛擬滾動 (Virtualization)**：僅對目前位於可視區域內（加上少量前後緩衝區）的卡片進行 DOM 渲染。即使在擁有 100,000 張圖像的龐大圖庫中滾動，記憶體佔用也與瀏覽 100 張圖片無異。

### 2. 瀑布流檢視（原始寬高比） (`masonry` — ▤)
- **設計理念**：流暢的多欄瀑布流排版，完整保留每張圖片的原始寬高比。
- **不裁切原始畫幅**：極度適合包含橫向寬螢幕桌布、垂直角色概念立繪 (9:16) 以及超廣角場景的混合圖庫。圖片透過 `object-fit: contain` 優雅縮放，邊緣細節分毫未損。
- **最短欄位平衡演算法**：新載入的圖片會自動填入目前高度最短的欄位，維持整齊協調且美觀的視覺作品牆。

### 3. 詳細清單檢視 (`table` — ☰)
- **設計理念**：高密度的試算表格化虛擬清單，單列高度固定為 46px。
- **極致資訊密度**：在微型縮圖（36px 規格）旁，完整展示豐富的結構化欄位：
  - 核取方塊選取狀態
  - 檔案名稱與相對目錄路徑
  - 媒體容器格式（`PNG`、`WEBP`、`MP4`）
  - 解析度尺寸（`寬 × 高`）
  - 檔案大小（格式化為 KB/MB）
  - 最後修改時間戳記
  - 星級評分（0–5 星 / 1–10 刻度）
  - 美學評分預測數值

### 4. 視覺相似度檢索檢視 (Visual Similarity Match View)
- **啟用方式**：在任一圖片的右側檢查器或右鍵選單中點擊 **「尋找相似圖片」**。
- **頂部比對工具列**：展示來源參考圖片、相似度門檻滑桿（**0% 至 95%**，以 5% 為步進），以及數量上限選取器（**20、50、100、200** 張）。
- **相似度百分比徽章**：每張比對出的圖片卡片均會標註由 CLIP 特徵向量餘弦距離精確計算的相似度得分徽章（例如 `94% 相似`）。
- **退出檢視**：按下 `Esc` 鍵或點擊工具列上的關閉按鈕 (`✕`)，即可返回原有的常規畫廊檢視。

## 2. 卡片角標與視覺標記

在 **偏好設定 > 顯示與安全保護** 中，您可以開啟或關閉 **「顯示卡片角標」**。啟用後，卡片上會呈現直觀的資訊徽章：

- **格式與容器角標**：標示 `.png`、`.webp`、`.jpg`、`.mp4` 或 `.webm`。
- **尺寸解析度角標**：原始像素解析度（例如 `1024×1024` 或 `832×1216`）。
- **影片時長與 FPS**：針對動態生成內容與影片，顯示總播放時間（例如 `00:05`）與影格率（`24 fps`）。
- **生成平台角標**：辨識生成工具特徵簽名（例如 `WebUI`、`ComfyUI`、`NovelAI`、`Fooocus`）。
- **星級評分浮層**：顯示當前評定星級（★ 1–5）。
- **我的最愛收藏**：已收藏圖片右上角常駐金色星形圖示。

## 3. 敏感內容 (NSFW) 遮罩保護

為在公共場合展示或協同辦公時維護個人隱私，Omera 具備原生的內容安全保護機制：

- **預設模糊遮罩 (`blur_nsfw` 設定)**：任何被標記為 `is_nsfw` 或被評為成人分級的圖片，均會被強效 CSS 模糊濾鏡覆蓋。
- **點擊解鎖檢視**：點擊卡片上的眼睛圖示 (`👁`) 或卡片本體，可臨時揭開該圖片的模糊效果進行檢視。
- **全域敏感內容分類**：左側側邊欄設有專屬的 **敏感內容 (18+) (🔞)** 系統入口，方便使用者集中審核與重新歸類受標記的內容。
