# 組織整理、評分與標籤

Omera 提供強大的資產管理與策展機制，專為在不破壞實體檔案系統結構的前提下，快速分類、篩選與優先排序數以萬計的藝術作品而設計。

---

## 1. 星級評分與評分系統

Omera 採用直接持久化於 SQLite 中的雙精度評分模型（`files.rating` 與 `files.aesthetic_score`）：

### 星級評分（0 至 5 星級或 1 至 10 刻度）
- **鍵盤快捷鍵**：選取一張或多張圖片後按下：
  - `1` 至 `5`：立即賦予對應的星級。
  - `0`：清除當前星級評分。
- **屬性檢查器 / 批次操作列**：透過下拉選單支援延伸的 10 星級精度標註（例如 8/10 或 9/10）。
- **資料庫索引最佳化**：`rating` 欄位建有專門的 SQLite B-tree 索引，即使在擁有 500,000 項資產的龐大圖庫中執行 `rating:>=4` 或 `rating:5` 查詢，依然能在次毫秒內完成檢索。

### 我的最愛收藏（★ 快速書籤）
- **切換方式**：按下 `F` 鍵或點擊檢查器中的星形圖示。
- **視覺呈現**：圖片卡片右上角會固定顯示金色星號標記。
- **側邊欄快速存取**：所有加星收藏的圖片均可在左側側邊欄的 **我的最愛 (★)** 分類中一鍵直達。

## 2. 精選相簿管理 (`AlbumModal.vue`)

相簿功能允許您跨越多個不同實體資料夾將相關的藝術作品組織在一起，完全無需複製或移動硬碟上的實體檔案。

### 建立與管理相簿
1. 在左側側邊欄的 **相簿** 區段，點擊 **「+ 新增」**。
2. 輸入相簿名稱（例如 `"賽博龐克角色設定"`、`"2026 個人精選集"`）以及選填的描述備註。
3. 隨時可在側邊欄對相簿按右鍵進行重新命名或刪除。刪除相簿僅移除虛擬分組關聯，絕不會刪除您的硬碟實體圖片。

### 將作品歸入相簿
- **拖曳歸檔**：從中央畫廊選取一張或多張卡片，直接拖曳到左側側邊欄的目標相簿上。
- **浮動批次操作列**：在選中狀態下點擊浮動操作列的 **「相簿」** 按鈕。
- **右側檢查器**：直接在檢查器面板中搜尋並勾選關聯相簿。

## 3. 8 色標籤體系 (`TagModal.vue`)

標籤功能提供細緻的維度歸類與敏捷的視覺分流：

### 預設 8 色標籤
Omera 提供 8 種醒目的視覺色系預設值：
- 🔴 紅色 (Red)
- 🟠 橘色 (Orange)
- 🟡 黃色 (Yellow)
- 🟢 綠色 (Green)
- 🔵 藍色 (Blue)
- 🟣 紫色 (Purple)
- 🌸 粉紅色 (Pink)
- ⚪ 石墨灰 (Slate / Gray)

### 標籤操作指引
- **建立標籤**：在側邊欄點擊 **「+ 新增」**，挑選代表顏色並輸入名稱（例如 `主要主角`、`未完成草稿`、`客戶已確認`）。
- **拖曳打標**：從中央畫布拖曳選中的卡片，直接放置於側邊欄的標籤膠囊徽章上即可完成標記。
- **按標籤篩選**：點擊側邊欄任一標籤，畫廊即刻快速篩選出包含該標籤的所有資產。
- **多維複合標記**：單張作品支援附加無限數量的分類標籤。

## 4. 浮動批次操作列 (`BatchActionBar.vue`)

當您在畫廊中透過 `Ctrl+點擊`、`Shift+點擊` 或 `Ctrl+A` 進行多選時，畫布底部會平滑滑出 **批次操作列**：

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  [✓ 14 / 120 項已選]  [全選]  [取消選取]                                                │
│  [★ 設定評分 ▾]  [🏷 標籤]  [📁 相簿]  [🧠 自動標籤]  [★ 收藏]  [🔞 設為敏感]             │
│  [📋 複製路徑]  [💬 複製提示詞]  [📂 移動]  [📄 複製]  [🧹 清理低分草稿]  [📤 批次匯出...]  │
│  [🗑 移至垃圾桶]                                                                        │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### 核心批次功能說明：
- **批次評分**：為所選取的所有圖片賦予統一的星級評分。
- **批次標籤 / 相簿**：開啟專用彈窗，一次性批量新增或清除標籤與相簿歸屬。
- **複製提示詞**：將所選圖片的正向提示詞統一複製至系統剪貼簿，條目間以標準的 `---` 分隔線整齊分段。
- **複製路徑**：提取所選檔案的本機絕對路徑（每行一個），方便直接貼上至終端機命令列或 Python 批次處理腳本。
- **移動與複製檔案**：將實體檔案批量遷移或複製至 Omera 已索引的其他實體目標目錄中。
- **清理低分草稿**：當所選卡片中包含圖片堆疊時自動啟用（詳見 [圖片堆疊、連拍與比對](../04-intelligent-curation/stacks-and-bursts.md)）。
- **移至垃圾桶**：安全將所有選中的實體檔案及其伴隨 sidecar 檔案移至作業系統資源回收筒。
