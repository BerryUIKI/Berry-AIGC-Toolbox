# 影片與動態媒體支援

隨著生成式 AI 跨足動態影像領域（如 AnimateDiff、SVD、Wan2.1、HunyuanVideo、CogVideoX、LTX-Video），Omera 提供原生、一流的 **MP4** 與 **WebM** 影片與動態創作支援。

---

## 1. 支援的影片格式與容器

Omera 透過原生 Rust 模組 (`omera-metadata`) 直接解析視訊檔案容器：

- **MP4 (`.mp4`)**：深度剖析 ISOBMFF 盒子樹狀結構（`ftyp`、`moov`、`trak`、`mdia`、`minf`、`stbl`）。
  - 自動擷取視訊解析度（`寬 × 高`）、影格率 (FPS)、播放時長以及視訊編碼格式（`H.264`、`H.265 / HEVC`、`AV1`）。
  - 深度嗅探 `moov/udta` 盒子中內嵌的 ComfyUI 完整執行流程圖與生圖參數。
- **WebM (`.webm`)**：解析 EBML 容器架構，支援 VP8、VP9 與 AV1 視訊資料流，直接從串流標頭中讀取時長與影格尺寸。

---

## 2. 畫廊影片卡片與動態預覽

在中央畫廊畫布中，影片檔案具有鮮明的視覺標記：

- **時長角標**：在卡片角落精確顯示總秒數（例如 `00:05` 或 `01:24`）。
- **影格率與格式角標**：清楚標示 `MP4 · 24fps` 或 `WEBP · 30fps`。
- **智慧縮圖生成**：
  - 由於常規影像庫無法直接解碼視訊影格，Omera 前端 WebView 會在後台透過離屏 HTML5 `<video>` 畫布擷取第一訊框（Keyframe），編碼為 Base64 並由 Rust 後端透過 `save_video_thumbnail` 快取為輕量高品質 WebP 縮圖。
- **懸停即時預覽**：滑鼠游標懸停在影片卡片上時，無需打開燈箱即可在卡片內靜音即時預覽動態畫面。

## 3. 全螢幕燈箱影片播放器 (`LightboxModal.vue`)

在任意影片卡片上按下 `Space` 或 `Enter` 鍵，即可呼叫全螢幕 **快速查看燈箱播放器**：

```
┌────────────────────────────────────────────────────────────────────────┐
│ [✕]                                                          [★ 收藏]  │
│                                                                        │
│                      [ 影片畫布播放區域 ]                              │
│                                                                        │
│                                                                        │
│ ┌────────────────────────────────────────────────────────────────────┐ │
│ │ [▶ / ⏸] [⏪ 1格] [1格 ⏩] [00:03 / 00:08] ──●────── [1.0x ▾] [🔁] [🔊] │ │
│ └────────────────────────────────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────────────────────────────────┐ │
│ │ 底部底片列: [縮圖] [縮圖] [● 當前播放影片] [縮圖] [縮圖]             │ │
│ └────────────────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────────────┘
```

### 燈箱播放控制項說明：
1. **播放 / 暫停**：點擊播放畫布或按下鍵盤 `Space`。
2. **逐格精細步進**：按下鍵盤 `←` 或 `→` 鍵（或點擊 HUD 控制板的步進按鈕），即可逐格前進或後退，極致審視微動作細節與影格畸變。
3. **播放速度調節**：支援 **0.25x**、**0.5x**、**1.0x**、**1.5x** 與 **2.0x** 變速切換。
4. **循環與音訊切換**：快速開啟無縫循環播放 (`🔁`) 與靜音/取消靜音開關 (`🔊`)。
5. **膠卷底片列瀏覽**：透過畫面下方的縮圖膠卷快速切換同目錄下的相鄰圖片與影片。

## 4. ComfyUI 動態與影片工作流程檢視

現代影片生成通常涉及複雜的多階段 ComfyUI 工作流程（例如：文字提示詞 → 初始潛在空間 Latent → AnimateDiff 運動模組 → ControlNet 姿態引導 → 空間超解析度放大）。

當檢視由 ComfyUI 生成的影片檔案時：
- **右側屬性檢查器**：自動解析並提取驅動動態模組的正向與負向文字提示詞。
- **原始元數據手風琴區塊**：完整渲染後台執行節點圖譜，包含 Checkpoint 模型、動態 LoRA、上下文窗口大小 (Context Window)、重疊影格數以及 VAE 解碼參數。
- **生成環境互通**：點擊「傳送至 ComfyUI」，即可將該影片的完整工作流程原封不動地重新載入到正在執行的 ComfyUI 工作區中，隨時微調續跑。
