# AIGC 元數據解析與提示詞檢查

Omera 內建使用原生 Rust 編寫的多引擎無損元數據解析核心 (`omera-metadata`)。它能自動從各大主流 AI 生成平台的輸出檔案中，精準擷取正向提示詞、負向提示詞、模型資訊、隨機種子與完整執行工作流程圖譜。

---

## 1. 支援的 AI 生成平台與解析能力

Omera 原生支援讀取內嵌於 PNG 數據區塊 (Chunks)、WebP EXIF 標頭以及 MP4 ISOBMFF 盒子中的元數據：

| 平台 / 工具 | 擷取的元數據欄位 | 來源容器位置 |
| :--- | :--- | :--- |
| **AUTOMATIC1111 / SD.Next / Forge** | 正向提示詞、負向提示詞、取樣步數、取樣器、CFG、隨機種子、尺寸、模型雜湊、模型名稱、降噪幅度、高畫質修復 (Hires Upscale) | PNG `parameters` 區塊 / JPEG EXIF `UserComment` |
| **ComfyUI** | 完整節點執行圖譜、CLIP 文字編碼正/負向提示詞、KSampler 種子、步數、CFG、模型載入器、LoRA 載入器、潛在放大節點等 | PNG `prompt` 與 `workflow` 區塊 / WebP ComfyUI 區塊 / MP4 `moov/udta` |
| **NovelAI** | 標題、描述、提示詞、負向提示詞、隨機種子、取樣器、步數、引導係數、軟體版本 | PNG `Comment` 與 `Description` 區塊 |
| **Fooocus / Fooocus-MRE** | 基底模型、Refiner 模型、LoRA 權重、銳化度、效能模式、解析度、提示詞文字 | PNG `parameters` 文字區塊 |
| **InvokeAI** | 模型名稱、VAE、排程器、生成模式（txt2img / img2img）、無縫拼貼 | PNG `sd-metadata` 與 `invokeai_metadata` JSON |
| **EasyDiffusion / Stable Swarm** | 格式化 JSON 參數區塊、種子、模型名稱 | PNG `sui_image_params` / 同名側車檔案 |

## 3. 互動式分詞提示詞標籤

Omera 會將冗長雜亂的提示詞文字自動切分為獨立的互動詞元（Token）膠囊標籤，而非單調的長文字塊：

- **一鍵反向搜尋**：點擊任意分詞標籤（如 `[cyberpunk city]`），系統會立即在整個圖庫中反向檢索所有包含該概念的生成作品。
- **一鍵完整複製**：點擊提示詞方框右上角的複製按鈕，即可將乾淨、標準化的提示詞文字複製到剪貼簿中。
- **提示詞靈感發掘**：透過標籤化展示，您可以輕鬆辨識不同藝術家風格、燈光照明術語或畫質增強標籤，方便二次創作抽樣借鑒。

## 4. Checkpoint 模型與雜湊比對

生成式工具通常在檔案中僅寫入簡短的模型雜湊（如 `31e35c80`）或完整 SHA256 雜湊，而缺少可讀的模型檔案名稱。

- Omera 會自動查詢本機的 **模型快取資料庫**（`model_cache` SQLite 資料表），將晦澀的雜湊字串即時轉譯為友善的模型名稱（如 `"Animagine XL 3.1"`）。
- 若遇到未收錄的未知雜湊，您可以直接匯入 AUTOMATIC1111 的 `cache.json` 檔案，或透過內建的一鍵連線至 Civitai 反向查詢（詳見 [模型庫與 LoRA 觸發詞庫](../04-intelligent-curation/models-and-loras.md)）。

## 5. 原始元數據與 ComfyUI 流程圖 JSON

針對需要深入分析節點拓撲的高階使用者與技術美術人員：
- 展開檢查器底部的 **原始元數據** 手風琴折疊區，即可直接檢視未經修改的原生 JSON 封包。
- 支援一鍵完整複製 JSON 工作流程內容，可直接貼上至程式碼編輯器中，或分享給團隊成員協同除錯。
