# 搜尋語法與視覺化篩選

Omera 配備雙引擎搜尋系統：提供技術參數精準檢索的**結構化語法搜尋**，以及理解自然語言描述概念的 **AI 語意搜尋**。

---

## 1. 語法搜尋與查詢語言

在頂部搜尋列（按 `/` 或 `Ctrl + F` 快速聚焦）中，您可以直接鍵入隨意關鍵字，或組合使用強大的結構化鍵值查詢語法：

### 基礎自由文字搜尋
- 不帶前綴輸入任何關鍵字，系統會自動在檔案名稱、相對路徑、正向提示詞、負向提示詞及模型名稱中進行綜合比對：
  ```
  cyberpunk neon rain
  ```
- 若需精確比對片語，請使用雙引號包覆：
  ```
  "cyberpunk street" "rainy reflections"
  ```

---

## 2. 鍵值查詢語法對照表

Omera 的原生 Rust 後端會將搜尋詞元（Token）即時解析為結構化的 `SearchCriteria` 物件，並利用 SQLite 複合索引實現次毫秒級的超高速查詢響應：

| 查詢前綴 | 語法範例 | 說明 |
| :--- | :--- | :--- |
| `prompt:` | `prompt:"masterpiece, 1girl"` | 比對正向生成提示詞中的分詞與字串。 |
| `neg:` | `neg:"bad hands, blurry"` | 比對負向提示詞 (Negative Prompt)。 |
| `model:` | `model:"animagine_xl"` | 按 Checkpoint 模型名稱篩選。 |
| `hash:` | `hash:31e35c80` | 比對模型短雜湊 (Short Hash) 或完整 SHA256 雜湊值。 |
| `sampler:` | `sampler:"Euler a"` | 按取樣器演算法名稱篩選。 |
| `steps:` | `steps:30`, `steps:20..40`, `steps:>=25` | 比對精確取樣步數或數值範圍。 |
| `cfg:` | `cfg:7`, `cfg:>=7.5`, `cfg:5..10` | 比對提示詞引導係數 (CFG) 或數值範圍。 |
| `seed:` | `seed:12345678` | 搜尋特定的隨機生成種子數值。 |
| `rating:` | `rating:5`, `rating:>=4`, `rating:1..3` | 按使用者星級評分進行精確或範圍篩選。 |
| `aesthetic:`| `aesthetic:>=7.0` | 按類神經網路預測的美學評分數值篩選。 |
| `fav:` | `fav:true`, `fav:false` | 篩選是否已加星加入「我的最愛」。 |
| `is:` | `is:nsfw`, `is:sfw` | 按敏感內容 (NSFW) 標記狀態進行篩選。 |
| `type:` | `type:image`, `type:video` | 按媒體容器類型（圖片或影片）篩選。 |
| `duration:` | `duration:>=5`, `duration:5..30` | 按影片時長（秒）進行範圍篩選。 |
| `fps:` | `fps:>=30`, `fps:24..60` | 按影片影格率 (FPS) 進行範圍篩選。 |

### 數值範圍進階語法
- **閉區間範圍 (`min..max`)**：`steps:20..35`（介於 20 至 35 步之間，包含邊界）。
- **大於或等於 (`>=`)**：`cfg:>=7.0`（引導係數等於或高於 7.0）。
- **小於或等於 (`<=`)**：`rating:<=2`（2 星級或更低）。
- **精準等值**：`rating:5`（精確為 5 星級）。

## 3. 視覺化抽屜篩選器 (`FilterDrawer.vue`)

若您偏好圖形介面操作而非手動鍵入語法，可點擊搜尋列右側的 **抽屜篩選器按鈕 (`☰ 篩選器`)** 滑出視覺化篩選面板：

│ [ 全部模型 ▾                                         ] │

│ [ 全部取樣器 ▾                                       ] │

│ 最小: [ 20 ] ────────────●──────────── 最大: [ 50 ]    │
│                                                        │

## 4. 畫廊排序控制項 (`SortBar.vue`)

在中央畫廊畫布頂部右側，您可以自由調整當前過濾結果的排列順序：

### 排序維度：
- **修改時間 (`modified_at`)**：按檔案於磁碟上的時間戳記排序。
- **檔案名稱 / 路徑 (`path`)**：按檔案名稱或檔案系統目錄字母順序排列。
- **檔案大小 (`size_bytes`)**：按實體佔用磁碟容量排序。
- **星級評分 (`rating`)**：按手動評定的星級高低排列。
- **美學評分 (`aesthetic_score`)**：按類神經網路美學評測分數排序。

### 排序方向：
- 點擊方向按鈕即可在 **降序 (`↓`)**（高到低 / 最新排前）與 **升序 (`↑`)**（低到高 / 最舊排前）之間迅速切換。
