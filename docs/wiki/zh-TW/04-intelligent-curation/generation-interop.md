# 生成環境互通整合

Omera 不僅是靜態的圖片檢視器，更是您生圖工作流的即時夥伴。它提供與 **ComfyUI** 及 **AUTOMATIC1111 / SD.Next** 的雙向原生 API 通訊能力。

---

## 1. 配置生圖服務端點

在 **偏好設定 > 生成環境互通** 中配置服務位址：

- **ComfyUI 基礎位址**：預設為 `http://127.0.0.1:8188`
- **SD WebUI 基礎位址**：預設為 `http://127.0.0.1:7860`

每個設定欄位均配有專屬的 **「測試連線」** 按鈕。Omera 會發送輕量健康檢查 Ping（ComfyUI 為 `/system_stats`，WebUI 為 `/sdapi/v1/options`），並即時顯示 **在線 (🟢)** 或 **離線 (🔴)** 狀態指示徽章。

---

## 2. ComfyUI 工作流程調度 (`send_to_comfyui`)

在瀏覽由 ComfyUI 生成的圖片或影片時：
1. 在右側屬性檢查器中找到 **生成環境互通卡片**。
2. 點擊 **「傳送至 ComfyUI」** 按鈕。
3. Omera 後端會直連 ComfyUI 的 `/prompt` HTTP 端點，將從該圖片中提取出的精準節點圖譜與潛在空間參數重新提交。
4. 您的 ComfyUI 實體會立即載入該工作流程並加入生成任務佇列——徹底告別跨視窗手動拖曳檔案的繁瑣操作。

---

## 3. SD WebUI 提示詞與參數調度 (`send_to_webui`)

針對在 AUTOMATIC1111、Forge 或 SD.Next 中產出的圖像：
1. 在檢查器中點擊 **「傳送至 SD WebUI」**。
2. Omera 會格式化一個標準的 txt2img 請求封包，包含正向提示詞、負向提示詞、步數、取樣器、CFG 引導係數、隨機種子與尺寸。
3. 該封包將透過 WebUI 的 `/sdapi/v1/txt2img` API 送達，自動填入您的 WebUI 參數輸入框或直接觸發新的生成任務。

---

## 4. 即時管線監聽閉環

當您將 **生成環境互通** 與 **AIGC 自動管線資料夾**（模式 C）結合使用時：
1. 您在 Omera 中點擊「傳送至 ComfyUI / WebUI」。
2. 生圖工具在背景進行渲染並將成品寫入輸出資料夾。
3. Omera 背景監聽器即刻探測到新檔案，進行 500 ms 寫入防抖確認、無損提取元數據、生成高品質 WebP 縮圖，並將最終成品以動畫形式呈現在畫廊最頂端。
4. 形成「調度生圖 → 監聽渲染 → 自動入庫 → 智慧策展」的零中斷極致創作閉環。
