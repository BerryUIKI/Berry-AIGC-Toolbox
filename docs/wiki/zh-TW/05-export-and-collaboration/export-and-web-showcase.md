# 批次匯出、轉碼與網頁畫冊

Omera 配備由 **Rayon** 多執行緒並行計算驅動的高吞吐量媒體匯出與封裝引擎 (`ExportModal.vue`)。支援多格式平行轉碼、4 級隱私元數據擦除脫敏、動態檔名範本替換，以及一鍵生成零外部依賴的獨立單檔案互動 HTML 網頁畫冊。

---

## 1. 開啟批次匯出介面

您可以透過以下方式開啟匯出面板：
- 在畫廊中選取一張或多張圖片或堆疊。
- 點擊底部浮動批次操作列上的 **「批次匯出...」** 按鈕，或按下快捷鍵 `Ctrl + E` / `Cmd + E`（或點擊頂部選單 `編輯 > 批次匯出...`）。

---

## 2. 格式平行轉碼與解析度壓縮

Omera 能跨所有 CPU 核心平行並行處理影像格式轉換與壓縮編碼：

| 目標格式 | 選項與參數特性 | 最佳應用場景 |
| :--- | :--- | :--- |
| **原始格式 (Original)** | 保持原始檔案位元組與容器不變。 | 無損歸檔存儲、完整備份。 |
| **WebP** | 品質滑桿可調（1–100%，預設 85%）。具備極致壓縮率與優異畫質。 | 網頁發布、Discord 社群交流、線上作品集展示。 |
| **JPEG** | 標準漸進式 JPEG 編碼（品質 1–100% 可調）。 | 相容舊型相片檢視裝置與通用系統。 |
| **PNG** | 純無損點陣圖壓縮。 | 工作室交接、高規格印刷輸出。 |

### 解析度縮放限制：
為避免意外散佈未壓縮的超大 4K/8K 龐大影像，可自訂最大輸出邊長限制：
- **原始尺寸**（不縮放）
- **4K 超清**（最大邊長限制：3840 px）
- **2K 標清**（最大邊長限制：2048 px）
- **全高清 1080p**（最大邊長限制：1080 px）
- **自訂邊長上限**（由使用者手動指定最大像素限制）

## 3. 4 級隱私元數據清洗與脫敏

許多創作者在社群平台分享作品時，希望對商業正向提示詞、私有負向 Embeddings 或精確種子進行保密。Omera 提供精細的 **4 級隱私保護脫敏模式**：

1. **完整保留 (Keep All)**：
   - 完整保留圖片內嵌的所有 A1111/ComfyUI 節點參數、NovelAI 註解及相機 EXIF 拍攝數據。
2. **僅擦除提示詞 (Strip Prompt Only)**：
   - 移除正向與負向提示詞字串，但保留模型名稱、取樣器、步數、CFG 引導係數與隨機種子等技術參數。
3. **擦除所有 AI 生成元資料與工作流 (Strip All AI Metadata)**：
   - 徹底清除 ComfyUI 流程圖、A1111 參數塊、LoRA 引用資訊與生圖軟體簽名。
4. **完全淨化 (Full Clean / Pixel-Only Sanitization)**：
   - 抹除包含 EXIF 標頭、ICC 色彩設定檔及軟體特徵在內的所有非像素數據。匯出檔案僅包含純點陣圖像素，極度適合公開發布或商業交付。

## 4. 命名規則範本與伴隨側車檔案

匯出時支援使用動態變數自訂輸出檔名，並提供所見即所得的即時效果預覽：

### 支援的範本變數：
- `{name}`：原始檔名（不含副檔名）。
- `{id}`：資料庫唯一 ID 或 UUID。
- `{index}`：流水號序號（001, 002, 003...）。
- `{date}`：建立日期（`YYYY-MM-DD`）。
- `{rating}`：星級評分（例如 `5star`）。
- `{model}`：Checkpoint 模型名稱。
- `{seed}`：生成隨機種子值。

*範本範例*：`{date}_{model}_{seed}_{name}` → `2026-09-22_animagine_xl_2849104812_cyberpunk_01.webp`

### 伴隨元數據側車檔案 (Sidecars)：
可選擇為每張匯出的圖片同步輸出伴隨文字檔案：
- **不生成伴隨檔案 (None)**：僅匯出影像實體。
- **獨立提示詞文字 (.txt)**：將正向提示詞單獨匯出為同名文字檔。
- **完整結構化參數 (.json)**：匯出完整的結構化元數據 JSON 與 ComfyUI 工作流程圖。

## 5. 獨立單檔案互動 HTML 網頁畫冊生成

Omera 能將您選取匯出的藝術作品直接打包為一個**完全離線、零外部相依的互動式單檔案網頁相簿** (`index.html`)：

- **零環境相依**：無需架設 Web 伺服器、無需 Node.js、無需外連 CDN。連線斷網狀態下按兩下即可在任何現代網頁瀏覽器中完美呈現。
- **內建強大功能**：
  - 與 Omera 風格一致的專業深色暗黑主題。
  - 具備延遲載入 (Lazy-load) 的響應式瀑布流畫廊畫布。
  - 支援滑鼠滾輪縮放與拖曳平移的全螢幕燈箱 Lightbox。
  - 可折疊式提示詞與生成參數檢查面版（支援一鍵複製）。
  - 純前端毫秒級即時關鍵字檢索搜尋列。
- **封裝輸出選項**：可直接匯出至本機指定資料夾，或一鍵打包壓縮為單一 `.zip` 檔案，方便快速交付客戶審閱或上傳至個人靜態網站託管。
