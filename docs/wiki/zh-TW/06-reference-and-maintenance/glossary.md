# 產品專有名詞詞彙表

本詞彙表定義了在 **Omera** 軟體介面、文檔與架構設計中頻繁出現的核心領域專有名詞與技術術語。

---

## A
- **AIGC (AI-Generated Content / 人工智慧生成內容)**：利用 Stable Diffusion、ComfyUI、Midjourney、Flux 等深度學習類神經網路模型生成的數位多媒體（圖片、動態插畫、音訊及影片）。
- **AIGC 自動管線 (Mode C / AIGC Ingestion Pipeline)**：一種主動式資料夾監聽模式。它持續監視生圖工具的輸出目錄，具備 500 ms 磁碟寫入防抖、自動收穫新圖入庫以及過期原圖安全移至資源回收筒機制。
- **相簿 (Album)**：由使用者自訂建立的虛擬藝術作品集合，在無需移動實體硬碟檔案的前提下進行彈性分組。
- **權威主封面圖 (Authoritative Hero)**：在畫廊處於摺疊展示狀態時，被指定用以代表整個連拍堆疊的精選首選圖片。

## B
- **批次操作列 (Batch Action Bar)**：當畫廊中選中一張或多張卡片時，懸浮於畫布底部中央的工具列，提供評分、標籤、相簿、轉碼匯出與移至垃圾桶等批次處理功能。
- **連拍堆疊 (Burst Stacking)**：將短時間內生成的、提示詞高度相似的一組跑批變體圖片，自動聚合為單一折疊卡片的智慧分群機制。

## C
- **CFG 引導係數 (Classifier-Free Guidance / CFG Scale)**：擴散模型中的關鍵超參數，用於控制生成的畫面多大程度嚴格遵循文字提示詞的描述。
- **Checkpoint 大模型**：包含已完成訓練權重的核心生成模型檔案（通常為 `.safetensors` 格式），透過模型名稱與 SHA256 雜湊識別。
- **CLIP (Contrastive Language-Image Pre-training)**：多模態視覺-語言神經網路架構，Omera 利用其進行本機自然語言文字搜圖與視覺向量相似度比對。
- **ComfyUI**：基於節點圖譜的高自由度模組化生成式 AI 工作流引擎。Omera 支援深度剖析其內嵌的完整節點拓撲圖，並支援 API 一鍵反向提交工作流程。
- **清理低分草稿 (Cull Drafts)**：一種智慧批次清理機制，保留連拍堆疊中的高分精選封面圖，將其餘未達標的冗餘變體安全移入系統資源回收筒。

## E
- **外部連結與監聽 (Mode A / External Link)**：一種資料夾連線模式。以原地零拷貝方式對本機或 NAS 儲存建立唯讀索引，完全不移動或更動磁碟上的原始檔案結構。

## J
- **Jaccard 相似度 (Jaccard Similarity)**：一種集合論統計指標，用於評估兩段提示詞分詞集合的重疊交集比例，驅動自動連拍堆疊的智慧分群判斷。

## K
- **鍵集游標分頁 (Keyset Cursor Pagination)**：一種高效能資料庫查詢策略，以 `WHERE (modified_at, id) < (?, ?)` 取代效能低落的傳統 `OFFSET N`，使 500,000+ 龐大圖庫在深層瀏覽時始終保持次毫秒級響應。

## L
- **燈箱預覽 / 快速查看 (Lightbox / Quick Look)**：按下 `Space` 或 `Enter` 呼叫的全螢幕無干擾預覽視窗，支援滑鼠滾輪縮放、平移拖曳以及影片逐格微調。
- **LoRA (Low-Rank Adaptation / 低秩適應)**：一種高效的微調外掛權重模型，掛載於 Checkpoint 之上以引導特定的動漫角色、特定藝術家畫風或服裝特徵。

## M
- **代管專案庫資料夾 (Mode B / Managed Vault)**：由軟體負責規範管理的作品庫，將匯入的圖片統一歸檔至標準的年/月分層目錄結構中 (`YYYY/MM/UUID_檔名.副檔名`)。
- **瀑布流檢視（原始寬高比） (Masonry Waterfall)**：一種多欄流式畫廊排版模式，保持作品原始寬高比例不裁切，透過最短欄位平衡演算法打造協調的藝術牆。

## N
- **敏感內容遮罩 (NSFW Blur)**：一項隱私保護功能，在成人或敏感標籤內容上覆蓋強效模糊濾鏡，直到使用者手動點擊方可臨時揭開檢視。

## O
- **樂觀並行控制 (OCC / Optimistic Concurrency Control)**：一種多機協同並行機制，利用資料列級的 `version` 版本號比對，防止多名藝術家在共享 NAS 上同時評分或打標籤時發生資料覆蓋與遺失。

## P
- **撲克牌折疊卡片 (Poker-Deck Card)**：圖片堆疊在畫廊網格中的專屬視覺呈現樣式，卡片後方呈現錯落的層疊陰影與醒目的張數標籤。
- **提示詞分詞標籤 (Prompt Chips)**：在右側屬性檢查器中，將提示詞切分為獨立的互動膠囊標籤，點擊即可一鍵反向檢索或複製。

## S
- **取樣器 / 排程器 (Sampler / Scheduler)**：數值積分降噪演算法（例如 `Euler a`、`DPM++ 2M Karras`），負責將潛在雜訊一步步解碼為清晰的點陣圖。
- **隨機種子 (Seed)**：初始化偽隨機雜訊生成器的整數值，決定擴散過程的初始雜訊構圖，是重現特定生成畫面的關鍵基礎。
- **伴隨側車檔案 (Sidecar File)**：與圖片存放於同一目錄下的同名 `.txt` 或 `.json` 檔案，用於補足遺失的內嵌生成參數或 Civitai 詮釋資料。
- **儲存根 (Storage Root)**：跨平台的抽象儲存目錄識別碼 (UUID)，使團隊成員能將中央共享 NAS 對應至各自作業系統的本機掛載路徑。

## W
- **WAL (Write-Ahead Logging / 預寫日誌)**：SQLite 的現代交易日誌模式，確保多執行緒在進行背景索引與縮圖生成時，前端依然能享有極致流暢的無鎖讀取效能。
- **WD14 自動標籤器 (WD14 Tagger)**：由 SmilingWolf 研發的開源電腦視覺類神經網路模型，能直接透過圖片點陣圖像素自動辨識 Danbooru 動漫標籤與內容分級。
