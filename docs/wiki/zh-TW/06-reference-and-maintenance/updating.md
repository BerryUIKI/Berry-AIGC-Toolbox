# 檢查更新與升級

Omera 配備安靜、無痛的就地覆蓋更新機制，旨在持續提供效能最佳化與新功能支援，同時保障您的工作流程不受打擾、珍貴的資產與標籤數據萬無一失。

---

## 1. 檢查可用更新

### 啟動時自動檢查：
預設情況下，Omera 在啟動時會非同步連線 GitHub Releases API：
- 若探測到更新版本，頂部選單列的 **說明** 功能表會顯示顯眼的更新徽章。
- 您可隨時在 **偏好設定 > 一般偏好 > 啟動時自動檢查更新** 中開啟或關閉此行為。

### 手動隨時檢查：
您可隨時手動觸發版本檢查：
- 點擊頂部選單列的 **說明 > 檢查更新...**。

---

### 就地安裝更新流程：
1. 點擊 **「🚀 自動下載並就地更新」**。
2. Omera 會直接從 GitHub Releases 將符合您目前作業系統架構的更新套件串流下載至暫存升級目錄中。
3. 下載完畢後，點擊 **「⚡ 立即安裝並重啟」**。
4. 原生安裝程式將在背景以無訊息模式快速就地覆蓋舊版二進位檔案，並自動重啟軟體完成升級。

## 3. 資料安全與跨版本相容保證

升級 Omera **絕對不會更動或遺失您的個人資料**：

- **資料庫完全實體隔離**：您的核心 SQLite 資料庫 (`omera.db`)、自訂相簿、彩色分類標籤、星級評分與連拍堆疊關係，均安全儲存在系統的使用者 AppData 設定檔目錄中（`%APPDATA%`、`~/Library/Application Support` 或 `~/.config`），與安裝程式二進位執行檔完全物理隔離。
- **僅向上追加的結構遷移 (Append-Only Migrations)**：當新版本包含資料表結構變更時，Omera 的 Rust 後端在啟動時會透過 `PRAGMA user_version` 自動執行增量遷移指令碼。遷移僅會在原庫上追加必要的新欄位與新索引，絕不覆寫或刪除現存的歷史資料列。
- **持久化設定保存**：您的 `config.json` 偏好設定、自訂快速鍵、縮圖快取配額與已登記的資料夾路徑，在跨版本升級過程中均會完整完好保留。
