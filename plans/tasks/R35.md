The UI presents this as Select all without making the loaded-page scope clear.

1. Index a folder containing more than 400 images and open it without scrolling through all pages.
2. Press Ctrl+A or the gallery Select all control.
3. Compare the selection count with the folder's total. The native review observed 400 selected out of 1,276 indexed.
4. Clear the selection; do not execute a destructive batch action.
